## 4. 常用研发命令速查

```bash
npm run dev          # 启动 Electron 热重载开发模式
npm run typecheck    # Node + Web 双端 TypeScript 严格类型检查
npm test             # 运行 Vitest 全量单元测试套件
npm run lint         # ESLint + 硬编码 CJK 国际化门禁检查
npm run format:check # Prettier 格式一致性校验（printWidth: 100, LF）
npm run site         # 本地预览静态官网（http://localhost:5174）
```

> **节点图端口连线铁律**：源端口与目标端口的 `dataType` 必须严格相等；单数与复数端口（如 `image` 与 `images`、`text` 与 `texts`）互不相通，列表选取节点仅接收复数列表口。
