# AI 对话：像跟同事聊天一样，指挥你的 AI 创作流水线

> 你负责想，它负责干。这是 AiArtEngine 内置的 AI 对话助手——一个真正**会调用工具干活**的创作搭子，而不是只会打字的聊天框。

## 先记住一句话

别的 AI 工具，聊完天你得自己把话翻译成操作：复制提示词、找模型、拖节点、调参数。

AIArtEngine 的对话助手不一样——**你只管说，它直接动手**：

- 你说「给产品出一张赛博朋克主视觉」，它就去调图像模型，把图生成到你的工程里；
- 你说「把这张图转成 3D 白模，扔进导演台」，它就去建 3D 资产、把节点图连好；
- 你说「用可灵把主视觉做成 15 秒广告」，它就调度视频模型，把成片素材送进时间线。

图、3D、视频、工作流、任务执行……**全在同一个窗口里，用一句话串起来**。这就是本应用把 DeepSeek Harness（业界前沿的 AI Agent 运行时）集成进来带来的能力：一个懂美术、会操作软件的全能助手，住进了你的软件里。

## 使用前，只需要两件事

1. **打开一个工程**（或者新建一个）。有工程它才能在里面帮你干活；不打开工程就只能闲聊。
2. **配置一个文本模型**：设置 → 模型接入 → 任一服务商填好 API Key 并启用即可（DeepSeek 官方体验最佳）。

都准备好了？打开侧边栏底部的 **◈（AI 对话）**，开始。

> 首次使用时，助手会做一次"体检"：检查运行环境、模型是否就绪、工作区是否打开。缺什么都会用大白话提示你，照着做就行，不用懂技术。

## 三步上手：跟 AI 对话面板聊天

### 第 1 步：选好你的"大脑"

面板顶部选择一个文本模型。下拉列表里已经按你配置的服务商整理好了，选一个今天想用的即可——比如 DeepSeek。

### 第 2 步：@ 引用素材（可选，但强烈推荐）

想让 AI 基于某张图/某段视频创作？在输入框里输入 `@`，会弹出工程里的资产列表，点选即可。引用会显示成带缩略图的小卡片，AI 一眼就知道你要用哪个素材。

### 第 3 步：用人话下需求，发送

试着说：

> **@参考图 给产品出一张赛博朋克风格的主视觉，深色调、霓虹光**

发送后，你会看到它：

1. 折叠展示一段"思考过程"（它在想怎么拆解你的需求）；
2. 弹出工具卡片，显示它正在调用哪个能力、进度如何；
3. 完成后把结果（图片）直接存进工程资产库，你可以马上在资产面板看到它。

## 它自带一套创作技能，不用学就会用

对话助手不只是会聊天，它**天生带着一套"美术职业能力"**，也就是创作技能。这些技能来自应用内置的导演台/分镜工作台能力（GraphSkill），每次对话启动时自动注入助手的大脑，随叫随用：

| 技能分类        | 代表技能                                                                                                                                                                           | 一句话说明                                                                                                                            |
| --------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| **分镜 / 动画** | 分镜师 · 9宫格分镜表、节拍拆解表、动态提示词表、4宫格动态分镜表、9宫格动态提示词表                                                                                                 | 把剧本拆成画面：节拍、机位、运动、提示词一步到位                                                                                      |
| **导演审核**    | 导演审核 · 9宫格分镜表、节拍拆解表、动态提示词表                                                                                                                                   | 以导演视角审查分镜与节奏，给出修改意见                                                                                                |
| **2D 帧动画**   | 2D 帧动画（GIF）                                                                                                                                                                   | 分格序列图或动作视频（`in` / `in-video`）→ 自动抠底 + 原地稳像 + 逐帧 PNG / GIF 动图：节点 `anim.2d` 设 `animGifFps` 后运行即产出 GIF |
| **系统创作**    | 剧本、图生提示词、图片生成、视频生成、声音、情绪、灯光、多角度、扩图、重绘、抠图、高清放大、界面图、界面拆分、世界提取、节拍拆分、节拍单元生成、策划案、肖像贴图、提示词优化、擦除 | 单点能力，专门对付某一个创作动作                                                                                                      |

这些技能**不用配置、不用安装**：应用内置，对话时自动就位。你可以直接说：

> 「用分镜技能，把这段剧本拆成 9 宫格分镜表」

助手就会调出对应的分镜技能，按专业流程（节拍 → 机位 → 动态 → 提示词）产出结果，而不是凭空瞎编。它知道哪些步骤该做什么、输出长什么样——因为这正是应用本身做分镜的那套专业方法。

> 小提示：技能是"职业手册"，工具是"手脚"。技能负责告诉它怎么做（流程、规范、输出格式），MCP 工具负责真正动手（生成图片、跑工作流）。两者配合，才能做到"说到做到"。

## 全工作区对话直控：不用学复杂节点与参数，所有手动操作一句话搞定

对于新手或不想翻找复杂面板的用户来说，AIArtEngine 最强大的地方在于：**你在界面上手动能做的任何操作，在 AI 对话里直接说人话就能完成。**

无论你当前是在**节点图画布**上，还是已经双击进入了某个 **Dive 下钻工作台**（如 3D 导演台、人像精修、多角度打光、影视工作台、漫画排版、2D 骨骼舞台），AI 都会自动感知你眼前的画面与焦点节点，**无需你报出节点 ID 或专业参数名**：

### 1. 在 3D 导演台（Director Stage）里直接指挥片场

当你进入 3D 导演台 Dive 时，你可以像真导演在片场喊话一样控制每一个演员、道具、骨骼、灯光和机位：

- **显隐与变换**：「隐藏林小满」「把办公桌往右移 0.5 米，旋转 30 度，放大 1.2 倍」
- **全身姿态与表情**：「让林小满换成坐姿（或奔跑/挥手/战斗戒备）」「把她的表情改成开心微笑」
- **手势、视线与 56 根骨骼微调**：「让她右手握拳，抬头往上看」「把男主的左大臂抬高 45 度，头部向右转 20 度」
- **灯光与环境氛围**：「把主光源改成暖橙色，亮度调到 2.5」「环境切换成赛博朋克霓虹夜景，开启地面网格」
- **机位与分镜白模预演**：「切到特写机位，焦距设为 85mm」「把第 2 镜自动摆好白模站位并抓拍构图」

### 2. 在任意 Dive 工作台与 Inspector 里微调深层参数

当你双击进入任意专业工作台或选中某个节点时，直接说出你想改的效果，底层智能补丁引擎会自动将口语转换为精准参数并保护其余设置不被冲掉：

- **人像精修（`image.portrait`）**：「把磨皮调成强烈，瘦脸适中，加一点眼神光」「套用清透日系预设」
- **球面打光（`image.lighting`）**：「切换成伦勃朗光（或黄金时刻）」「主光水平角转到 -45 度，亮度调到 85，打开轮廓光」
- **多角度机位（`image.multiAngle`）**：「机位水平转到右侧 60 度，俯仰角 25 度，景别拉近到特写」
- **情绪罗盘（`image.emotion`）**：「把情绪调成兴奋愉悦（或隐忍愠怒）」
- **合一影视工作台（`film.workbench`）**：「把第 2 镜的动作改成『林小满收起雨伞奔向巷口』，音效改成急促脚步声」「把角色设定里林小满的服装改成黑色机能风衣」
- **漫画页排版（`comic.page`）**：「套用四格漫画模板，阅读顺序改成从右到左，把第一格的标题改成『黎明』」
- **10 合 1 图像处理（`image.process`）**：「裁剪比例切成 16:9」「高清放大改成 4 倍超清模式」

### 3. 在画布上编排节点、打组与自动排版

- 「在画布上新建一个球面打光节点和一个精修节点，把它们连起来」
- 「把刚才这两个节点打成一组，组名叫『女主光影精修』，然后帮我自动排版整张图」
- 「把主光源节点锁住，标题改成『夕阳逆光』」

## 会话管理：像微信聊天一样简单

- **多轮对话**：它记得上下文，可以连续修改、追问，不用每次重讲需求。
- **新建会话**：右上角可以开新对话，互不干扰。
- **删除会话**：删掉一条，历史和它在磁盘上的记忆都会一并清除，不会"诈尸"恢复。

## 万一不顺怎么办（自查清单）

| 现象                        | 原因与解法                                                                                                                                                      |
| --------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 面板提示"未检测到运行环境"  | 应用已内置 Node.js 运行时与 dsh 运行体（内置 Node 由 Electron 二进制以 ELECTRON_RUN_AS_NODE 模式提供），无需安装系统 Node；如仍出现该提示，请检查应用安装完整性 |
| 提示"请先配置模型"          | 到设置里给任一服务商填好 Key 并启用                                                                                                                             |
| 它一直说"工具不可用"        | 确认设置中已开启「MCP 工具服务」开关                                                                                                                            |
| 生成大任务（3D/视频）很慢   | 正常——这种任务本身耗时长，进度卡片会告诉你它还在跑，耐心等即可                                                                                                  |
| 选了 Ask 模式后它仍想动手   | 符合预期：Ask 模式下应用的创作工具（生成 / 改工程 / 跑任务）已被整体禁用，它只能靠文字回答。想让它动手就把面板模式切到 Craft，或切到 Plan 先让它出方案          |
| Plan 模式下它说"需要先确认" | 也符合预期：Plan 在用户确认计划前只能读、不能改也不能生成。看它给的方案，选「继续」它就会在同一轮里开工                                                         |
| 答非所问                    | 检查是否选错模型，或把需求说得再具体些                                                                                                                          |
