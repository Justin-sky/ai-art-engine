# AI 对话：像跟同事聊天一样，指挥你的 AI 创作流水线

> 你负责想，它负责干。这是 AiArtEngine 内置的 AI 对话助手——一个真正**会调用工具干活**的创作搭子，而不是只会打字的聊天框。

## 先记住一句话

别的 AI 工具，聊完天你得自己把话翻译成操作：复制提示词、找模型、拖节点、调参数。

AIArtEngine 的对话助手不一样——**你只管说，它直接动手**：

- 你说「给产品出一张赛博朋克主视觉」，它就去调图像模型，把图生成到你的工程里；
- 你说「把这张图转成 3D 白模，扔进导演台」，它就去建 3D 资产、把节点图连好；
- 你说「用可灵把主视觉做成 15 秒广告」，它就调度视频模型，把成片素材送进时间线。

图、3D、视频、工作流、任务执行……**全在同一个窗口里，用一句话串起来**。这就是本应用把 DeepSeek Harness（业界前沿的 AI Agent 运行时）集成进来带来的能力：一个懂美术、会操作软件的全能助手，住进了你的软件里。

## 使用前，只需要两件事

1. **打开一个工程**（或者新建一个）。有工程它才能在里面帮你干活；不打开工程就只能闲聊。
2. **配置一个文本模型**：设置 → 模型接入 → 任一服务商填好 API Key 并启用即可（DeepSeek 官方体验最佳）。

都准备好了？打开侧边栏底部的 **◈（AI 对话）**，开始。

> 首次使用时，助手会做一次"体检"：检查运行环境、模型是否就绪、工作区是否打开。缺什么都会用大白话提示你，照着做就行，不用懂技术。

## 三步上手：跟 AI 对话面板聊天

### 第 1 步：选好你的"大脑"

面板顶部选择一个文本模型。下拉列表里已经按你配置的服务商整理好了，选一个今天想用的即可——比如 DeepSeek。

### 第 2 步：@ 引用素材（可选，但强烈推荐）

想让 AI 基于某张图/某段视频创作？在输入框里输入 `@`，会弹出工程里的资产列表，点选即可。引用会显示成带缩略图的小卡片，AI 一眼就知道你要用哪个素材。

### 第 3 步：用人话下需求，发送

试着说：

> **@参考图 给产品出一张赛博朋克风格的主视觉，深色调、霓虹光**

发送后，你会看到它：
1. 折叠展示一段"思考过程"（它在想怎么拆解你的需求）；
2. 弹出工具卡片，显示它正在调用哪个能力、进度如何；
3. 完成后把结果（图片）直接存进工程资产库，你可以马上在资产面板看到它。

## 它自带一套创作技能，不用学就会用

对话助手不只是会聊天，它**天生带着一套"美术职业能力"**，也就是创作技能。这些技能来自应用内置的导演台/分镜工作台能力（GraphSkill），每次对话启动时自动注入助手的大脑，随叫随用：

| 技能分类 | 代表技能 | 一句话说明 |
|----------|----------|-----------|
| **分镜 / 动画** | 分镜师 · 9宫格分镜表、节拍拆解表、动态提示词表、4宫格动态分镜表、9宫格动态提示词表 | 把剧本拆成画面：节拍、机位、运动、提示词一步到位 |
| **导演审核** | 导演审核 · 9宫格分镜表、节拍拆解表、动态提示词表 | 以导演视角审查分镜与节奏，给出修改意见 |
| **系统创作** | 剧本、图生提示词、图片生成、视频生成、声音、情绪、灯光、多角度、扩图、重绘、抠图、高清放大、界面图、界面拆分、世界提取、节拍拆分、节拍单元生成、策划案、肖像贴图、提示词优化、擦除 | 单点能力，专门对付某一个创作动作 |

这些技能**不用配置、不用安装**：应用内置，对话时自动就位。你可以直接说：

> 「用分镜技能，把这段剧本拆成 9 宫格分镜表」

助手就会调出对应的分镜技能，按专业流程（节拍 → 机位 → 动态 → 提示词）产出结果，而不是凭空瞎编。它知道哪些步骤该做什么、输出长什么样——因为这正是应用本身做分镜的那套专业方法。

> 小提示：技能是"职业手册"，工具是"手脚"。技能负责告诉它怎么做（流程、规范、输出格式），MCP 工具负责真正动手（生成图片、跑工作流）。两者配合，才能做到"说到做到"。

## 高频玩法：这些场景一句话就能搞定

| 你想做的事 | 就这么说 |
|------------|----------|
| 出图 | 「@参考图 基于这张图出 4 张不同风格的设定图」 |
| 视频 | 「用可灵把这张主视觉变成 15 秒产品广告，写实风格」 |
| 3D 白模 | 「把这张图转成 3D 白模，扔进导演台摆好」 |
| 规划工作流 | 「用短剧分镜模板规划一条『剧本→分镜→竖屏成片』的工作流并保存」 |
| 执行与检查 | 「运行刚才那条工作流，完成后告诉我结果」 |
| 素材整理 | 「把工程里所有 3D 资产列出来，按文件名排序」 |
| 多轮修改 | 生成后直接说「太亮了，压暗一点」/「换个科幻风格再来」 |

> 小提示：说得越具体，结果越准。把用途、风格、尺寸、参考素材一次说清，它基本能一次到位。

## 会话管理：像微信聊天一样简单

- **多轮对话**：它记得上下文，可以连续修改、追问，不用每次重讲需求。
- **新建会话**：右上角可以开新对话，互不干扰。
- **删除会话**：删掉一条，历史和它在磁盘上的记忆都会一并清除，不会"诈尸"恢复。

## 万一不顺怎么办（自查清单）

| 现象 | 原因与解法 |
|------|-----------|
| 面板提示"未检测到运行环境" | 本机需要 Node.js 22.19 及以上（首次也会自动尝试内置运行体，实在不行按提示装一下） |
| 提示"请先配置模型" | 到设置里给任一服务商填好 Key 并启用 |
| 它一直说"工具不可用" | 确认设置中已开启「MCP 工具服务」开关 |
| 生成大任务（3D/视频）很慢 | 正常——这种任务本身耗时长，进度卡片会告诉你它还在跑，耐心等即可 |
| 答非所问 | 检查是否选错模型，或把需求说得再具体些 |
