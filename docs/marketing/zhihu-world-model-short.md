# 一张图，五分钟，变成一个能走进去的世界

> **利益相关**：**AIArtEngine** 是我参与开发的开源项目（GPL-3.0），安装包在本仓 GitHub Release 直接下载，无推广链接。
> 先把丑话说前面：**要花 World Labs 的 API 积分，单次生成约 5 分钟**，不是几十秒。

---

## 三十秒说清它解决什么

你拿一张概念图给人看，对方第一反应永远是同一个问题：

> **「那……转过去是什么样？」**

图的天花板就在这 —— **它只有一个视角**。以前只能靠美术再画三张，或者建模师做几天。

现在给一张图，五分钟，返回一个**能自由转视角、能往里走**的空间。

**但它不只是能看。** 大多数世界生成止步于"进去转两圈、截图、关掉"；这里的重点是**世界是上游**：导出成网格后直接进 3D 导演台摆机位、走位、录运镜 —— **生成出来的世界，成了你的拍摄场地。**

---

## 三步上手

### ① 把图拖进节点图

新建节点图，把那张图拖上去。

### ② 加「空间世界生成」

画布右键 → **「空间世界」** 分组 → 空间世界生成。把图接到 `Image` 口。

它接四种输入（互斥）：**文本 / 单图 / 最多 4 张同场景多图 / 一段视频**。**同时给视频和图片时以视频为准。**

三个开关值得注意：

- **随机种子** —— 想复现必须固定它
- **全景判定** —— 你那张图若是 2:1 等距柱状全景，**一定要让它走全景判定**，空间信息完整，结果通常明显更准
- **按原文** —— 不勾的话上游会**自己替你补描述**，所以同一张图跑两次结果可能不同

模型四档：日常用 **Marble 1.1**；要**更大的世界**（户外 / 大型室内）用 **1.1 Plus**（更费积分）。

点运行，**约 5 分钟**。

### ③ 加「空间世界导出」—— 这步不能跳

生成完拿到的是**世界**，不是模型。想接导演台，接口会**拒绝**你：

> `spatialWorld` 端口**只连 `spatialWorld`，不隐式兼容 `model`**。

这不是缺陷，是故意的：**模型是一个物体，世界是一个空间**，各有坐标系和尺度，让它们隐式互换才是真坑。

所以中间插「空间世界导出」，它把世界**变成模型**，从这一刻起才进入可编排的世界。

导出两种模式，**计费差别很大**：

| 模式             | 用途                               | 计费                            |
| ---------------- | ---------------------------------- | ------------------------------- |
| **网格（默认）** | 接导演台 / 3D 加工，按模型资产登记 | 异步最长约 1 小时，**单独计费** |
| 高斯泼溅         | PLY，留给外部工具                  | 同步                            |

> **省钱关键**：只想进去看看，**根本不用导出** —— 世界生成时**随包免费返回**的 `*.spz` 泼溅（约 200 万 splats）**已经能直接逛**了。要拍东西才走「网格」。

## 进去之后

导演台里 **中键平移、右键环视 / 第一人称飞行（WASD）** 自由移动；视口灵敏度五项全部可调，滑块在底部工具栏，拖动即时生效。

泼溅是**普通 `Object3D`**，能像别的物体一样**选中、变换、显隐**。

一键工作流里有现成预设：**世界模型**（世界生成 → 导出 → 导演台 → 选站位 → 漫游成片）。内置 MCP 工具 **`generate_world`** 还能让 Claude Code 这类 Agent 直接调。

---

## 说点不好听的

1. **约 5 分钟、无实时预览** —— 不适合当草稿工具。正确用法：**先在出图环节把画面定死**，最后一步再生成世界
2. **要充 API 积分** —— 注意 **API 积分与 Marble 应用积分分开计费**，去 `platform.worldlabs.ai/billing` 充
3. **本地参考图默认上传** World Labs 托管存储（好处是不用配对象存储，代价是素材出本机）
4. **PLY 在应用内没有预览通道**，不登记为资产

## 怎么开始

1. 本仓 GitHub Release 下载（Win / macOS / Linux）
2. 设置 → 模型 → 添加 **World Labs（Marble）**，填 API Key
3. 充 API 积分
4. 有张图，或者想清楚一句描述

**不想花钱也能先试**：接本地 ComfyUI 或你自己的图片模型先把图磨出来 —— **软件这半边是免费、本地、开源的**，钱只花在真正调用云模型那一刻。
