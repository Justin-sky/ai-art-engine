## 一、5 分钟看懂「万游之源」：5 个节点搭出一切游戏机制

不管你的游戏是修仙渡劫、赛博朋克卡牌、还是模拟经营，剥掉美术皮囊之后，底层永远只有 **5 种核心节点 + 2 种连线**：

| 节点类型                           | 图标语义          | 游戏里的对应物                           | 核心作用                                 |
| :--------------------------------- | :---------------- | :--------------------------------------- | :--------------------------------------- |
| **产出源（Source）**               | 🔺 水龙头         | 每日签到、刷怪掉落、随时间回蓝           | 源源不断向系统注入资源（Faucet）         |
| **资源池（Pool）**                 | ⭕ 储水池         | 金币袋、角色血量 HP、经验槽、护盾        | 存储当前拥有的数值，可设初始值与容量上限 |
| **转化器（Converter）**            | 🔀 加工厂         | 铁匠铺合成、消耗经验「三选一升级」、抽卡 | 吃掉上游资源，按比例产出了下游新资源     |
| **回收漏斗（Drain）**              | 🔻 下水道         | 商店扣费、受到怪物伤害扣血、装备耐久损耗 | 把资源从系统里销毁回收（Sink），抑制通胀 |
| **寄存器 / 门（Register / Gate）** | 🧮 算盘 / 🎲 骰子 | 暴击率判定、波次难度倍率公式、随机掉宝   | 用公式计算动态倍率，或按概率分发资源     |

再加上两条线，整个游戏就活了：

- **实线（资源边 Resource）**：代表「真金白银的流动」，比如从 `刷怪` 每步流 `3` 点经验到 `经验池`。
- **虚线（状态边 State）**：代表「规则与控制」，比如：
  - **激活条件（`>=3`）**：只有当 `经验池 >= 3` 时，才点亮「三选一升级」转化器；
  - **增益修正（`+25%` / `+2`）**：每多清一个房间，怪物伤害产出源的速率自动 `+2`。

## 三、第二步：点一下「运行」，让 AI 替你跑 100 局抓出隐藏崩盘点

图画好了，怎么知道这套机制玩起来会不会崩？

点击顶部的 **「▶ 运行模拟」**，切到底部的 **「🩺 经济诊断（Diagnostics）」** 页签。系统会在几毫秒内跑完多轮时序模拟，并给出 **0–100 分的经济平衡健康度评级（S / A / B / C / F）**，同时盯死 4 个核心命门指标：

1. **产出 / 回收比（Faucet / Sink Ratio）**：理想区间在 **`0.8x – 1.5x`**。如果高达 `66x` 甚至 `108x`，说明你的游戏只发钱不回收，玩家三分钟就会因为通货膨胀失去消费目标。
2. **每步净流入（Net Flow / Step）**：每回合全系统净堆积多少资源。
3. **饥饿阻塞次数（Blocked Count）**：自动转化器（如「升级·三选一」）因为上游池子里资源不够而“空转卡死”了多少次。
4. **爆仓封顶 / 枯竭池数（Capped / Depleted）**：有没有哪个资源池早早撞上容量天花板溢出浪费，或者中途归零断档。

更直观的是，诊断面板会把所有隐患翻译成策划一眼能看懂的**告警卡片**：

- `WARN ⚠ 通胀预警: 当前系统无活跃 Sink 回收 (每步净堆积 +12.5)，建议增加 Drain 回收或调高转化消耗`
- `WARN ⚠ 转化器饥饿: 「升级·三选一」因上游资源不足被阻塞 6 次 (占比 67%，首现于第 1 步)`
- `WARN ⚠ 指数失控: 「累计受伤」后半程增速为前半程的 2.6 倍 (终值 48)，存在数值膨胀风险`

## 四、第三步：哪里亮黄灯点哪里！「⚡ 一键修复」与「🎯 智能调参」

以前看到这些警告，你得自己回画布上一根根改公式、连状态线、再重跑对比。
现在，每条警告卡片右侧都直接配好了两个“外挂级”按钮 —— **「⚡ 一键修复」** 和 **「🎯 智能调参」**，右上角还有 **「⚡ 一键修复全部」**！

### 1. 点击「⚡ 一键修复」，它在底层帮你做了什么？

它绝不是简单粗暴地屏蔽警告，而是像一位资深数值主策一样，自动修改你的拓扑结构并做**闭环模拟验算**：

- **修「转化器饥饿」**：
  自动检测上游资源池（如 `经验池`）到转化器（如 `升级·三选一`）的消耗阈值（比如需要 `3` 点经验），自动补齐一条 **`>=3` 的虚线状态激活边**；如果同一个池子同时喂给多个自动节点，还会自动把出边切换为 `instant` 瞬时传输防止抢占死锁。修完后，转化器平时安静待机，一攒够 3 点经验立刻精准触发，**饥饿阻塞直接降为 `0` 次**！
- **修「通胀预警 / 无 Sink 回收」**：
  自动识别全图净堆积最大的非生命值资源池（比如不断暴涨的 `金币池`，绝不会误删玩家的 `角色血量 HP`），按当前每步净流入速率自动挂载一个 **`维护费回收（Upkeep Sink）` Drain 节点**，把产出/回收比精准拉回 `1.0x–1.4x` 的黄金区间。
- **修「指数失控（如累计受伤后半程暴涨 2.6 倍）」**：
  不会傻傻地给池子加个容量上限（那会导致新的「容量爆仓」警告），而是智能分析失控根源：
  - 如果是**复利自激环**（池子自身向外发出了 `+35%` 状态边），自动按比例收敛正反馈增益；
  - 如果是**波次递增入边**（如后期怪物伤害陡增），自动根据前半程平稳流速为入边设置平滑单步上限 `maxLimit` 或步数阻尼 `1 + step * k`；
  - 并在写入前自动用下一轮随机种子跑一遍完整模拟，确保**指数失控彻底消失、不衍生任何爆仓或枯竭副作用、健康分直冲 `S (100/100)`**！

### 2. 想精细微调？点「🎯 智能调参」开启反向求解（Goal-Seek）

如果你想保留自己设计的拓扑结构，只想知道**“把怪物掉落率或商店税率调到多少，经济最平衡”**：

1. 点击任意警告右侧的 **「🎯 智能调参」**；
2. 面板会自动跳转到 **「自动配平与扫描（Auto-Balancer）」** 页签，并自动帮你选中导致该警告的**罪魁祸首变量**（比如那条掉落边速率、或某个全局参数 `wave_scale`）；
3. 优化目标默认锁定为 **「🩺 经济健康度最高分 (0–100)」**（也可以切换为指定池子的终值、均值或峰值）；
4. 系统会在搜索区间内自动跑完几十组参数扫描，直接告诉你最优解（例如 `最优值: 6.5 → 达成健康度: 100 分`），点一下 **「一键应用最优值」** 即可写回画布！

## 六、策划避坑指南：最容易把游戏写崩的 4 个反模式

我们在开发这套诊断引擎时，总结了新手设计游戏机制最常踩的 4 个深坑（现在软件都会自动静态拦截并支持一键修复）：

1. **❌ 坑 1：把「扣血伤害」连成了向「生命池」注入资源**
   - **错误画法**：`怪物攻击（Converter） ──实线──> 角色生命 HP（Pool）`。这在流量图里代表“怪物打你一拳，你的血量反而增加了”！
   - **正确画法**：扣血永远是 **`角色生命 HP（Pool） ──实线──> 受伤扣血（Drain）`**，由怪物攻击通过虚线触发或控制那条 Drain 边的速率。
2. **❌ 坑 2：自动转化器不加「`>=阈值`」状态激活门控**
   - **后果**：转化器每回合都尝试强行抽水，抽不到就记一次饥饿阻塞，还会把共用的上游池子抽成半死不活的碎片。
   - **正确做法**：凡是消耗 `N` 点资源的自动转化器，养成习惯从上游池拉一条 **`>=N`** 的虚线状态边过去。
3. **❌ 坑 3：只有水龙头（Source），没有下水道（Drain）**
   - **后果**：玩家手里的金币从第 5 回合开始变成一串毫无意义的数字。
   - **正确做法**：每设计一个产出源，必须配套设计至少一个消耗漏斗（商店刷新费递增、高阶合成损耗、或者按比例回收的维护税）。
4. **❌ 坑 4：正反馈闭环不加阻尼（复利滚雪球）**
   - **后果**：`金币越多 → 利息越高 → 金币更多`，10 回合内必崩。
   - **正确做法**：给正反馈入边加上 **`maxLimit`（单回合收益上限，比如最多吃 5 金币利息）**，或者用 `diminish()` 边际递减函数。
