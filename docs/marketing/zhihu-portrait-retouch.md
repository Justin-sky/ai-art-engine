## 一、先说结论：两个我想重点说的点

### 传播点 1｜修图这件事，不该按张付费

在线 AI 修图服务（像素蛋糕这类）的基本形态是：**你把照片传上去，它按张/按会员收钱**。这个模式本身没问题——云端算力、开箱即用、手机就能用，值这个钱。

但如果你**手上已经有图片模型**（买了即梦/Seedream 的额度、开通了 Gemini/OpenAI、或者本机跑着 ComfyUI），那你其实已经为「出图」付过一次钱了。这时候再为「调参数」这件事按张付费，就是**同一笔算力买两次**。

AIArtEngine 的人像处理走的是另一条路：**软件的活归软件**。参数在本地，合成提示词，然后**调用你自己配的那个图片模型**出图。修一张图的边际成本就是你那次模型调用的成本；如果你想让它等于零，就接**本地 ComfyUI**，全程不花钱。

再加上流水线能力，这个差价的量级就出来了：上游一次接 **24 张**，同一套参数逐张跑完——**调一次参，出 24 张**。

> 一句话版本：**出图的钱，只花在模型上一次；重复劳动交给流水线。**

### 传播点 2｜你的脸，不必先上传给谁

人像是最敏感的一类照片。很多人拒绝在线修图，理由不是贵，是**不想把自己的脸传到别人服务器上**——尤其是「AI 换背景」「智能消除」这类功能，一听就是照片要离开本机。

这个人像处理节点里，两件事是分开的：

- **看脸这件事，在本机做**。人脸关键点用的是一套本地小模型（BlazeFace 检测 + FaceMesh 468 点），**随安装包内置、开箱即用、不联网**。它决定「哪些工具能用在脸上、脸的范围在哪」。
- **出图这件事，交给谁由你选**。你接哪个模型、照片发给谁，是你在设置里决定的；接**本地 ComfyUI** 就全程不出本机。

更关键的是第三点：**发给模型的提示词是公开的**。编辑器里直接显示这轮要发出去的原话，可以复制、可以自己再加一句「保留皮肤毛孔纹理」。不是一堆黑盒滑杆——**你始终能看到它对你的脸做了什么。**

> 一句话版本：**人脸分析在本机，出图给谁你说了算，而且整个过程你能看到原话。**

## 二、它到底是什么：节点图上的一个「人像处理」节点

不是网页、不是小程序，是一个**桌面端应用**（Windows / macOS / Linux）。安装包装完打开，你会看到一张节点画布——所有功能都是节点，连线即流程。

**人像处理节点（`image.portrait`）** 是其中「图片精修」分组里的一个节点：

- **双击节点卡片**进入精修编辑器；
- 编辑器左边是画面，右边是参数面板，顶部是**横向铺满的 14 组工具**；
- 所有参数实时写回节点，关掉再打开不会丢。

| 分组   | 里面有什么                                                                          |

每一档都是 **`关闭 / 轻 / 标准 / 强 / 极强`** 五档分段按钮——这是小白最需要的设计：**不需要懂数值，只要会说「轻一点」。**

## 三、小白三步上手

### 第一步：装 + 接一个图片模型

装好应用后，先去设置里接一个**图片模型**。已经买了哪家的额度就用哪家：

- 即梦 / Seedream、Gemini、OpenAI、OpenRouter、自建 NewAPI 这类线上接口；
- 或者**本机 ComfyUI**（想完全免费、且照片不出本机就选它）。

> 这一步决定了效果上限。人像建议用擅长人像/写实的模型，不要拿一个只擅长二次元的模型去修证件照。

### 第二步：拖进图片，双击「人像处理」节点

上游接一张图（或一次接多张，见第九节），双击节点卡片进入编辑器。

### 第三步：挑一套预设，然后只微调「轻一点 / 强一点」

右侧面板顶部有 **12 套内置预设**：自然 / 写真 / 新娘 / 儿童 / 证件照 / 港风 / 通透 / 质感 / 胶片 / 黑白 / 复古 / 舞台。挑一套接近你想要的，然后：

- 觉得假 → 把重的那几档往下调一档（比如「磨皮」从「极强」调回「标准」）；
- 觉得不够 → 往上调一档；
- 想再加点氛围 → 「调色」里挑一款滤镜。

调完按 **保存并出图**。这里有个我很喜欢的细节：**它不会关窗**。按钮上转圈显示进度，失败了原因直接留在窗口里，跑完**左边画面自动换成产物**——你可以立刻和出图前那张对比。

【配图建议：12 套预设的一排缩略图 + 出图前后对比】

## 四、不懂参数怎么出片：五档 + 12 套预设

小白最容易踩的坑是「把每一项都拉满」，结果脸磨成塑料、下巴推到变形。给三条实践经验：

1. **一次只动 1~2 组**。先修脸（修复 + 磨皮 + 肤色），再看形体（五官 + 身形），最后补氛围（光影 + 调色 + 质感）。
2. **「轻」的档位比你想的更有用**。人像修饰的原则是「别人看不出你修了」，大多数场景 `轻` 和 `标准` 就够了。
3. **颗粒 / 柔焦 / 暗角是「防塑料味」的三件套**。磨皮之后加一点颗粒或柔焦，皮肤会立刻不那么假。这一点很多在线工具的一键美颜做不到——它只会把脸磨平。

预设不只是起点，也是**可分享的**（见第十节）。

## 五、为什么磨皮不再连衣服一起糊：「只处理对应部位」

这是我觉得**比滑杆数量重要得多**的一件事。

图片模型的接口里**没有蒙版通道**，一次调用一定是「重绘整张图」。于是常见翻车现场就是：你只想磨个皮，结果衣服纹理、背景细节全被重画了一遍；你只想瘦个脸，结果背景里的直线跟着扭。

这里的做法是：**让模型整张出图，然后按范围把结果贴回原图**——不是请求的部位，保持原图像素不变。

- 需要修脸（修复 / 磨皮 / 肤色 / 五官 / 眼睛 / 妆容 / 光影 / 质感）→ 只把**脸和脖子**的区域贴回；
- 需要改身形 → 只把**人物**的区域贴回；
- 你画的区域框 → 一并算进去；
- 而**换背景、证件照、调色**属于整图语义 → 自动按整图处理（只贴局部反而会把全局效果裁掉）。

开关在「区域」组顶部，**默认开着**。缺人脸模型或分割模型时，对应那一块会退回整图，并在运行日志里写明原因——不静默降级。

【配图建议：同一张图开/关这个开关的对比，重点圈出衣服与背景】

## 六、只想改一处：在画面上拖一个框

「区域」组里可以直接在画面上拖框，一次画一个，画完选类型：

**瑕疵修复 / 磨皮提亮 / 肤色提亮 / 形体收窄 / 换背景 / 消除杂物**。

框的位置会翻译成「画面左上的小块」这类方位语写进提示词——所以模型知道你说的是**哪一块**。

用法举例：

- 只想修右脸的痘印 → 画一个框，选「瑕疵修复」；
- 只想给眼睛下方提亮 → 画一个框，选「肤色提亮」；
- 路人入镜 → 画在他身上，选「消除杂物」，再补一句说明。

## 七、怕修坏？按住就对比，或者拖中缝

- **`⇆ 对比原图`**：按住不动，画面切成上游原图，松手回到当前效果——快速看「我到底改了多少」。
- **`◐ 分割对比`**：画面中间一条分割线，左原图右效果，**中缝可以拖动**，想细看哪儿就拖到哪儿。这条线铺满整个画面，且不随缩放变粗变细。
- **滚轮缩放 / Shift+滚轮或 `[` `]` 旋转 / 空格拖拽平移**，方便检查眼角、发丝这些细节；
- **撤销重做**照常，参数改错了 Ctrl+Z 就回来了。

【配图建议：GIF——拖中缝对比、按住看原图】

## 八、证件照：10 种规格 + 5 寸相纸拼版

这块单独说，因为它是最刚需、也最容易省钱的场景。

- 内置 **10 种规格**（一寸 / 小一寸 / 大一寸 / 两寸 / 小两寸 / 护照 / 签证 / 驾照 / 社保卡 / 自定义）；
- 三种标准底色（白 / 蓝 / 红）+ 渐变；
- 出图时**按规格精确裁切**，头肩比例不对会重裁；
- 还能直接**铺成 5 寸相纸拼版**，拿去冲印店按 5 寸相纸打，一次就是一版。

配合「背景」组的纯色/渐变换底，流程就是：**拍一张 → 换底 → 选规格 → 拼版 → 出图**。证件照的钱，从此只在冲印那一步。

【配图建议：一张普通自拍 → 证件照规格 + 5 寸拼版的成品图】

## 九、批量出片：一次调参，24 张一起跑

这是「按张付费」和「流水线」差距最大的地方。

在节点图里，把**多张图片接到同一个「人像处理」节点**（一次最多 24 张），然后：

1. 在编辑器里把参数调到你满意（只调一次）；
2. 保存并出图；
3. 它会按同一套参数**逐张**跑完，每张都会先做局部回贴、证件照规格再各自裁切；
4. 人脸关键点按每张图的指纹缓存，同一张图重复跑不会重复检测。

典型场景：**一组写真**、**一组电商模特图**、**全班同学的证件照**、**同一天拍的婚礼选片**。手工修是几小时的活，这里是「点一次，等它跑完」。

【配图建议：节点图上 6 张图接进一个节点 → 输出的缩略图墙】

## 十、把自己的「配方」发给别人

调好的一套参数可以**导出成 JSON**，别人导入即用。这意味着：

- 影楼里老板调好一套「婚纱通稿」，全组导进去，出来的风格是统一的；
- 你可以把自己的「港风写真配方」发给粉丝；
- 换电脑、换项目，参数跟着走。

比起「每张图重新调一遍滑杆」，这是完全不同的工作方式。

## 十一、和像素蛋糕怎么选（说实话）

先把话说清楚：**像素蛋糕（以及同类在线 AI 修图服务）是很成熟的产品**，它的强项是「零配置」——打开网页/App，传图，点一键美颜，手机就能用。**你没买图片模型额度、也不想折腾**，用它最省事。

我做的事情不一样，适合的是另一类人：

| 维度         | 像素蛋糕这类在线服务              | AIArtEngine 的人像处理                                            |
| ------------ | --------------------------------- | ----------------------------------------------------------------- |
| 计费         | 按张 / 按会员（云端算力包含在内） | 软件免费开源；出图只花**你自己模型**的钱（接本地 ComfyUI 则为 0） |
| 照片在哪     | 上传到它的云端                    | 人脸分析在**本机**；出图传给哪个模型由你选（可全本地）            |
| 一次多张     | 通常单张处理                      | 一个节点接 **24 张**，同一套参数跑完                              |
| 参数透明度   | 黑盒滑杆                          | 显示**发给模型的原话**，可复制、可自己加约束                      |
| 与其它流程串 | 处理完下载，再手工接下一步        | 节点图上直接串（裁剪 / 拼版 / 视频 / 批量出片）                   |
| 上手成本     | **几乎为零**，这是它最大的优势    | 需要装桌面端 + 配一个图片模型（约 5 分钟）                        |
| 手机端       | 有                                | **没有**，桌面端（Windows / macOS / Linux）                       |

**怎么选**：

- 偶尔修一两张、手机上完成、不想配模型 → 用在线服务；
- 一次几十张、想统一风格、在意照片去向、或者手上已经有模型额度 → 试试这条流水线。

## 十二、常见问题与避坑

**Q：一定要自己配模型吗？**
A：要。这也是它便宜的原因——应用本身不做「按张收费的云端算力」，出图完全走你配的模型。

**Q：人脸模型要额外下载吗？**
A：不用，随安装包内置（检测 + 468 点关键点），离线可用。真缺了也不会出错：依赖人脸的 7 组会**置灰**，悬停提示与参数面板会告诉你缺什么，不会让你白调半天。

**Q：为什么「换背景」没有被限制在局部？**
A：换背景、证件照换底、调色都是**整图语义**。只贴局部会把你要的全局效果裁掉，所以这几项自动按整图处理——这是刻意的取舍。

**Q：效果不如预期怎么办？**
A：先看三件事：① 模型选得对不对（人像别用二次元模型）；② 档位是不是拉太满（回到 `标准` 试试）；③ 出图失败的原因**会留在编辑器窗口里**，照着改就行，不用去翻日志。

**Q：能商用吗？**
A：应用本身开源（GPL-3.0）。出图的版权与合规取决于**你用的那个模型**的服务条款，请按你接入的供应商规则来。YOLO 系内置模型是 AGPL-3.0，商用前请自行评估。

## 最后：怎么开始

1. 去 GitHub 下载安装包：<https://github.com/Justin-sky/ai-art-engine/releases>（Windows / macOS / Linux）；
2. 设置里接一个图片模型（有 ComfyUI 就接本地）；
3. 拖一张人像进去 → 双击「人像处理」→ 挑一套预设 → **保存并出图**。

如果这篇对你有用，欢迎回来告诉我：**你最想让它自动化的那一步是什么**——是批量证件照、还是「把一套风格套到 100 张图」？评论区说，我按需求排下一版。

> 补充一句：这套东西是开源的，装完你可以在自己的机器上验证本文提到的每一句话——**包括它到底把你的照片发给了谁**。
