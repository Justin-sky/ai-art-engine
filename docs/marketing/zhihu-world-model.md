# 一张照片，五分钟，变成能走进去的世界：我把「世界模型」接进了节点图

> **利益相关**：本文介绍的 **AIArtEngine** 是我参与开发的开源项目（GPL-3.0），安装包直接在本仓 GitHub Release 下载，没有推广链接。
>
> 另外先把丑话说前面：**世界模型不是免费的**，要走 World Labs 的 API 积分；单次生成**约 5 分钟**，不是几十秒。这两条在下面「说点不好听的」一节里展开写。
>
> 我不吹效果。Midjourney 比我好看，Runway 比我快，Marble 官方站点比我省事。这篇文章讲的是**流程**：当你手上已经有一张图，怎么让它在五分钟里变成一个**可以走进去、并且能立刻拿去拍东西**的空间。

## 一、先说结论：两个真正的变化

### 传播点 1｜从「一张好看的图」到「一个能进去的地方」

过去两年，AI 出图的进步是**像素级**的：更清晰、更准、更有风格。

但图有个天花板：**它只有一个视角**。

你拿一张概念图给美术、给导演、给客户看，所有人的第一反应都是同一个问题——

> **「那……转过去是什么样？」**

这个问题以前只有两个答案：要么靠美术再画三张，要么靠建模师做几天。

现在有了第三个答案：**让它自己长出来**。给一张图，五分钟，返回一个可以自由转动视角、可以往里走的空间。

### 传播点 2｜生成完就能用，不是只能看

这一点是我想重点说的，也是最容易被忽略的。

大多数「世界生成」的体验止步于**观看**：你进去转两圈，觉得很酷，截图，关掉。它是个 demo。

我这次接进节点图里，**重点根本不在"能看"，而在"能接着干活"**：

世界不是终点，它是**上游**。它可以导出成网格，接进 3D 导演台摆机位、走位、录运镜——**这个"生成出来的世界"直接成了你的拍摄场地**。

> 一句话版本：**以前是"生成一个东西给你看"，现在是"生成一个场地给你拍"。**

## 二、它到底是什么：节点图上的「空间世界生成」

先破一个误解：这不是"把图片加个 3D 滤镜"。

它背后是 **World Labs 的 Marble** —— 李飞飞团队的 3D 世界模型。你在节点图上加一个 **「空间世界生成」** 节点，它能接受**四种输入**（官方叫 `world_prompt`，四选一，互斥）：

| 输入           | 说明                          | 什么时候用                   |
| -------------- | ----------------------------- | ---------------------------- |
| **文本**       | 直接描述你想要的世界          | 从零开始，没有素材           |
| **单图**       | 一张参考图                    | **本文主题**：你手上有一张图 |
| **多图同场景** | 最多 **4 张**同场景的不同视角 | 你有多角度参考，空间关系更准 |
| **参考视频**   | 一段视频                      | 你有现成素材，想要它的空间   |

几个实测出来的**细节**，都是会直接影响成功率的：

- **同时给了视频和图片时，以视频为准**（与项目里「对口型」同口径）。别指望它俩叠加。
- **参考视频推荐 mp4 / webm / mov / avi，单条不超过 100MB** —— 这是上游的硬限制，超了直接失败。
- **单图可以标「这是全景图」**：官方参数 `is_pano`，我做成三档（自动识别 / 强制 / 关闭）。**如果你那张图是 2:1 的等距柱状全景，一定要让它走全景判定** —— 全景图带着完整的空间信息，出来的世界通常明显更准。自动档会认 2:1 这类比例。
- **默认它会"替你写描述"**（上游 recaption）：你不给指令时，它会自己补一段画面描述。所以**同一张图跑两次，结果可能不一样**。要可复现就勾上「按原文」+ **固定随机种子**。

## 三、三步上手：一张图 → 一个能走的世界

### 第 1 步：把图放进节点

新建节点图，把那张图拖上去（或者接到生成节点的 `Image` 口）。

### 第 2 步：接「空间世界生成」

从画布右键菜单的 **「空间世界」** 分组里加这个节点，把图接到它的 `Image` 口。

模型有**四档**，我按用途分了三类：

| 档位                   | 适合                                             |
| ---------------------- | ------------------------------------------------ |
| **Marble 1.1**         | 标准世界尺寸，日常用这个                         |
| **Marble 1.1 Plus**    | **更大的世界**：户外或大型室内空间。消耗更多积分 |
| Marble 1.0 / 1.0 Draft | 上一代，上游仍支持，**后续版本会移除**，只作兼容 |

要微调就三个开关：**随机种子**（0 = 交给上游随机）、**全景判定**、**按原文**。

点运行。**约 5 分钟**。

### 第 3 步：……先别急着看，中间还得插一个节点

这一步是必须的，很多人第一次会卡在这。

## 四、关键的那一步：为什么中间必须有个「导出」节点

生成完，你会得到一个 **`spatialWorld` 类型的产物**。

它不是模型 —— 它是**世界**：带着一个 `world_id`（世界的身份证），以及三样东西：

| 产物                 | 说明                                  | 计费               |
| -------------------- | ------------------------------------- | ------------------ |
| **GLB 网格**         | 粗网格，10–20 万面                    | 含                 |
| **`*.spz` 高斯泼溅** | 约 200 万 splats，**Marble 原生格式** | **随世界免费返回** |
| **360° 全景图**      | 2560×1280 等距柱状                    | **随世界免费返回** |

这时候你想把它接给导演台——**接口会拒绝你**。

因为在这个项目里，**端口类型是严格同类型的**：`spatialWorld` 只连 `spatialWorld`，**不隐式兼容 `model`**。

这不是我在为难你。恰恰相反，这是我的**故意设计**：

> **一个"世界"和一个"模型"不是一回事。**
> 模型是一个物体，可以摆、可以缩放、可以拼。
> 世界是一个**空间**，它有自己的坐标系、自己的尺度。
>
> 让它们隐式互换，就等于允许你在不自知的情况下把"整个世界"塞进一个"物体"的位置——**那才是真正会让人踩坑的地方。**

所以中间要加 **「空间世界导出」** 节点：它把世界**变成一个模型**，从这一刻起，它才进入"可继续编排"的世界。

导出有两种模式：

| 模式             | 产物                                                                   | 用途                                     | 计费                                                      |
| ---------------- | ---------------------------------------------------------------------- | ---------------------------------------- | --------------------------------------------------------- |
| **网格（默认）** | HQ 网格 → GLB，可选**带贴图**（约 60 万面）或**顶点色**（约 100 万面） | 接导演台、接 3D 加工。**按模型资产登记** | 上游异步，**最长约 1 小时**，限速 4 次/小时，**单独计费** |
| **高斯泼溅**     | PLY                                                                    | 高质量泼溅                               | 官方同步转换，可选分辨率                                  |

**这里有个省钱的关键**：如果只是想进去看看，**根本不用走导出** —— 世界生成时随包免费给的 `*.spz` 泼溅**已经能直接看**了（见下一节）。

**要接导演台拍东西，才需要走「网格」模式**，那一档是单独计费的。想清楚再点。

## 五、进去之后：你得到的是什么

### 一个能走的世界

接进 **3D 导演台**之后：

- **中键平移、右键环视/第一人称飞行（WASD）** 在里面自由移动
- 世界直接呈现为可漫游的场景，不是一张贴图

顺手说一句我们刚做的：**视口的操控灵敏度五项全部可调**（环视/飞行转向、飞行移动、环绕旋转、平移、滚轮缩放），入口在视口底部工具栏的滑块图标里，**拖动即时生效**。默认值等于旧版写死的手感，所以老用户升级后不会觉得"手感变了"。

### 一个能拍的场地

这才是重点。世界进来之后就是**普通场景内容**，所以：

- 往里**摆角色、摆道具、摆灯光**
- **架机位**，走位，录运镜
- 用「导演台」直接**截站位图、录动作视频**，接到下游生成

**那个"生成出来的世界"，在这里变成了你的摄影棚。**

### 高斯泼溅是直接能看的

`.spz` 和 `.ply` 走 **Spark** 渲染（Rust/wasm 在构建期内联进 bundle，Electron 下不需要额外拷 wasm / worker 静态资源 —— 这是接入前唯一的打包风险点，已实测通过）。

泼溅在场景里是**普通的 `Object3D`**，所以它能像别的物体一样被**选中、变换、显隐**，也进模型预览和缩略图。

> **这也是为什么"只想看看"时不必花钱走导出**：世界生成时免费给的 `.spz` 已经能看能逛。

## 六、为什么我非要把它做成节点，而不是一个按钮

因为**按钮只能用一次，节点能进流水线**。

### 1. 它能接成链，而且不用你手动搬文件

一键工作流里已经有现成的 **「世界模型」** 预设：

> 世界设定 → **空间世界生成** → **空间世界导出** → **3D 导演台** → 选站位图 → 漫游成片

创建完之后你只要改参数、点运行。中间那些"下载 → 改名 → 拖进去"的体力活，没有。

### 2. 生成出来的东西能继续加工

导出得到的网格，可以接 **3D 加工节点**（拆分 / 重拓扑 / 贴图 / 格式转换……），也能当背景、当素材复用。

### 3. 一个图里可以放多个世界，各自独立

每个「空间世界生成」节点的参数**独立保存**，互不干扰。想并排试三个方案，就放三个节点。

（顺便说个不显眼但很要命的修复：以前删掉重建节点后，**旧参数会串回来**。根因是清理孤儿数据时把"图里没有导演台节点"当成了"拿不到图信息"，于是旧状态永远留着。现在修了，并有回归测试钉住。）

### 4. 可以被 Agent 直接调用

内置 MCP 工具里有 **`generate_world`** —— Claude Code、Codex 这类外部 Agent 可以直接让你应用生成世界，异步轮询，生成的产物对话里直接出卡片。想入库点一下「保存到资产库」就行。

## 七、说点不好听的：它现在不擅长什么

我写文案的习惯是把"不适合谁"讲清楚。这一节建议认真看。

### 1. 约 5 分钟，而且**没有实时预览**

这是最大的体感问题。出图的交互节奏是"几秒到几十秒一次、快速试错"，世界生成是"点一次、等五分钟"。

**所以它不适合当草稿工具。** 更合理的用法是：先在出图环节把画面定下来（构图、光线、风格都确认好），**最后一步**再拿那张确定的图去生成世界。

### 2. 要花 World Labs 的 API 积分

**没有免费额度。** 而且有个容易踩的坑：

> **API 积分与 Marble 应用的积分是分开计费的。** 你在 Marble 网页端充的钱，不一定能用在这里；要去 `platform.worldlabs.ai/billing` 充 API 积分。

导出 HQ 网格还要**额外计费**，而且限速 4 次/小时。**只想看看的话别点导出**，直接用免费的 `.spz`。

### 3. 本地参考图会被上传

用本地图片/视频当参考时，**默认上传到 World Labs 的托管存储**（官方 media-asset 流程）。

好处是**你不需要配对象存储**就能用；代价是**素材要出本机**。对保密素材，这条得先想清楚。

（上传失败时才会回退到"用你自己的对象存储换公网 URL"，两条都失败会把两条原因一起写进报错 —— 不会静默。）

### 4. PLY 泼溅在应用内没有预览通道

走「泼溅」导出的 PLY **不登记为资产**，只写回路径。因为它在应用内没有预览通道、也没有对应的资产类型。

**建议**：想预览就用世界自带的 `.spz`；PLY 留给外部工具（Unreal / Unity / Blender / Houdini）。

### 5. 世界的 `world_id` 只能由生成节点给出

导出节点只认「空间世界生成」节点给的 id。**上游没接这个节点，它直接报错，不做任何猜测** —— 因为猜错就是拿别人的世界去导出。

（出口值偶尔丢失时会按"产出这个模型的节点"去任务记录里找回，生成本身已经花过积分，不会逼你重生成。）

## 八、最后：怎么开始

**它的定位很明确**：不是"随手玩一个世界"，而是**当你需要把一个确定的画面变成可拍的空间时**，把这件事从"几天"压到"五分钟 + 一次导出"。

**准备工作**：

1. 下载安装（本仓 GitHub Release，Windows / macOS / Linux）
2. 设置 → 模型 → 添加 **World Labs（Marble）** 提供商，填 API Key（默认 Base URL 是 `api.worldlabs.ai`，鉴权头 `WLT-Api-Key`）
3. 去 `platform.worldlabs.ai/billing` **充 API 积分**（注意是 API 积分，不是 Marble 应用的）
4. 有张图，或者想清楚一句描述

**完全不想花钱也能先试**：接一个本地 ComfyUI 或者你自己的图片模型，先把图磨出来——**软件这部分是免费的、本地的、开源的**，钱只花在真正调用云模型的那一刻。
