# AIArtEngine Roadmap

## Unreleased（进行中，5.1 / 5.2）

### P0 — 近期（5.1 / 5.2）

- [ ] 剧本 → 集 → 幕 → 分镜树（既有规划）
- [ ] 参数继承与覆盖（既有规划）
- [ ] 批量生成（既有规划）
- [ ] **成片时间线升级为可剪辑面板**：多轨非线性时间轴（视频 / 音频 / 字幕轨）、转场库、语音识别自动字幕、时间线上直接「重拍此镜头」回到对应节点图分支（承接既有「时间线高级剪辑」规划）
- [ ] **Skill 生态基础**：技能模板库（内置 GraphSkill 快照提炼为可复用模板）、技能调试视图（对话中可视化已加载技能与命中依据）、GraphSkill ↔ dsh skills 双向同步工具
- [x] **dsh 运行时离线打包**：dsh 运行体随包内置（resources/dsh），并复用 Electron 内置 Node（ELECTRON_RUN_AS_NODE=1）执行——运行时不再依赖系统 Node 22.19+ 与 npx 联网拉包
- [ ] **项目级 Agent 记忆**：跨会话记住项目偏好（风格 / 机位 / 角色一致性），沉淀为项目目录下记忆文件并随技能注入

### P1 — 中期

- [ ] **多 Agent 协作编排**：导演 / 分镜 / 质检角色化 Agent 并行流水线，把 `shortDrama` 预设的 4 级导演审核升级为可编排的多 Agent 协作图
- [ ] **3D 闭环**：3D 角色 / 场景资产库、骨骼动画导入编辑（复用导演台 IK / 骨骼基础）、3D 场景 → 分镜机位自动生成、GLB 动画导出
- [ ] **资产语义检索**：AI 自动标签（现有文本模型描述 → 标签）、自然语言检索资产、跨工程资产库、资产级版本历史
- [ ] **插件 SDK 正式化**：开放组件 / 脚本贡献点（当前仅声明式 toolbarItems）、配套文档与示例仓库、`aiartengine.*` 生态规范
- [ ] **i18n 补全**：主进程错误本地化补全，新增日 / 韩 / 西等语言

### P2 — 长期

- [ ] **团队协作**：工程云同步、审片批注（时间线打点）、角色权限
- [ ] **商业化**：许可证 / 试用、素材与技能市场（Skill 生态的商业化出口）、模板商城
- [ ] **Web / 移动端**：PWA 预览版（只读资产 + 审片）、移动端审片
- [ ] **本地模型深度集成**：SDXL / 视频本地模型一键部署、Ollama / 本地 vLLM 默认化
- [ ] **E2E 与性能体系**：桌面 E2E 测试、大图 / 视频处理 worker 化、崩溃报告（隐私合规）
