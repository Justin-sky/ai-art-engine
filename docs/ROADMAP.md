# AIArtEngine Roadmap

## Unreleased（进行中）

### 5.1「成片版」— P0 近期

> 主题：把「生成很强、成片很弱」的短板补上——时间线可剪辑 + 音频域 + 平台导出。
> 成功标准：用户能在 10 分钟内完成一条带字幕 + BGM 的 30s 成片并一键导出到目标平台规格。

- [x] **成片时间线升级为可剪辑面板**：多轨非线性时间轴（视频 / 音频 / 字幕轨）、转场库、语音识别自动字幕、时间线上直接「重拍此镜头」回到对应节点图分支（承接既有「时间线高级剪辑」规划）
- [ ] **AI 音乐 / BGM 生成**：按成片情绪与时长生成配乐（接入 MiniMax 音乐 / 聚合网关等），一键铺轨；沿用现有异步任务 + 资产落盘管线
- [ ] **音效与混音基础**：音效库 + AI 音效生成、人声 / 伴奏分离（隔离对白、去 BGM 再混音）
- [ ] **平台规格导出预设**：一键导出适配抖音 / 快手 / 视频号 / TikTok / YouTube 的尺寸、时长、安全区与可选水印

### 5.2「智能创作版」— P0 近期

> 主题：Agent 从"会生成"进化到"懂项目"——记忆、一致性、智能剪辑。

- [ ] **项目级 Agent 记忆**：跨会话记住项目偏好（风格 / 机位 / 角色一致性），沉淀为项目目录下记忆文件并随技能注入
- [ ] **角色音色 / 声音克隆**：基于现有 TTS 增加角色音色档案与声音克隆，跨镜头一致配音（与项目级记忆的角色一致性合并）
- [ ] **智能剪辑（AI 粗剪）**：按台词 / 语义自动切点、BGM 节拍卡点、AI 转场推荐；直接承接 5.1 的剪辑面板
- [ ] **视频级媒体理解**：媒体质检从图片扩展到视频帧序列理解（场景 / 动作 / 表情 / 画面质量）

### P1 — 中期

- [ ] **多 Agent 协作编排**：导演 / 分镜 / 质检角色化 Agent 并行流水线，把 `shortDrama` 预设的 4 级导演审核升级为可编排的多 Agent 协作图
- [ ] **3D 闭环**：3D 角色 / 场景资产库、骨骼动画导入编辑（复用导演台 IK / 骨骼基础）、3D 场景 → 分镜机位自动生成、GLB 动画导出
- [ ] **资产语义检索**：AI 自动标签（现有文本模型描述 → 标签）、自然语言检索资产、跨工程资产库、资产级版本历史
- [ ] **插件 SDK 正式化**：开放组件 / 脚本贡献点（当前仅声明式 toolbarItems）、配套文档与示例仓库、`aiartengine.*` 生态规范
- [ ] **i18n 补全**：主进程错误本地化补全，新增日 / 韩 / 西等语言
- [ ] **内容级多语言出海**：字幕翻译 + 台词翻译 + 多语言配音替换，一键生成多语言版本成片（短剧 / 广告出海）
- [ ] **AI 内容合规检测**：违禁词、敏感内容、版权风险扫描，叠加在媒体质检五维评分之上（投放审核硬需求）
- [ ] **工程模板市场前置**：把 `shortDrama` 等行业预设与 `.aipackage` 升级为可分享的「项目模板包」，为模板商城铺路
- [ ] **Headless / CLI 模式**：无头批处理（进参 → 跑图 → 导出）、CI 可集成，配合现有 MCP HTTP 做成自动化生产
- [ ] **渲染代理与性能体系**：大视频代理（proxy）文件、图 / 视频处理 worker 化（自 P2 提前——剪辑面板的性能前提）
- [ ] **工程快照 / 版本历史**：里程碑快照与回滚，为团队协作与商业化版本奠基

### P2 — 长期

- [ ] **团队协作**：工程云同步、审片批注（时间线打点）、角色权限
- [ ] **商业化**：许可证 / 试用、素材与技能市场（Skill 生态的商业化出口）、模板商城
- [ ] **Web / 移动端**：PWA 预览版（只读资产 + 审片）、移动端审片
- [ ] **本地模型深度集成**：SDXL / 视频本地模型一键部署、Ollama / 本地 vLLM 默认化、本地 TTS 与本地字幕识别（隐私卖点 = 本地优先）
- [ ] **E2E 与崩溃体系**：桌面 E2E 测试、崩溃报告（隐私合规）
