## 正文（可直接粘贴）

### 0. 开场：这段时间大家在吵什么

最近朋友圈和技术群都被同一类视频刷屏了：

> Claude **Opus 5.5** 吃下一句话需求，吭哧吭哧写完一个 **纯前端 / Node + esbuild** 的可玩小游戏，浏览器一打开就能玩，还有 3D。

评论区关键词高度一致：

- 「模型太强了」
- 「程序员要失业」
- 「这才是真正的 vibe coding」

我玩过几条 Demo，确实炸。**但这件事被说成「只有 Opus 才能做」，我觉得偏了。**

真正值得硬钢的，从来不是「哪家模型聊天更会写代码」，而是：

> **一句话之后，你有没有一条能重复、能续跑、能落盘、能试玩、成本还扛得住的工作流？**

所以我拿自己在维护的开源桌面工具 **AI Art Engine**，用**便宜得多的 DeepSeek**，把同一条赛道走通了：

**一句话玩法 → dsh 多轮 Agent 写纯 Node（esbuild）工程 → cook 打成单文件 HTML → 沙盒里直接试玩。**

模式拉开：**2D Canvas / 3D Three.js**，节点里一眼能选。

不是来踩 Opus。是来问一句：**顶配模型负责惊艳一次，廉价模型 + 产品化流水线能不能每天都用？**

---

### 1. 先把对手抬到桌面上：Opus 5.5 到底赢在哪

硬钢要公平。Opus 5.5 这一波火，不是营销空转，是有真本事：

1. **长上下文硬刚复杂工程**：多文件、依赖、着色器、输入循环，它能一口气扛住。
2. **审美与完成度**：很多 Demo 不是「能跑的玩具」，而是「看起来像个小产品」。
3. **叙事杀伤力**：一句话 → 可玩，视频 30 秒讲完，传播效率拉满。

如果你的目标是：**今晚发一条推特 / 小红书炸一下**，上 Opus 没错。

但如果你的目标是：

- 团队每天要出几十个玩法草案；
- 预算里写着「API 账单别爆」；
- 产物要进本地工程、能续改、能给策划点开就玩；

那「每次都上顶配模型」会很快从爽感变成账单焦虑。

---

### 2. 我这条廉价路线到底在干什么

AI Art Engine 里这条链路不叫「让模型在聊天框里吐一个巨大 HTML」，而是拆成工程步骤（v6.6 起）：

| 步骤         | 谁干                          | 产出                                      |
| ------------ | ----------------------------- | ----------------------------------------- |
| 写一句话玩法 | 你                            | 「太空射击，WASD 移动，鼠标瞄准，R 重置」 |
| 选模式       | 你                            | **3D Three.js**（或 2D / 自动）           |
| 多轮改工程   | **DeepSeek + 内嵌 dsh Agent** | `package.json` / `build.mjs` / `src/*.js` |
| cook         | 本机 `npm` + `node build.mjs` | **单文件 HTML**                           |
| 试玩         | 应用内沙盒                    | 双击就能玩                                |

结构刻意对齐社区里那类 **pelican-bike 式纯 Node + esbuild** Demo：没有 React、没有 Vite 全家桶，Agent 写的是它学过无数遍的「小而硬」前端。

**配图位 1**：节点图——「文本简报 → 可玩 HTML 生成 → 可玩 HTML 资产」三连。  
**配图位 2**：Inspector 里「模式 = 3D Three.js」。  
**配图位 3**：沙盒里正在跑的 3D 小游戏画面（GIF 更好）。

关键差异在这里：

- Opus Demo 往往是：**模型一次写完 → 你在外面自己跑**。
- AIAE 路线是：**模型多轮改工程 → 软件负责脚手架、续跑、构建、沙盒**。

模型可以换成 DeepSeek，产品骨架还在。这才是「能硬钢」的点。

### 3. 正面硬钢：五维对照（不装客观，但尽量诚实）

| 维度           | Opus 5.5 典型 Demo        | DeepSeek + AI Art Engine                            |
| -------------- | ------------------------- | --------------------------------------------------- |
| **单次惊艳度** | 经常赢                    | 看任务；复杂 3D/自定义 WebGL 可能要多轮             |
| **单次成本**   | 贵（顶配价）              | **便宜一个数量级很常见**（按你自己的 DeepSeek Key） |
| **可重复性**   | 靠你复制粘贴 / 自建仓库   | 节点图模板一键起，工程目录固定可续跑                |
| **试玩闭环**   | 自己开浏览器 / 本地起服务 | **应用内沙盒，双击就玩**                            |
| **数据落盘**   | 看你有没有另存            | **本地工程 + Cache/GamePlayJobs**                   |

一句话总结：

> **Opus 赢开场；DeepSeek + 工作流赢续航。**

硬钢不是嘴炮「谁更强」，是问：**你要的是首发日热搜，还是下周还能便宜地再出 20 个玩法原型？**

### 4. 实操：三分钟走通「一句话 3D」

（按 v6.6.0 界面描述，版本以 Releases 为准）

1. 从 [Releases](https://github.com/Justin-sky/ai-art-engine/releases) 装 AI Art Engine（Win / macOS / Linux）。
2. 设置里填入你的 **DeepSeek API Key**（走你自己的额度，不是软件卖点数）。
3. 新建 / 打开工程，丢进预设「可玩 HTML」工作流，或手动连：
   - 文本节点：一句话玩法
   - **可玩 HTML 生成**：模式选 **3D Three.js**
   - **可玩 HTML** 资产节点：负责 cook
4. 跑生成节点：dsh 多轮改 `src/`，不要自己瞎 `npm install`（宿主会在 cook 时构建）。
5. 跑资产节点 cook：看到日志里 `npm install` + `node build.mjs` + 单文件体积。
6. **双击**可玩 HTML 节点进沙盒，键盘鼠标开玩。

示例一句话（可直接抄）：

> 第一人称在低多边形太空站走廊里捡能量块，WASD 移动，鼠标转向，碰到红怪扣血，捡满 10 个过关，按 R 重置；用 Three.js，画面干脆点。

**配图位 4**：执行日志滚动（npm / build / cook 成功）。  
**配图位 5**：沙盒试玩 + 源码面板切换。

踩坑实话（硬钢文必须有，不然像软广）：

- **模式一定要选 3D**：停在「自动」时脚手架按 2D 起，Agent 容易偷懒不装 `three`。
- **自定义 WebGL / 着色器**比「Three 官方材质」更容易炸（导数扩展、WebGL1/2）；复杂玩法允许多轮续跑，别指望一轮封神。
- 这是 **原型 / 玩法草案**，不是 Unity 替身——定位是「一小时内可玩」，不是「上架 Steam」。

---

### 5. 为什么「廉价模型」反而适合这条赛道

很多人有个迷思：**越贵的模型，越适合写游戏。**

写游戏 Demo 吃的是：

1. 多文件编辑与自我修正（**多轮 Agent**，不是单次补全）；
2. 狭窄技术栈（Canvas / Three / esbuild），降低胡编框架的概率；
3. **构建与试玩反馈环**（cook 失败、沙盒黑屏，都能回到同一工程目录继续改）。

DeepSeek 在「便宜 + 够快 + 中文 instruction 友好」上非常能打；缺的那截「一次成型的神性」，用 **dsh 多轮 + 固定脚手架 + 本地构建**补上。

Opus 也可以接进同一条流水线——软件不绑死一家模型。  
但硬钢的叙事是：

> **顶配模型证明「这件事人类做得到」；廉价模型证明「这件事团队用得起」。**

AI Art Engine 站后半句。

---

### 6. 收束：给三类人的结论

- **做内容 / 做 Demo 传播的**：继续追 Opus 5.5，爽就完事，别让人说你不懂热点。
- **做产品 / 做工具 / 做小团队管线的**：把「一句话可玩」收成**节点 + 工程目录 + cook + 沙盒**，模型可替换，账单可控。
- **两边都想要的**：同一条 AIAE 工作流，难活偶发切顶配，日常草案用 DeepSeek——这才是成人的用法。
