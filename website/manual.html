使用手册

AI Art Engine 7.3 的完整操作参考，按使用路径分为六个部分：本页介绍准备工作与核心概念，其余内容见下方「手册章节」或侧栏目录。文案以应用内中文界面为准；视频演示见 B 站教程。

第一次用？ 跟着快速上手，5 分钟跑通第一条片 先懂几个概念 宿主资产、锚点图、世界元素指什么 短剧成片全流程 剧集流水线专题：分镜、拼图、审核与视频 出问题了？ 按现象排查：余额、连线、一致性

1. 概述与准备

AIArtEngine 是 Agent 原生的 AI 美术资产引擎，服务短剧、广告、游戏与电商内容生产。工程与素材保存在你指定的本机目录；文本 / 图片 / 视频 / 声音生成通过你配置的模型提供商完成（OpenRouter、OpenAI、DeepSeek、智谱、Kimi、xAI、Google、vLLM、Ollama、LM Studio、火山方舟、可灵、MiniMax、通义千问、魔塔、ComfyUI、MagicRouter 等）， 其中 OpenRouter 另提供决策模型（Decisions API），与文本 / 图片 / 视频一样按模态配置。 3D 模型生成支持 Meshy、Tripo、Rodin（Hyper3D）、Luma AI 与 Lux3D。 空间世界生成（从文本 / 参考图生成可漫游 3D 世界）支持 World Labs（Marble）。 可用一键工作流从模板或自然语言快速生成可复用宿主资产，再拖入画布继续编排。

首次使用建议

  1. 从 官网下载页 或 GitHub Releases 安装对应平台安装包。
  2. 启动后先打开设置，添加模型提供商并填入密钥，拉取并勾选要用的模型。
  3. （可选）在对象存储中配置火山引擎 TOS / 阿里云 OSS / 腾讯云 COS（同时仅可启用一个），便于参考视频等大文件外链。
  4. 回到首页新建工程，进入工作区；可先试工作区「新建」里的「一键工作流」，或按传统流程新建剧本 / 场。
应用无传统菜单栏。顶栏 Logo 回首页；「设置」打开设置面板；「插件市场」就在「设置」左边， 打开的是一个独立窗口（见 §5.7）。关闭设置可点遮罩空白或「返回」。

2. 核心概念

先花两分钟认识下面这些词，后面所有界面都能看懂。本软件的数据组织是 工程 → 场 / 剧集 → 节点图 → 资产：工程是容器，节点图是生产车间，资产是产出物。

工程 Project

一部作品的全部数据，保存在你自己指定的本机目录下，根目录是 project.json。素材不出本机，换机器时把整个目录拷走即可。

详见 §3 首页与工程

资产 Asset

工程里的一切产出与素材的统称：剧本、节拍表、分镜图、锚点图、视频、音频、3D 模型，以及宿主资产。统一在资产库中浏览与拖用。

详见 §6 资产库

宿主资产 Host Asset

一键工作流生成的可复用组件。外层只暴露边界输入 / 输出，双击可 Dive 进入内部完整节点图微调。一次创建，多个工程反复使用。

详见 §7 一键工作流

节点图 Graph

用节点和连线描述「输入 → 生成 → 输出」的画布，是剧本、场、画布、导演台、宿主资产共同的底座。

详见 §8 节点图

端口 Port

节点的出入口，严格区分单数与复数：image / images、video / videos、text / texts。类型不同连不上，单数不能进复数。 圆形口一般是单条 out，方形口是列表 out-all。

详见 §8.1 添加与连线

剧集 / 场 / 节拍

剧集（Episode）由多个场（Scene）组成；剧本先拆成节拍拆解表，再落到具体的场。 对应专用端口类型 world / worldEntities / beat，不可与普通 text 混连。

详见 §9 剧本与场

锚点图 Anchor Image

从 9 宫格 / 4 宫格拼图里按格拆出的单张参考图，用来锁住角色长相、服装与场景， 保证后续所有分镜保持一致——这是短剧不"变脸"的关键。

详见 短剧制作教程

世界元素 World Element

可复用的设定条目：角色、场景、道具。挂在剧集上被各场共用，避免每个镜头重新描述一遍， 也是保持一致性的手段之一。

详见 §11 画布与世界元素

导演台 Director Stage

3D 舞台：摆放模型、布光、调机位，然后截取站位图或录制动作视频， 分别从 out-shots / out-actions 两个方形口输出。

详见 §12 导演台

成片时间线 Timeline

多轨道剪辑面板：把节点输出或导入素材拖进轨道，编排顺序、对齐音频，预览并导出成片。

详见 §10 成片时间线

资产包 .aipackage

把资产连同依赖关系打包导出的格式，用于迁移到另一台机器或分享给协作者，导入后可原样还原。

详见 §13 资产包

2.1 一条短剧是怎么跑出来的

理解了上面的概念，就能看懂短剧流水线的完整数据流：

  1. 剧本 → 文本模型拆解为节拍拆解表（beat）。
  2. 节拍 → 9 宫格分镜表：一个节点生成 3×3 拼图，再按格拆出 9 张锚点图并高清放大。
  3. 锚点图 → 4 宫格动态分镜表：每组 2×2 拼图，拆出 36 个动态格并放大。
  4. 动态格 → 动态提示词表（36 条）→ 36 条动态视频。
  5. 全程穿插 review1~review4 四个导演审核节点，不达标可打回重做。
  6. 视频 → 成片时间线编排 → 导出成片。
这套流程已固化为「短剧分镜」模板，用一键工作流选它即可自动生成上述全部节点， 无需手动搭建。完整演示见 短剧制作教程 与 快速上手。
