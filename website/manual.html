使用手册

覆盖当前版本（2.0）主要界面与组件：工程与模型配置、一键工作流、宿主资产、节点图与任务队列、分镜、成片时间线、导演台与资产包。 文案以应用内中文界面为准；视频演示见 B 站教程。

1. 概述与准备

AIArtEngine 是面向短剧、广告与成片制作的专业 AI 创作工具。工程与素材保存在你指定的本机目录；文本 / 图片 / 视频 / 声音生成通过你配置的模型提供商完成（OpenRouter、火山方舟、可灵、MinMax、通义千问、魔塔等）。 可用一键工作流从模板或自然语言快速生成可复用宿主资产，再拖入画布继续编排。

首次使用建议

  1. 从 官网下载页 或 GitHub Releases 安装对应平台安装包。
  2. 启动后先打开设置，添加模型提供商并填入密钥，拉取并勾选要用的模型。
  3. （可选）在对象存储中配置火山引擎 TOS / 阿里云 OSS / 腾讯云 COS（同时仅可启用一个），便于参考视频等大文件外链。
  4. 回到首页新建工程，进入工作区；可先试顶栏「一键工作流」，或按传统流程新建剧本 / 分镜。
应用无传统菜单栏。顶栏 Logo 回首页；「设置」打开设置面板。关闭设置可点遮罩空白或「返回」。

2. 首页与工程

新建工程

  1. 点击「新建工程」。
  2. 填写「工程名称」。
  3. 点击「浏览」选择「存储目录」。
  4. 点击「创建」后进入工作区。

打开工程

  • 点击「打开工程」，选择工程目录中的 project.json。
  • 或在「最近工程」列表中点击对应路径。

最近工程

  • 列表展示近期打开过的工程路径。
  • 右侧 × 表示「从最近列表移除」——不会删除磁盘上的工程文件。
当前版本没有应用内「删除工程」功能。若要彻底删除，请在文件管理器中手动删除工程目录。

3. 设置

在首页或工作区顶栏进入「设置」。修改会自动保存。

3.1 通用

  • 主题：暗色 / 亮色。
  • 语言：中文 / English。
  • 自动保存：可启用，并设置间隔（秒）。
  • 关于与更新：查看版本、检查更新（见下文）。

3.2 模型

  1. 点击「添加模型提供商」，可选：
    • OpenRouter：文本 / 图片 / 视频（聚合目录，单 API Key）。
    • 火山方舟：文本 / Seedream 图 / Seedance 视频用方舟 API Key；声音设计走豆包语音 openspeech（语音控制台 API Key，可与方舟 Key 不同）+ 手填 speaker_id。
    • 可灵：图片 / 视频（API Key）。
    • MinMax：文本 / 图片 / 视频 / 音色设计（同一 API Key；默认 Base URL https://api.minimaxi.com）。
    • 通义千问：文本（兼容模式）/ 万相图 / 万相视频（含 HappyHorse 等，百炼 API Key）。
    • 魔塔：文本 / 文生图（ModelScope 访问令牌，如 ms-…）。
  2. 选择或展开提供商后，设置页会显示对应密钥申请页链接（也可直接打开）：
    • OpenRouter： https://openrouter.ai/keys
    • 火山方舟 API Key（文本 / 图片 / 视频）： https://console.volcengine.com/ark/region:ark-cn-beijing/apiKey
    • 豆包语音控制台（声音设计 API Key / speaker_id）： https://console.volcengine.com/speech/app
    • 可灵开放平台（API Key）： https://app.klingai.com/cn/dev
    • MinMax 接口密钥： https://platform.minimaxi.com/user-center/basic-information/interface-key
    • 通义千问 / 百炼 API Key： https://bailian.console.aliyun.com/?tab=model#/api-key
    • 魔塔访问令牌： https://modelscope.cn/my/myaccesstoken
  3. 填写显示名称、Base URL、密钥（可显示/隐藏）。
  4. 启用该提供商后，点击「拉取可用模型」（可灵 / MinMax 部分模态 / 百炼图视频等为本地静态目录）。
  5. 用筛选、全选/清空勾选需要的模型；也可手动添加模型 ID。
  6. 按模态配置：文本 / 图片 / 视频 / 声音（方舟声音页签会提示语音控制台链接，并手填 speaker_id；可灵仅图片与视频页签；MinMax 支持文本 / 图片 / 视频 / 音色设计；魔塔仅文本与图片，文生图为异步任务）。
  7. 设置默认生成模型与默认声音（如需要）。提供商卡片可折叠以节省空间。
API Key 保存在本机设置文件中（Windows 示例： %APPDATA%\aiartengine\aiartengine-settings.json），不会上传到应用官方服务器。

3.3 对象存储

用于将本地参考视频等上传为可公网访问的 URL（私有桶时使用签名链接）。

  • 「添加对象存储」→ 选择其一：
    • 火山引擎 TOS：AccessKey / SecretKey、Region、Endpoint、Bucket。
    • 阿里云 OSS：AccessKey / SecretKey、Region、Endpoint、Bucket。
    • 腾讯云 COS：SecretId / SecretKey、Region、Bucket（通常为 BucketName-APPID）。
  • 密钥申请页（设置中亦有外链）：
    • 火山引擎： https://console.volcengine.com/iam/keymanage
    • 阿里云 RAM： https://ram.console.aliyun.com/manage/ak
    • 腾讯云 API 密钥： https://console.cloud.tencent.com/cam/capi
  • 公网访问域名（CDN / 自定义域名）可选；未填时使用签名 URL（约 24 小时有效）。
  • 同时只能启用一个对象存储；勾选启用会自动关闭其它项。卡片支持折叠。

3.4 扩展

只读列出用户数据目录 plugins 下的声明式扩展。当前不会执行外部任意脚本，仅展示已声明的扩展信息。

4. 工作区

打开工程后进入工作区（应用内导航名称为「工作区」）。界面为可拖拽停靠的多面板布局。

4.1 顶栏

  • 未保存时标题旁显示 *；用 Ctrl+S 保存。
  • ↶ / ↷：撤销 / 重做（亦可用快捷键）。
  • 一键工作流：用预设或 AI 规划生成可复用宿主资产（见 §6）。
  • 任务列表、执行日志：后台队列与模型调用日志。
  • 布局：切换默认布局、保存当前布局、导出/导入布局 .json、删除自定义布局。

提示：拖动标签可停靠到不同区域；标签右键可浮动、分离到新窗口或关闭相关标签。节点执行中不可关闭关键面板。

4.2 四栏面板

面板 作用
工具 左侧窄栏，快捷新建各类资产草稿。
工作区 中心编辑器；空态显示推荐流程与最近资产，打开资产后为标签页。
资产 工程资产库浏览与管理。
参数 当前选中项的 Inspector 参数面板。

4.3 左侧工具栏：新建资产

点击图标创建草稿资产，编辑后用 Ctrl+S 落盘。可新建：

  • 画布 · 剧本 · 分镜 · 世界元素 · 叙事单元 · 导演台 · 图片 · 视频 · 声音

空工作区推荐流程：剧本 → 分镜 → 节点生成；也可快捷新建剧本、分镜、导演台，或双击最近资产打开。

4.4 右侧竖栏：资产 / 参数

工作区最右侧为 Rider 式竖栏，可分别展开或收起资产与参数面板（收起后不占中间布局宽度）。

  • 点击竖栏按钮切换对应侧栏显示。
  • 可将「资产」拖到「参数」上方或下方叠放；拖放预览仅在上下半区出现（半屏 left/right 预览已禁用，避免灰框残留）。
  • 布局菜单保存的是展开几何；侧栏收起偏好单独记忆，不会把收起态写成零宽灰洞。

5. 资产库

浏览与筛选

  • 标题「资产」旁可刷新；支持搜索与类型筛选。
  • 底部滑条在列表视图与图标视图间切换。
  • 面包屑显示路径，如 Assets > …
  • 支持框选多选；可从系统拖入图片 / 视频 / 声音 / 模型 / .aipackage。

空白或目录右键

  • 新建各类资产、新建目录。
  • 导入资产包 / 导出资产包。
  • 目录另有：重新导入、重命名、删除目录（内容上移）、删除目录及内容。

资产右键

  • 打开编辑器 · 在文件管理器中显示 · 复制原始文件。
  • 重新导入 · 导出资产包 · 重命名 · 查找引用 · 删除。

资产库焦点下快捷键

  • Delete / Backspace：删除选中。
  • Ctrl+A：全选。
  • Ctrl+C：与复制原始文件相关操作。

6. 一键工作流

「一键工作流」用预设模板或AI 规划快速生成一张可复用的宿主资产（内含完整节点图与边界 I/O）。创建后可拖入任意画布，像组件一样灌入输入、取走输出。

6.1 打开入口

  1. 打开任意工程进入工作区。
  2. 顶栏点击一键工作流。
需已配置至少一个可用的文本模型（AI 规划时）；纯模板预览可不依赖 AI。

6.2 预设与描述

  • 预设模板：游戏买量、角色设定、分镜出片、产品广告、短剧分镜、自定义等。带固化拓扑的预设可直接「预览模板」。
  • 工作流描述：用自然语言说明目标（例如「剧本 → 分镜图 → 竖屏短视频」）；可先选预设再改描述。
  • 模型：文本模型用于 AI 规划；图片 / 视频默认模型会写入生成节点的初始参数。

6.3 预览 → 创建

  1. 点击预览模板（固化预设）或AI 生成预览（需文本模型；快捷键 Ctrl+Enter / ⌘+Enter）。
  2. 在预览区查看节点与连线拓扑；可打开执行日志查看模型规划过程。
  3. 确认后点击创建工作流，选择保存目录与名称。
  4. 资产库中出现新的宿主资产；拖入画布即可使用。
创建的是宿主资产：外层暴露边界输入 / 输出，内图可 Dive 进入编辑。多路同类型出口（如多张立绘）会各自保留独立边界输出。

6.4 创建后怎么用

  • 从资产库拖到画布 → 连上上游文本 / 图片等到宿主输入口。
  • 双击或 Dive 进入内图，微调节点、模型与指令。
  • 选中边界输出或宿主节点，用「加入任务」跑整条内链；可与其它链并行（见 §7.3）。

7. 节点图

节点图是核心生成编排界面。在剧本、分镜、画布、导演台、宿主资产等场景中，通过节点连线组织「输入 → 生成 → 输出」链路。

7.1 添加与连线

  1. 在画布空白处右键，或按 Space，选择「添加节点」。
  2. 从端口拖出连线，松开后可「选择节点并连接」。
  3. 改接：按住已有连线拖动（靠近哪一端就改哪一端），或从已连线的输入口拖出，接到其他兼容端口；松在空白处则断开。 框选或多选连线（Shift / Ctrl 点选）后拖其中一条，可一次改接多条；从输入口拖出时会带走该口全部入边。
  4. 从资产库拖入资产到画布，可快速建立引用。
  5. 选中节点或边后按 Delete / Backspace 删除。

图片 / 视频 / 声音 / 剧本等图库生成节点有两个输出口： out（当前选中的单条，默认自动连线）与 out-all（全部历史，方形端口）。每次执行成功会自动选中最新一条；在右侧 Inspector 中单击历史项可改设当前 out。

导演台编辑节点使用两个方形输出口： out-shots（站位图，images）与 out-actions（动作视频，videos）。旧连线 out / out-all 会在加载时迁移到 out-shots。

结构化目录类端口使用专用类型 world / narrative / shots（界面显示为世界元素 / 叙事单元 / 分镜），勿与普通 text 混连。

生成类节点支持锁定：开启后跳过模型调用，直接复用图库或上次输出（节点卡锁图标与 Inspector 可切换）。

7.2 工具条与画布交互

  • 选择 / 平移 · 适配视图 · 网格与吸附 · 对齐 / 分布 · 自动布局。
  • 连线样式：曲线 / 直角 / 不显示（偏好会记住）。
  • 小地图：左下角概览与视口框；布局条收起时也可开关显示。
  • 滚轮缩放范围约 17.5%–400%；点击缩放百分比可复位相关视图习惯。
  • 执行 / 停止 / 加入任务。

节点卡与 Inspector 中的图片预览按比例完整显示（letterbox），不会因画幅不同被裁切。

7.3 执行方式与任务队列

方式 说明
工具条「执行」 有选中时执行选中节点及其上游；无选中时确认后「执行所有节点」。
按住 C 打开执行环：执行当前 / 重跑 / 跳过上游 / 强制上游 / 加入任务 / 停止。
节点右键 执行当前 · 重新执行 · 停止。
任务列表 后台工作流队列。选中输出终端再「加入任务」只跑该汇点上游；未选输出则跑图内全部输出链的并集。
共同上游只 cook 一次：同一画布上多条输出链分别加入任务时，各任务保留独立进度；后入队的任务会等待更早任务完成重叠上游，并跳过已 done 的共同节点。汇点本身仍会各自执行。若要强制重跑某共同节点，请先清除其运行态或关闭锁定后再入队。

分组：Ctrl+Shift+G；取消分组：Ctrl+Shift+U。

7.4 节点类型一览

  • 图片生成 · 视频生成 · 声音生成 · 剧本生成 · 分镜 · 导演台编辑 · 画布编辑 · 模型（引用）

输出类

  • 图片 / 视频 / 声音 / 剧本输出 · 导演台输出 · 分镜输出 · 叙事单元输出 · 世界元素输出

工具类

  • 备注 · 文本 · 选取图片 / 视频 · 选择文本 · 提示词优化 · 图片反推提示词 · 对口型

图片编辑（图片分组下）

  • 多角度编辑 · 打光效果 · 人像质感调节 · 情绪调节 · 高清放大 · 扩图 · 重绘 · 擦除 · 抠图 · 裁剪 · 宫格切分
  • 精修 / 图片编辑在 Dive 中操作；选项与提示词会实时写回节点 params，Inspector 同步可见。预览走弹窗，不占用 Dive 工具位。

分镜管线

  • 分镜拆分 · 分镜表格 · 分镜编辑 · 分镜参数

叙事 / 世界

  • 叙事单元拆解 / 表格 / 编辑 · 世界元素提取 / 表格 / 编辑 / 输出

其它

  • 图插件示例（扩展演示用）

7.5 典型节点工作流

  1. 剧本：新建剧本 → 右侧选文本模型 → 填「生成指令」→ 执行生成节点 → 接到「剧本输出」。
  2. 分镜：剧本 →「分镜拆分」→「分镜表格」（运行导入 JSON）→「分镜编辑」/ 视频生成 →「分镜输出」。
  3. 图片 / 视频：上游参考连入生成口 → 提示词中用 @ 引用 → 执行 → 输出节点导出结果。自由画布上从零搭视频与参考视频，见 专题指南。
  4. 成片：分镜 / 视频节点输出 → 打开剧本资产的成片时间线 → 拖入轨道拼装与导出。
  5. 一键工作流：顶栏创建宿主 → 拖入画布接线 → Dive 微调 → 加入任务。

7.6 宿主资产与 Dive

宿主资产（含一键工作流产物、选区封装等）在外层只暴露边界输入 / 边界输出；双击或 Dive 进入内图编辑完整拓扑。

  • 边界输出按汇点一一对应：多路同类型结果（如多张立绘）会各建一个出口，而不是合并成单口。
  • 备注类文本节点默认不暴露为宿主出口。
  • 内图整链可入队任务列表；宿主节点也可作为画布上的黑盒参与更大流程。
  • 精修 / 图片编辑等工具在 Dive 中操作，选项写回节点参数；大图预览走弹窗。

8. 剧本与分镜

8.1 剧本资产

通过节点图生成与编辑剧本内容。将结果连到「剧本输出」，并在参数面板选择合适的文本模型与指令。 可将剧本资产拖入其他图中作为上游。

8.2 分镜资产

  • 节点图提示：拖入资产、连线至输出、在右侧调参数。
  • 底栏分镜条：+ 新建镜头；点击切换；拖到画布可建「分镜参数」节点； × 删除镜头。
  • 分镜表格：批量编辑名称、时长、画面、景别、光影、对白、音效、运镜、状态等；可开独立窗口。
  • 分镜编辑：以节点图方式编排；双击拆分 / 表格 / 编辑类节点可打开对应窗口。

8.3 镜头参数常见字段

  • 画面描述 · 景别 · 光影 · 对白 / 旁白 · 音效 · 运镜。
  • 参考：首帧 / 尾帧等，支持 @ 引用资产。
  • 生成视频：在参数齐全且模型配置正确后执行相关生成节点。

8.4 镜头调度预设与分镜思维

分镜参数面板顶部和分镜表格的每一行都提供「镜头调度」。在参数面板选择预设后点击「套用」，或直接在表格行内选择， 即可自动填写相关的画面描述、景别、光影或运镜； 预设文本会插入当前编辑字段的光标位置，其他相关字段追加到末尾，不会清空已有内容；景别仅在为空时填写。

  • 镜头语言：英雄 / 神秘出场、双人中景、过肩反打、俯视、背面、荷兰角等。
  • 身体朝向：全正面、45° 正面、纯侧面、45° 背面和严格背面。
  • 人物表演：把愤怒、失神、疯癫、释然、焦虑、悲伤、自信与惊讶拆成面部、呼吸、肩颈、手指和重心动作。
  • 打光：顶光、正侧光、伦勃朗光、体积光、逆光和画面内有动机光源。
  • 广告运镜与转场：冲击硬切、闪白、运动匹配、短叠化、匹配剪辑、前景遮挡、虚焦揭示、跳切和产品英雄揭示。

「分镜拆分」已按可剪辑镜头序列生成：画面描述负责可生成的静态首帧，运镜负责随时间发生的运动； 同场景会有目的地变化景别并在关键节拍插入特写。图片和视频生成节点的指令预设中，除「建立镜头 / 细节镜头」模板外，视频节点还提供动作连续性、产品揭示、匹配转场三种首尾帧成对模板，以及短叠化、 遮挡和虚焦转场。先连接首帧与尾帧，再套用对应模板，填写一个核心动作和一条镜头路径。

9. 成片时间线

成片时间线用于把分镜 / 导入素材拼成一条可预览、可导出的时间轴，通常挂在剧本资产上打开。

9.1 打开与布局

  • 在剧本相关流程中打开成片时间线编辑器（左：素材列表 · 中：预览 · 下：多轨时间线）。
  • 轨道常见类型：视频 · 配音 · 字幕 · 音乐。

9.2 左侧素材

  • 节点输入：从上游节点收集的视频 / 声音，不可从列表删除（删轨道片段不影响列表）。
  • 导入素材：从资产库或系统文件拖入时间线后出现在此；可删除，并同步清掉轨道上对应片段。
  • 在导入区右键可新建分组；将导入项拖入分组或拖回「未分组」。分组会随时间线文档保存。
  • 视频素材图标使用首帧缩略图；声音素材显示通用声音图标。

9.3 上轨与编排

  • 从列表拖到轨道放置；声音误拖到视频轨时会智能落到配音轨。
  • 轨道上的片段可用指针左右拖动改时间，也可拖到其他轨道。
  • 双击片段可预览 / 定位；字幕轨支持编辑文案。

9.4 播放

  • 中间预览区播放：只播放当前选中的视频或声音片段（未选中媒体片段时按钮禁用）。
  • 下方时间线工具栏播放：按整条时间线联播（视频序列 + 声音轨），并受速度 / 循环设置影响。

9.5 导出

时间线工具栏提供导出成片。需本机可用 ffmpeg（或回退预览录制）；导出进度与结果路径会提示在界面中。

10. 画布与世界元素

10.1 画布资产

  • 自由画布：空白节点画布；右键添加节点，或从资产库拖入资产。多次新建会得到「自由画布 2」等名称。在画布上搭视频生成与参考视频，见 自由画布：视频生成与参考视频。
  • 若使用旧式分镜画布：可调网格 / 间距 / 图层；按钮「聚焦画板」或 F； 删除选中；图层显隐、锁定、上下移；通常仅拖入图片。

10.2 世界元素 / 叙事单元

  • 表格视图：角色 / 场景 / 道具 / 武器，或叙事相关列；支持新建与删除行。
  • 双击对应节点：打开提取 / 拆解指令、表格或编辑窗口。

11. 导演台

导演台用于 3D 场景摆姿、机位、动画预览与录制。节点链路一般为「导演台编辑 →（可选）选取 / 下游生成」。编辑节点提供两个方形输出口：站位图与动作视频。

11.1 从节点打开

  1. 在节点图中双击「导演台编辑」节点，打开舞台窗口。
  2. 关闭舞台或同步后，结果写入节点： out-shots（站位截图，images）与 out-actions（动作录制，videos）。
  3. 在节点 Inspector 中可预览站位缩略图与动作视频（双击进入媒体预览）。

11.2 舞台视口操作

  • 左键选择 · 中键平移 · 右键环视。
  • Q / R / S：移动 / 旋转 / 缩放工具。

11.3 侧栏与对象

  • 左侧场景列表：层级、搜索、创建相机 / 空物体 / 基本体；拖动右缘可调整列表宽度（会记住本地设置）。
  • 对象：删除、隐藏、显示名称、锁定；支持拖拽改父子关系。
  • 属性 · 姿势（FK / IK、预设、姿势资产）。

11.4 站位和动作

标题栏「站位和动作」打开面板，内含两个分类：

  • 站位：视口截屏历史。用工具栏相机按钮截取；双击缩略图可预览。
  • 动作：动画模式录制的视频历史。录制成功后自动写入工程 Cache/Videos/（无需另选目录），并打开动作分类。

11.5 视图与全景

  • 导演视角 / 机位切换；六向视图；重置。
  • 移动到视图：Ctrl+Alt+F；与视图对齐：Ctrl+Shift+F。
  • 全景：拖入背景图，调节缩放 / 平移 / 旋转、地面与天空色。

11.6 动画模式与录制

  • 在场景模式 / 动画模式间切换。
  • 轨迹与关键帧：K 添加关键帧；Delete 删除关键帧；Space 播放 / 暂停。
  • 动画面板红色圆点按钮为录制动作：按当前动画内容录成 WebM，自动保存到缓存目录并进入「动作」列表。

12. 资产包 .aipackage

格式标识为 com.aiartengine.asset-package，用于在工程间迁移素材与相关依赖。

导出

  1. 选中资产，或进入目标文件夹。
  2. 右键选择「导出资产包」。
  3. 在对话框中勾选目录 / 资产；可选「包含依赖」→「导出」。

导入

  1. 在资产库空白或根目录右键「导入资产包」，或直接拖入 .aipackage 文件。
  2. 勾选要导入的条目（一次处理一个包）→「导入」。
  3. 支持条目复用与重映射；脚本类资产可携带分镜快照。

14. 关于与更新

路径：设置 → 通用 → 关于与更新。

  • 当前版本：显示为 v{version}（预发布如 2.0.0-alpha.0 会标为 prerelease）。
  • 检查更新：查询 GitHub Releases；开发模式下会提示不检查更新。
  • 状态包括：正在检查、发现新版本并下载、已是最新、下载进度、失败提示。
  • 下载完成后可点击重启并安装。

15. 推荐端到端流程

  1. 设置 → 模型（填密钥并勾选模型）→ 可选配置对象存储（TOS / OSS / COS，仅启用一个）。
  2. 快速路径：顶栏「一键工作流」→ 选预设或 AI 预览 → 创建宿主资产 → 拖入画布接线并加入任务。
  3. 或手动：首页新建工程 → 左栏新建「剧本」→ 执行生成 → 接到剧本输出。
  4. 新建「分镜」→ 分镜拆分 → 分镜表格 → 视频生成；多条输出链可分别入队，共同上游会自动复用。
  5. 打开成片时间线：拖入节点输出或导入素材 → 编排轨道 → 预览 / 导出成片。
  6. 新建「导演台」→ 双击打开舞台 → 截取站位 / 录制动作 → 从方形口 out-shots / out-actions 接到下游。
  7. 在资产库导入媒体，或导出 / 再导入 .aipackage 做迁移验证。
  8. 设置中检查更新，保持客户端为最新版。
