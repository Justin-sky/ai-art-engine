使用手册

覆盖当前版本全部主要界面与组件的操作说明：从创建工程、配置模型，到资产、分镜、节点图与导演台。 文案以应用内中文界面为准。

1. 概述与准备

AIArtEngine 是本地 AI 短视频创作工作台。工程与素材保存在你指定的本机目录； 文本 / 图片 / 视频 / 声音生成通过你配置的模型提供商完成（OpenRouter、火山方舟、可灵、海螺 AI、通义千问、魔塔等）。

首次使用建议

  1. 从 官网下载页 或 GitHub Releases 安装对应平台安装包。
  2. 启动后先打开设置，添加模型提供商并填入密钥，拉取并勾选要用的模型。
  3. （可选）在对象存储中配置火山引擎 TOS / 阿里云 OSS / 腾讯云 COS（同时仅可启用一个），便于参考视频等大文件外链。
  4. 回到首页新建工程，进入工作区开始创作。
应用无传统菜单栏。顶栏 Logo 回首页；「设置」打开设置面板。关闭设置可点遮罩空白或「返回」。

2. 首页与工程

新建工程

  1. 点击「新建工程」。
  2. 填写「工程名称」。
  3. 点击「浏览」选择「存储目录」。
  4. 点击「创建」后进入工作区。

打开工程

  • 点击「打开工程」，选择工程目录中的 project.json。
  • 或在「最近工程」列表中点击对应路径。

最近工程

  • 列表展示近期打开过的工程路径。
  • 右侧 × 表示「从最近列表移除」——不会删除磁盘上的工程文件。
当前版本没有应用内「删除工程」功能。若要彻底删除，请在文件管理器中手动删除工程目录。

3. 设置

在首页或工作区顶栏进入「设置」。修改会自动保存。

3.1 通用

  • 主题：暗色 / 亮色。
  • 语言：中文 / English。
  • 自动保存：可启用，并设置间隔（秒）。
  • 关于与更新：查看版本、检查更新（见下文）。

3.2 模型

  1. 点击「添加模型提供商」，可选：
    • OpenRouter：文本 / 图片 / 视频（聚合目录，单 API Key）。
    • 火山方舟：文本 / Seedream 图 / Seedance 视频用方舟 API Key；声音设计走豆包语音 openspeech（语音控制台 API Key，可与方舟 Key 不同）+ 手填 speaker_id。
    • 可灵：图片 / 视频（API Key）。
    • 海螺 AI（MiniMax）：文本 / 图片 / 海螺视频 / 音色设计（同一 API Key；默认 Base URL https://api.minimaxi.com）。
    • 通义千问：文本（兼容模式）/ 万相图 / 万相视频（含 HappyHorse 等，百炼 API Key）。
    • 魔塔：文本 / 文生图（ModelScope 访问令牌，如 ms-…）。
  2. 选择或展开提供商后，设置页会显示对应密钥申请页链接（也可直接打开）：
    • OpenRouter： https://openrouter.ai/keys
    • 火山方舟 API Key（文本 / 图片 / 视频）： https://console.volcengine.com/ark/region:ark-cn-beijing/apiKey
    • 豆包语音控制台（声音设计 API Key / speaker_id）： https://console.volcengine.com/speech/app
    • 可灵开放平台（API Key）： https://app.klingai.com/cn/dev
    • 海螺 AI / MiniMax 接口密钥： https://platform.minimaxi.com/user-center/basic-information/interface-key
    • 通义千问 / 百炼 API Key： https://bailian.console.aliyun.com/?tab=model#/api-key
    • 魔塔访问令牌： https://modelscope.cn/my/myaccesstoken
  3. 填写显示名称、Base URL、密钥（可显示/隐藏）。
  4. 启用该提供商后，点击「拉取可用模型」（可灵 / 海螺部分模态 / 百炼图视频等为本地静态目录）。
  5. 用筛选、全选/清空勾选需要的模型；也可手动添加模型 ID。
  6. 按模态配置：文本 / 图片 / 视频 / 声音（方舟声音页签会提示语音控制台链接，并手填 speaker_id；可灵仅图片与视频页签；海螺支持文本 / 图片 / 视频 / 音色设计；魔塔仅文本与图片，文生图为异步任务）。
  7. 设置默认生成模型与默认声音（如需要）。提供商卡片可折叠以节省空间。
API Key 保存在本机设置文件中（Windows 示例： %APPDATA%\aiartengine\aiartengine-settings.json），不会上传到应用官方服务器。

3.3 对象存储

用于将本地参考视频等上传为可公网访问的 URL（私有桶时使用签名链接）。

  • 「添加对象存储」→ 选择其一：
    • 火山引擎 TOS：AccessKey / SecretKey、Region、Endpoint、Bucket。
    • 阿里云 OSS：AccessKey / SecretKey、Region、Endpoint、Bucket。
    • 腾讯云 COS：SecretId / SecretKey、Region、Bucket（通常为 BucketName-APPID）。
  • 密钥申请页（设置中亦有外链）：
    • 火山引擎： https://console.volcengine.com/iam/keymanage
    • 阿里云 RAM： https://ram.console.aliyun.com/manage/ak
    • 腾讯云 API 密钥： https://console.cloud.tencent.com/cam/capi
  • 公网访问域名（CDN / 自定义域名）可选；未填时使用签名 URL（约 24 小时有效）。
  • 同时只能启用一个对象存储；勾选启用会自动关闭其它项。卡片支持折叠。

3.4 扩展

只读列出用户数据目录 plugins 下的声明式扩展。当前不会执行外部任意脚本，仅展示已声明的扩展信息。

4. 工作区

打开工程后进入工作区（应用内导航名称为「工作区」）。界面为可拖拽停靠的多面板布局。

4.1 顶栏

  • 未保存时标题旁显示 *；用 Ctrl+S 保存。
  • ↶ / ↷：撤销 / 重做（亦可用快捷键）。
  • 任务列表、 执行日志：查看后台任务与运行日志。
  • 布局：切换默认布局、保存当前布局、导出/导入布局 .json、删除自定义布局。

提示：拖动标签可停靠到不同区域；标签右键可浮动、分离到新窗口或关闭相关标签。节点执行中不可关闭关键面板。

4.2 四栏面板

面板 作用
工具 左侧窄栏，快捷新建各类资产草稿。
工作区 中心编辑器；空态显示推荐流程与最近资产，打开资产后为标签页。
资产 工程资产库浏览与管理。
参数 当前选中项的 Inspector 参数面板。

4.3 左侧工具栏：新建资产

点击图标创建草稿资产，编辑后用 Ctrl+S 落盘。可新建：

  • 画布 · 剧本 · 分镜 · 世界元素 · 叙事单元 · 导演台 · 图片 · 视频 · 声音

空工作区推荐流程：剧本 → 分镜 → 节点生成；也可快捷新建剧本、分镜、导演台，或双击最近资产打开。

5. 资产库

浏览与筛选

  • 标题「资产」旁可刷新；支持搜索与类型筛选。
  • 底部滑条在列表视图与图标视图间切换。
  • 面包屑显示路径，如 Assets > …
  • 支持框选多选；可从系统拖入图片 / 视频 / 声音 / 模型 / .aipackage。

空白或目录右键

  • 新建各类资产、新建目录。
  • 导入资产包 / 导出资产包。
  • 目录另有：重新导入、重命名、删除目录（内容上移）、删除目录及内容。

资产右键

  • 打开编辑器 · 在文件管理器中显示 · 复制原始文件。
  • 重新导入 · 导出资产包 · 重命名 · 查找引用 · 删除。

资产库焦点下快捷键

  • Delete / Backspace：删除选中。
  • Ctrl+A：全选。
  • Ctrl+C：与复制原始文件相关操作。

6. 节点图

节点图是核心生成编排界面。在剧本、分镜、画布、导演台等资产中，通常通过节点连线组织「输入 → 生成 → 输出」链路。

6.1 添加与连线

  1. 在画布空白处右键，或按 Space，选择「添加节点」。
  2. 从端口拖出连线，松开后可「选择节点并连接」。
  3. 从资产库拖入资产到画布，可快速建立引用。
  4. 选中节点或边后按 Delete / Backspace 删除。

6.2 工具条

  • 选择 / 平移 · 适配视图 · 网格与吸附 · 对齐 / 分布 · 自动布局。
  • 执行 / 停止 / 加入任务。

6.3 执行方式

方式 说明
工具条「执行」 有选中时执行选中节点及其上游；无选中时确认后「执行所有节点」。
按住 C 打开执行环：执行当前 / 重跑 / 跳过上游 / 强制上游 / 加入任务 / 停止。
节点右键 执行当前 · 重新执行 · 停止。
任务列表 后台工作流队列；执行中一般不可对单节点随意重跑。

分组：Ctrl+Shift+G；取消分组：Ctrl+Shift+U。

6.4 节点类型一览

生成 / 资产类

  • 图片生成 · 视频生成 · 声音生成 · 剧本生成 · 分镜 · 导演台编辑 · 画布编辑 · 模型（引用）

输出类

  • 图片 / 视频 / 声音 / 剧本输出 · 导演台输出 · 分镜输出 · 叙事单元输出 · 世界元素输出

工具类

  • 备注 · 文本 · 选取图片 / 视频 · 选择剧本 · 提示词优化 · 图片反推提示词 · 对口型

图片编辑（图片分组下）

  • 多角度编辑 · 打光效果 · 人像质感调节 · 情绪调节 · 高清放大 · 扩图 · 重绘 · 擦除 · 抠图 · 裁剪 · 宫格切分

分镜管线

  • 分镜拆分 · 分镜表格 · 分镜编辑 · 分镜参数

叙事 / 世界

  • 叙事单元拆解 / 表格 / 编辑 · 世界元素提取 / 表格 / 编辑 / 输出

其它

  • 图插件示例（扩展演示用）

6.5 典型节点工作流

  1. 剧本：新建剧本 → 右侧选文本模型 → 填「生成指令」→ 执行生成节点 → 接到「剧本输出」。
  2. 分镜：剧本 →「分镜拆分」→「分镜表格」（运行导入 JSON）→「分镜编辑」/ 视频生成 →「分镜输出」。
  3. 图片 / 视频：上游参考连入生成口 → 提示词中用 @ 引用 → 执行 → 输出节点导出结果。

7. 剧本与分镜

7.1 剧本资产

通过节点图生成与编辑剧本内容。将结果连到「剧本输出」，并在参数面板选择合适的文本模型与指令。 可将剧本资产拖入其他图中作为上游。

7.2 分镜资产

  • 节点图提示：拖入资产、连线至输出、在右侧调参数。
  • 底栏分镜条：+ 新建镜头；点击切换；拖到画布可建「分镜参数」节点； × 删除镜头。
  • 分镜表格：批量编辑名称、时长、画面、景别、光影、对白、音效、运镜、状态等；可开独立窗口。
  • 分镜编辑：以节点图方式编排；双击拆分 / 表格 / 编辑类节点可打开对应窗口。

7.3 镜头参数常见字段

  • 画面描述 · 景别 · 光影 · 对白 / 旁白 · 音效 · 运镜。
  • 参考：首帧 / 尾帧等，支持 @ 引用资产。
  • 生成视频：在参数齐全且模型配置正确后执行相关生成节点。

7.4 镜头调度预设与分镜思维

分镜参数面板顶部和分镜表格的每一行都提供「镜头调度」。在参数面板选择预设后点击「套用」，或直接在表格行内选择， 即可自动填写相关的画面描述、景别、光影或运镜； 预设文本会插入当前编辑字段的光标位置，其他相关字段追加到末尾，不会清空已有内容；景别仅在为空时填写。

  • 镜头语言：英雄 / 神秘出场、双人中景、过肩反打、俯视、背面、荷兰角等。
  • 身体朝向：全正面、45° 正面、纯侧面、45° 背面和严格背面。
  • 人物表演：把愤怒、失神、疯癫、释然、焦虑、悲伤、自信与惊讶拆成面部、呼吸、肩颈、手指和重心动作。
  • 打光：顶光、正侧光、伦勃朗光、体积光、逆光和画面内有动机光源。
  • 广告运镜与转场：冲击硬切、闪白、运动匹配、短叠化、匹配剪辑、前景遮挡、虚焦揭示、跳切和产品英雄揭示。

「分镜拆分」已按可剪辑镜头序列生成：画面描述负责可生成的静态首帧，运镜负责随时间发生的运动； 同场景会有目的地变化景别并在关键节拍插入特写。图片和视频生成节点的指令预设中，除「建立镜头 / 细节镜头」模板外，视频节点还提供动作连续性、产品揭示、匹配转场三种首尾帧成对模板，以及短叠化、 遮挡和虚焦转场。先连接首帧与尾帧，再套用对应模板，填写一个核心动作和一条镜头路径。

8. 画布与世界元素

8.1 画布资产

  • 空白节点画布：右键添加节点，或从资产库拖入资产。
  • 若使用旧式分镜画布：可调网格 / 间距 / 图层；按钮「聚焦画板」或 F； 删除选中；图层显隐、锁定、上下移；通常仅拖入图片。

8.2 世界元素 / 叙事单元

  • 表格视图：角色 / 场景 / 道具 / 武器，或叙事相关列；支持新建与删除行。
  • 双击对应节点：打开提取 / 拆解指令、表格或编辑窗口。

9. 导演台

导演台用于 3D 场景摆姿、机位与动画预览，常作为节点链路中的「导演台编辑 → 导演台输出」。

9.1 从节点打开

  1. 在节点图中双击「导演台编辑」节点，打开舞台窗口。
  2. 将编辑结果连到「导演台输出」；截屏结果会出现在输出图片数组中。

9.2 舞台视口操作

  • 左键选择 · 中键平移 · 右键环视。
  • Q / R / S：移动 / 旋转 / 缩放工具。

9.3 侧栏与对象

  • 侧栏：场景层级、Inspector、全景相关资产。
  • 创建：创建相机 · 创建空物体 · 创建物体（Cube / Sphere 等）。
  • 对象：删除、隐藏、显示名称、锁定。
  • 属性 · 姿势（FK / IK、预设、姿势资产）· 站位（截屏）。

9.4 视图与全景

  • 导演视角 / 机位切换；六向视图；重置。
  • 移动到视图：Ctrl+Alt+F；与视图对齐：Ctrl+Shift+F。
  • 全景：拖入背景图，调节缩放 / 平移 / 旋转、地面与天空色。

9.5 动画模式

  • 在全景模式 / 动画模式间切换。
  • 轨迹与关键帧：K 添加关键帧；Delete 删除关键帧；Space 播放 / 暂停。
  • 可导出视频。

10. 资产包 .aipackage

格式标识为 com.aiartengine.asset-package，用于在工程间迁移素材与相关依赖。

导出

  1. 选中资产，或进入目标文件夹。
  2. 右键选择「导出资产包」。
  3. 在对话框中勾选目录 / 资产；可选「包含依赖」→「导出」。

导入

  1. 在资产库空白或根目录右键「导入资产包」，或直接拖入 .aipackage 文件。
  2. 勾选要导入的条目（一次处理一个包）→「导入」。
  3. 支持条目复用与重映射；脚本类资产可携带分镜快照。

12. 关于与更新

路径：设置 → 通用 → 关于与更新。

  • 当前版本：显示为 v{version}。
  • 检查更新：查询 GitHub Releases；开发模式下会提示不检查更新。
  • 状态包括：正在检查、发现新版本并下载、已是最新、下载进度、失败提示。
  • 下载完成后可点击重启并安装。

13. 推荐端到端流程

  1. 设置 → 模型（填密钥并勾选模型）→ 可选配置对象存储（TOS / OSS / COS，仅启用一个）。
  2. 首页新建工程 → 左栏新建「剧本」→ 执行生成 → 接到剧本输出。
  3. 新建「分镜」→ 分镜拆分 → 分镜表格 → 视频生成。
  4. 在资产库导入媒体，或导出 / 再导入 .aipackage 做迁移验证。
