使用手册

AI Art Engine v9.0.0 的完整操作参考，按使用路径分为本总览与五卷手册章节：本页介绍准备工作、v9.0.0 核心特性与基础概念，其余内容见下方「手册章节」或侧栏目录。文案以应用内中文界面为准；视频演示见 B 站教程。

第一次用？ 工作区 ◈ AI 对话内置「⚡ 零 Key 极速体验」，5 分钟跑通管线 先懂几个概念 多工程工作区、宿主资产、五阶段影视工作台与工业交付包 21 题材五阶段漫剧 影视工作台专题：分镜、11 项审核、设定音色、拍摄与宣发包 出问题了？ 按现象排查：余额、连线、MCP 服务与一致性

1. 概述与准备

AI Art Engine（AIArtEngine）是本地优先、Agent 原生的全模态 AI 创作与工业资产桌面引擎，服务游戏研发、AI 漫剧 / 短剧、爆款视频复刻、广告与电商内容生产。在 v9.0.0 中，它不止生成单张扁平图或视频，更能把 AI 产出直接编译为引擎级生产资产：

  • 游戏 UI 拆层与图集重组（image.layerSplit + ui.atlasCompose + ui.componentLib）：16 类控件语义识别、离线/在线双模 OCR 字色描边提取、九宫格无字底板修复、3D 爆炸视图预览、真实精灵图集重排组装，一键导出含原生可编辑 TySh 文本图层的 .psd 及 Unity UGUI/UXML、Godot 4 .tscn、HTML5 代码。
  • Machinations v2 游戏经济数值沙盘（game.economy）：100% Machinations 语义对齐与 59 种已验证构件、宏视图/专业蓝图无损互切、120fps 贝塞尔斜率菱形手柄（◆）与直接拖拽曲线反推 k * pow(STEP, p) 公式求解（Goal-Seek）、蒙特卡洛 P10/P50/P90 置信带、二维参数敏感度热力图与零代码可玩 HUD 卡牌原型。
  • 21 题材五阶段 AI 漫剧 / 短剧工业工作台（film.workbench）：内置 P01–P21 题材母体，串联「① A+B 双节拍分镜拆解 → ② 11 项导演连贯性与 ≥67% 对白审核 → ③ 角色 #variant / 场景 / 道具 / STYLE01 锚点与跨集 TTS 音色绑定 → ④ @1–@4 锁定批量拍摄与视觉质检重拍 → ⑤ 封面标题宣发包与整集 .mp4」。
  • 双节点爆款视频四轴取证与 1:1 复刻（rea-video：semantic.analyze → semantic.rebuild）：融合 WhisperX 逐词时间戳、PySceneDetect 切镜、Librosa 节拍、Demucs 人声伴奏分离与三帧 VLM 运镜取证，自动去字幕并输出分屏对比复刻成片（compare.mp4）。
  • 进程内 Pi 智能体、102 工具双向 MCP 服务与 24 小时定时自动化：对外暴露 /mcp（93 个核心工具）与 /mcp/blender（9 个实时建模桥工具）；内置 ◈ AI 对话 运行主进程内嵌 Pi 智能体（Pi Agent），支持 load_toolset 按需惰性激活领域与外部 MCP 工具（活跃工具数 <= 96，挂载再多外部 MCP 也绝不触发 128 工具上限报错）、Craft / Plan / Ask 双层工具门禁、工具栏实时 🛡️ 受限模式 ↔ 🔓 完全访问 切换、跨工程最多 6 路并发会话（配多精灵祈愿巫女伴随）与 00:00–23:59 定时任务。
  • 剪映级 6 栏 NLE 时间线、2D Spine 骨骼与专业人像调色：120+ GPU/FFmpeg 特效转场滤镜、剪映草稿工程直出、AI 姿态对齐 Spine 2D 导出、4 频段小波磨皮与 3D 导演台 56 骨骼运镜白模预演。

工作区与素材保存在你指定的本机目录（workspace.json + project.json）；文本 / 图片 / 视频 / 声音生成通过你自带密钥（BYOK）的模型提供商完成（OpenRouter、OpenAI、DeepSeek、智谱、Kimi、xAI、Google、vLLM、Ollama、LM Studio、火山方舟、可灵、MiniMax、通义千问、魔塔、ComfyUI、MagicRouter 等）； 3D 模型支持 Meshy、Tripo、Rodin（Hyper3D）、Luma AI、Lux3D 与 Blender MCP 实时建模，空间世界支持 World Labs（Marble 3DGS → .glb）。 你可通过一键工作流、技能市场或直接把导出的 aiae:graph 配方 PNG 拖入画布一键复现整条生产管线。

首次使用建议

  1. 从 官网下载页 或 GitHub Releases 安装对应平台安装包。
  2. 启动后可先新建工作区，在右侧 ◈ AI 对话 点击「⚡ 零 Key 极速体验」免配置跑通仙侠 RPG UI 拆解导出流程；正式云端生成前打开右上角设置，添加模型提供商并填入密钥，拉取并勾选要用的模型。
  3. （可选）在对象存储中配置火山引擎 TOS / 阿里云 OSS / 腾讯云 COS / 兼容 Amazon S3（同时仅可启用一个），便于参考视频等大文件外链。
  4. 在工作区中通过一键工作流（如内置 爆款视频拆解复刻）、顶栏技能市场安装行业工作流，或拖入 aiae:graph 配方 PNG 开启创作。
应用无传统菜单栏。顶栏 Logo 回首页；「设置」打开设置面板；「技能市场」就在「设置」左侧， 打开独立市场窗口安装社区工作流与技能包（见 §5.7 技能市场）。关闭设置可点遮罩空白或「返回」。

2. 核心概念

先花两分钟认识下面这些词，后面所有界面都能看懂。v9.0.0 的数据组织层级为 工作区（Workspace）→ 多工程（Project）→ 宿主资产 / 节点图 → 资产：工作区与工程是本地目录容器，节点图是生产车间，资产是工业交付物。

工作区与工程 Workspace

保存在你自己指定的本机目录下，由 workspace.json 统筹多工程列表，每个工程根目录含 project.json。可在 ◈ AI 对话 左侧边栏随时切换多工程或编辑文件，整个目录拷走即可跨机迁移。

详见 §3 首页与工作区

资产 Asset

工程里的一切产出与素材的统称：剧本、分镜文档、设定图、关键帧图、视频、音频、3D 模型、UI 图集，以及宿主资产。统一在资产库中浏览与拖用。

详见 §6 资产库

宿主资产与配方图

一键工作流或技能市场生成的可复用组件：外层只暴露输入 / 输出端口，双击 Dive 进入内部完整节点图微调；导出为带 aiae:graph 元数据的配方 PNG 后拖入画布即可一键还原。

详见 §7 一键工作流

节点图 Graph

用强类型节点和连线描述「输入 → 生成 / 仿真 / 拆层 → 输出」的 DAG 画布，也是所有专业 Dive 工作台与 102 个 MCP 工具共同操作的底座。

详见 §8 节点图

端口 Port

节点的出入口，严格区分单数与复数：image / images、video / videos、text / texts。类型不同连不上，单数不能进复数。 圆形口一般是单条 out，方形口是列表 out-all。

详见 §8.1 添加与连线

五阶段影视工作台

影视工作台（film.workbench）内置 21 种题材母体（P01–P21），在一个全屏 Dive 界面内串联「①A+B 节拍拆解 → ②11 项连贯性审核 → ③角色换装/场景/音色设定 → ④@1–@4 批量拍摄与视觉质检 → ⑤宣发包与整集导出」。

详见 §9 影视工作台

锚点图与 #variant

在影视工作台阶段 ③ 生成的角色多套换装（#variant）、场景、道具与全局画风（STYLE01）参考图，在阶段 ④ 拍摄时按 @1–@4 精确锁定并配合跨集 TTS 音色绑定，彻底杜绝角色「变脸串音」。

详见 短剧制作教程

游戏 UI 与数值沙盘

image.layerSplit + ui.atlasCompose 将概念图拆解或按真实图集重组为可编辑 TySh .psd 与 Unity/Godot 代码；game.economy 提供 120fps 曲线拖拽反推公式的 Machinations v2 经济仿真。

详见 §8 游戏 UI 与经济沙盘

3D / 2D 导演台

director.stage 支持 56 骨骼人形绑定、24 套程序化动作、38 组姿势预设、.webm 运镜轨迹白模视频（@2）与 World Labs 3DGS 转 .glb；stage.2d 支持 AI 骨骼对齐导出 Spine 2D。

详见 §11–12 画布与导演台

6 栏成片时间线

剪映级 6 栏多轨 NLE（素材 / 特效 / 转场 / 滤镜 / 调节 / 模板）：内置 120+ GPU/FFmpeg 效果、DOTween 双层关键帧与 TD-PSOLA 歌声合成，一键导出 .mp4 或剪映 / CapCut 多轨可编辑草稿。

详见 §10 成片时间线

资产包 .aipackage

把资产连同依赖关系打包导出的归档格式，用于跨机迁移或团队交付，导入后原样还原全部节点与引用。

详见 §13 资产包

2.1 一条五阶段 AI 漫剧 / 短剧是怎么跑出来的

理解了上面的概念，就能看懂 v9.0.0 短剧 / AI 漫剧流水线的五阶段闭环数据流：

  1. 剧本输入（text.plain）→ 连入影视工作台（film.workbench），选定 P01–P21 题材母体。
  2. ① A+B 双节拍分镜拆解：文本模型按剧情拆出结构化镜头列表（A 叙事拍 + B 情绪反应拍、景别、运镜、单镜时长、台词与分段提示词）及角色 / 场景 / 道具实体表。
  3. ② 11 项导演连贯性审核：AI 导演执行 11 项视听连贯性与 ≥67% 对白占比审计，不达标镜头自动修订复审（已锁定镜头保护不改写）。
  4. ③ 设定锚点与跨集音色绑定：批量生成角色多套换装（#variant）、场景、道具与 STYLE01 锚点图（支持指纹缓存），并为角色绑定跨集一致的 TTS 音色。
  5. ④ @1–@4 锁定批量拍摄与视觉质检：自动挂载 @1–@4 锚点生成关键帧（开启视觉质检自动重拍）→ 按分镜时长批量生成多镜头动态视频与口型对白。
  6. ⑤ 宣发包与成片交付：在第五阶段一键生成封面海报、爆款标题文案宣发包并合成整集 .mp4；或送入 6 栏成片时间线导出剪映多轨草稿精剪。
这套流程可通过技能市场安装 short-drama 工作流包或用一键工作流自动铺设，无需手搭连线。完整演示见 短剧制作教程 与 快速上手。
