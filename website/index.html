Workflow

七步完成一部作品

每一步都可以手动搭，也可以交给 Agent 一次跑完。

  1. 01

    一键工作流

    选预设（含「影视全流程」「影视精修·单镜头」短剧模板）或用一句话描述需求，预览拓扑后创建可复用宿主资产；拖入画布即可接线运行。详见 使用手册 §7 与 短剧制作教程。

  2. 02

    资产入库

    图片、视频、音色以 GUID 引用，支持素材包导入导出。

  3. 03

    影视工作台与单镜节点

    四阶段合一影视工作台（分镜拆解 → 导演审核 → 角色场景设定 → 批量拍摄，支持跟随分镜自动视频时长与视觉质检重拍）及下游「镜头」节点单镜精修。

  4. 04

    节点生成与专业工作台

    文本 / 图像 / 视频 / 音色 / 音乐 / 音效 / 空间世界 / 3D 模型节点，内置 10 合 1 图像处理、漫画页排版、2D 帧动画与骨骼舞台，对接 30+ 模型提供商并可配置多云对象存储。

  5. 05

    导演台

    3D 摆姿与机位；截取站位图、录制动作视频，经方形口接到下游生成。

  6. 06

    成片时间线

    导入与节点素材上轨编排，预览选中片段或整轨联播，导出成片。

  7. 07

    影视四阶段闭环与增量重跑

    双击「影视工作台」进入全屏 Dive 界面，一站式完成剧本拆镜、导演审核评分、角色场景定妆锚点图与批量视频生成；内置指纹缓存，改单镜只重算变更镜头，已满意镜头一键锁定保护。
