Workflow

七步完成一部作品

每一步都可以手动搭，也可以交给 Agent 一次跑完。

  1. 01

    一键工作流

    选预设（含「短剧分镜」短视频模板）或用一句话描述需求，预览拓扑后创建可复用宿主资产；拖入画布即可接线运行。详见 使用手册 §7 与 短剧制作教程。

  2. 02

    资产入库

    图片、视频、音色以 GUID 引用，支持素材包导入导出。

  3. 03

    剧集流水线

    节拍拆解、9 宫格 / 4 宫格分镜表与导演审核，把叙事节奏落到画面。

  4. 04

    节点生成

    文本 / 图像 / 视频 / 音色 / 音乐 / 音效 / 空间世界 / 3D 模型节点，对接 30+ 模型提供商并可配置多云对象存储。端口类型必须相同，选取节点只收列表口。

  5. 05

    导演台

    3D 摆姿与机位；截取站位图、录制动作视频，经方形口接到下游生成。

  6. 06

    成片时间线

    导入与节点素材上轨编排，预览选中片段或整轨联播，导出成片。

  7. 07

    Agent 流水线

    短剧模板自动生成 剧本 → 节拍 → 9 宫格 → 拼图 → 4 宫格 → 动态提示词 → 36 条视频；「剧集流水线」窗口集中操作，阶段重生成后下游自动失效、一致补跑。
