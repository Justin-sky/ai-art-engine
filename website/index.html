Production Pipeline

从灵感到工业交付的七步标准管线

每一步既可以手动精细微调，也可以交给内置 AI 或 MCP Agent 一键跑通。

  1. 01

    技能市场模板 / PNG 配方 / 一句话建图

    从内置「爆款视频拆解复刻」预设、技能市场（如短剧全流程技能包）、任意作品 PNG 拖入还原，或在 AI 对话里一句话描述需求，自动生成可复用的强类型节点图。详见 使用手册 §7。

  2. 02

    多工程工作区与 GUID 资产库

    多工程侧栏秒切，图片、视频、3D 与专属 TTS 音色以 GUID 统一引用，支持整包导入导出与 Git 状态比对。

  3. 03

    21 题材五阶段影视工作台

    剧本 A+B 拆镜 → 11 项连续性与对白审计 → 角色 #variant / 场景 / STYLE01 锚点 → 批量拍片与视觉质检重拍 → 发布包直出。

  4. 04

    游戏 UI 拆层、图集拼装与 Machinations 数值沙盘

    image.layerSplit 拆解 16 类控件直出原生 TySh PSD 与 Unity/Godot 代码；ui.atlasCompose 用自有图集零幻觉拼装界面；game.economy 120fps 拖拽曲线反推数值公式并导出 C# / GDScript。

  5. 05

    2D Spine 舞台与 3D 导演台

    2D 立绘自动拆件对骨导出 Spine 2D；3D 导演台 56 骨骼摆姿与录制 .webm 运镜白模驱动视频生成。

  6. 06

    六栏时间线与剪映草稿

    120+ 特效转场、LUT 调色、DOTween 关键帧与歌声合成，一键渲染 MP4 或导出剪映 / CapCut 多轨草稿。

  7. 07

    24 小时定时自动化与无头质量门禁

    为漫剧日更、热点视频拆解或资产巡检配置 00:00–23:59 本地定时任务；可玩 HTML5 游戏构建自带无头 Chromium 冒烟自检，指纹缓存确保改单处绝不重算全图。

FAQ

常见问题解答

关于开源协议、零 Key 体验、PSD/引擎导出、AI 漫剧一致性与 MCP 接入的高频问题。

AI Art Engine 是免费开源的吗？需要充值会员或买积分吗？

完全免费开源（GPL-3.0 协议），没有任何会员墙、水印或算力差价。工程文件 100% 保存在你的本地磁盘；云端模型填入你自己的 API Key（BYOK），也可接入 Ollama、LM Studio、vLLM、ComfyUI 与内置本地 ONNX 视觉模型零成本运行。

还没有配置任何 API Key，可以先体验核心功能吗？

可以！打开软件新建或进入任意工作区，展开右侧 ◈ AI 对话 面板，点击 「⚡ 零 Key 极速体验」，无需填写任何密钥即可实机观看仙侠 RPG 游戏 UI 拆层、3D 爆炸视图预览与 PSD / Unity / Godot 导出全过程。

它和传统网页端 AIGC 工具或原生 ComfyUI 有什么区别？

网页端工具通常只能下载扁平图片或单段视频；原生 ComfyUI 擅长底层扩散采样连线。AI Art Engine 既能把 ComfyUI 作为后端接入，又内置了 10+ 面向游戏与影视工业交付的专属工作台，直接产出 .psd（原生 TySh 文本层）、Unity .uxml / Godot .tscn、Spine 2D 骨骼包、Machinations C#/GDScript、剪映多轨草稿与可玩 HTML5 游戏。

游戏 UI 拆层导出的 PSD 在 Photoshop 里文字真的能直接改吗？

是的。image.layerSplit 节点通过离线/在线 OCR 提取字号、字色与描边参数，自动抹除底板文字补全干净九宫格底图，并在写出的 .psd 中构造标准 Photoshop 原生 TySh 文本层，在 Photoshop 或 Photopea 中双击即可改字换字体。详见 使用手册 §8.3。

怎样保证 AI 漫剧和短剧多集之间角色不崩脸、衣服和配音不串戏？

五阶段「影视工作台（film.workbench）」在第 3 阶段专门锁定角色基础锚点与 #variant 换装状态卡、场景定妆图、STYLE01 画风圣经以及跨集复用的 TTS 音色库；第 4 阶段批量拍片时自动注入 @1–@4 视觉锚点并由 VLM 自动质检重拍异常镜头。详见 AI 漫剧教程。

Machinations 游戏数值仿真沙盘能做什么？支持反推公式吗？

game.economy 100% 对齐 Machinations 核心语义，内置 59 个验证机制积木，支持精简宏观卡片与完整蓝图无损切换。v8.9.1 支持直接在图表上以 120fps 拖拽目标曲线点或紫色贝塞尔斜率控制点（◆）反推底层成长公式（Goal-Seek），并支持蒙特卡洛仿真、二维灵敏度热力图与导出 Unity C# / Godot GDScript。

Claude Code、Cursor 或 Codex 如何通过 MCP 操控本软件？

桌面端运行后自动在 127.0.0.1 开启带 Bearer Token 鉴权的本地 MCP 服务（共 102 个工具：/mcp 93 个 + /mcp/blender 9 个）。执行一行 claude mcp add aiartengine -- node ./resources/mcp-bridge.mjs 即可接入。详见 MCP 接入指南。

什么是「PNG 即工作流（Workflow-in-PNG）」？怎么用？

AI Art Engine 导出的作品 PNG 会自动在图像 aiae:graph 元数据块中写入完整节点拓扑与提示词参数。你只需把本站或社区分享的配方 PNG 直接拖进画布，整条多模态工作流就会原样重现，无需手动连线。
