Workflow
  1. 01

    One-Click Workflow

    Pick a preset (including the “short-drama storyboard” short-video template) or describe what you need in one sentence, preview the topology and create a reusable host asset; drag it onto the canvas to wire it up and run. See Manual §6 and the Short-Video Guide.

  2. 02

    Asset library

    Images, videos and voices are referenced by GUID, and asset packages can be imported and exported.

  3. 03

    Episode pipeline

    Beat breakdown, 9-grid / 4-grid storyboard tables and director review turn narrative pacing into shots.

  4. 04

    Node generation

    Text / image / video / voice / 3D model nodes; works with OpenRouter, OpenAI, Google, Volcengine Ark, Kling, MiniMax, Tongyi Qianwen, ModelScope, ComfyUI, Meshy, Tripo, Rodin (Hyper3D), Luma AI and Lux3D, plus configurable multi-cloud object storage. Port types must match, and select nodes only accept list ports.

  5. 05

    Director stage

    3D posing and cameras; supports a 3D model input port; capture blocking shots and record motion clips, then feed them downstream through the square ports.

  6. 06

    Final timeline

    Place imported and node-produced media on tracks, preview the selected clip or play the whole timeline, then export the cut.

  7. 07

    Agent pipeline

    The short-drama template auto-generates script → beats → 9-grid → tiling → 4-grid → motion prompts → 36 videos; drive everything from the Episode Pipeline window, where regenerating a stage invalidates downstream stages and re-runs them consistently.
