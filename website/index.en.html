FAQ

Frequently asked questions

Common questions on licensing, Zero-Key demo, editable PSD/engine exports, episodic consistency, and MCP agents.

Is AI Art Engine completely free and open source?

Yes — 100% free and open source under GPL-3.0, with zero subscriptions, credit markups, or watermarks. Projects live on your local disk; connect your own API keys (BYOK) or run locally via Ollama, LM Studio, vLLM, ComfyUI, and built-in ONNX Runtime vision.

Can I try it right away without any API key?

Yes! Open any workspace, expand the right-hand ◈ AI Chat panel, and click ⚡ Zero-Key Instant Demo to watch a live RPG Game UI decomposition, 3D exploded layer preview, and PSD / Unity / Godot export pipeline run locally.

How is AI Art Engine different from web AIGC tools or raw ComfyUI?

Web tools stop at flat images or isolated clips; ComfyUI focuses on low-level diffusion sampling graphs. AI Art Engine integrates ComfyUI as a backend while adding 10+ domain Dive studios that ship editable deliverables: native TySh PSDs, Unity .uxml / Godot .tscn, Spine 2D rigs, Machinations C#/GDScript, CapCut drafts, and playable HTML5 games.

Are text layers genuinely editable in Photoshop when exporting Game UI to PSD?

Yes. image.layerSplit extracts font size, fill color, and stroke via offline/online OCR, inpaints clean 9-slice base plates, and writes native Photoshop TySh text layers into the .psd so you can double-click to edit text in Photoshop or Photopea. See Manual §8.3.

How does it keep faces, outfits, and voices consistent across short-drama episodes?

Stage 3 of film.workbench locks character base anchors, #variant wardrobe cards, scene plates, a STYLE01 style bible, and persistent cross-episode TTS voice profiles; Stage 4 injects @1–@4 anchors into every shot and runs VLM Vision QC auto-reshoots. See the short-drama guide.

What can the Machinations v2 Game Economy Studio simulate and export?

game.economy aligns 100% with Machinations semantics (59 verified blocks, Simple ↔ Pro lossless toggle). In v8.9.1 you can drag target curve points or the purple Bezier slope diamond (◆) at 120fps to inversely solve progression formulas (Goal-Seek), run Monte Carlo & 2D sensitivity sweeps, playtest HUD cards, and export Unity C# / Godot GDScript.

How do Claude Code, Cursor, or Codex control AI Art Engine via MCP?

The desktop app hosts an authenticated local MCP server on 127.0.0.1 exposing 102 tools (93 on /mcp + 9 on /mcp/blender). Run claude mcp add aiartengine -- node ./resources/mcp-bridge.mjs to connect. See the MCP setup guide.

How does Workflow-in-PNG (aiae:graph) work?

Every PNG exported from AI Art Engine embeds its full node graph and prompt recipe inside a lossless aiae:graph PNG metadata chunk. Dragging that PNG back onto the canvas restores the complete pipeline immediately.
