Manual · Workspace · v9.0.0

Workspace, AI Chat & asset library

The dockable workspace layout and Multi-Fairy Wish Maiden weather system; the ◈ AI Chat in-process Pi Agent runtime, up to 6 parallel cross-project sessions, load_toolset lazy MCP loading, live sandbox toggle, and 24-hour scheduled automations; skills and the Skill Marketplace; plus the asset library.

5. Workspace

Opening a workspace (workspace.json / project.json) brings up the main dockable multi-pane studio interface.

5.1 Top bar

  • Unsaved changes show * next to the title; press Ctrl+S to save.
  • ↶ / ↷: undo / redo (also available as shortcuts).
  • One-Click Workflow: generate a reusable host asset from a built-in preset (such as builtin.video-breakdown-remake) or AI natural-language planning (see §7).
  • Film Workbench: double-click a film.workbench node in the node graph to enter the full-screen Dive workbench for the 21-genre, 5-stage AI Comic / Short Drama loop (beat breakdown → 11-point audit → cast/scene/TTS voice → batch shoot & Vision QC → release pack & full MP4; see §9).
  • Task list and Run log: background queue and model / MCP tool call logs.
  • Skill Marketplace & Settings: immediately to the left of the Settings gear sits the Skill Marketplace launcher (see §5.7).
  • Layout: switch the default layout, save the current layout, export / import a layout .json, or delete custom layouts.

Tip: drag a tab to dock it in another area; right-click a tab to float it, detach it into a new window, or close related tabs. Key panels can't be closed while nodes are running.

5.2 Core panels

Panel Purpose
Tools Narrow left column with shortcuts for creating asset drafts.
Workspace canvas The central editor; empty state shows recommended flows and recent assets, opened assets become tabs, and dropping any aiae:graph recipe PNG unpacks the workflow in place.
◈ AI Chat Right-hand agent hub featuring an expandable left sidebar (multi-project switcher, conversation threads, scheduled automations, and workspace file tree) plus an embedded file editor (see §5.5).
Assets Browse, filter, package, and drag-move items in the project asset library.
Parameters Inspector panel for the currently selected node or Dive element.

5.3 Left toolbar: create assets

Click an icon to create a draft asset, then press Ctrl+S after editing to write it to disk. You can create:

  • Free canvas · host asset · script · world elements · shot · director stage · image · video · audio

Recommended flow in an empty workspace: One-Click Workflow / Skill Marketplace → Host Asset → Run Graph, or create scripts, a Film Workbench, or a 3D Director Stage directly.

5.4 Right rail: assets / parameters / AI Chat

The far right of the workspace is a Rider-style vertical rail; the Assets, Parameters, and ◈ AI Chat panels can be expanded or collapsed independently (collapsed panels take zero width from the center canvas).

  • Click a rail button to toggle the matching side panel.
  • You can drag “Assets” above or below “Parameters”; drop previews only appear in the top / bottom halves (half-screen left / right previews are disabled to avoid leftover grey frames).
  • The layout menu saves the expanded geometry, while collapse preferences are remembered separately — a collapsed state is never written as a zero-width grey hole.

5.5 ◈ AI Chat panel (In-process Pi Agent · 6 parallel sessions · Universal control)

Open ◈ AI Chat on the right side of any workspace to launch the built-in AI agent hub. In v9.0.0 it runs an in-process Pi Agent runtime (built on @earendil-works/pi-agent-core & @earendil-works/pi-ai inside src/main/agent/), perceiving your active editor surface (Node Graph, all Dive workbenches, Machinations v2 studio, 3D Director Stage, Final Timeline, Script) and calling all 102 local MCP tools, external MCP servers, and live web search — anything you can adjust manually on the canvas, inside a Dive workbench, or in the Inspector can be driven conversationally in a single prompt.

  • ⚡ Zero-Key Instant Demo (starter experience): Even with zero API keys configured, click “⚡ Zero-Key Instant Demo” inside ◈ AI Chat to run a live local Xianxia RPG Equipment UI decomposition + 3D Exploded Layer Split → native editable TySh text-layer .psd / Unity UGUI / Godot 4 pipeline.
  • Multi-project sidebar, up to 6 parallel sessions & lock-free model switching: Toggle the left sidebar inside ◈ AI Chat to create or switch between multiple projects (project.json) within the active workspace (workspace.json), run up to 6 parallel chat sessions across projects with live status dots, and inspect or edit scripts, JSON configs, and Markdown skills in the embedded workspace file editor. Sessions persist as lock-free atomic JSON files in <userData>/dsh-harness/pi-sessions/ (with project memory in <userData>/dsh-harness/memory/), allowing seamless mid-session model switching across providers without write-lock errors.
  • On-demand lazy MCP toolset loading (load_toolset) & live orchestration: Each session starts with ~24 core tools and dynamically activates Studio/Blender domain toolsets and external MCP tools (ext:<serverId>) on demand via load_toolset with LRU eviction (<= 96 active tools, well below the 128-tool OpenAI/DeepSeek API ceiling — so mounting multiple external MCP servers in Settings → MCP never triggers tools array too long errors). Every tool call (skill_install, workflow_use_installed, graph_edit, task_run, vision_local_ocr, machinations_studio) streams live progress cards.
  • @ asset references & native web search: Type @ to inline project images, videos, audio, or 3D models with thumbnail previews; built-in web_search and web_fetch tools query providers configured under Settings → Web search.
  • Craft / Plan / Ask modes (dual-layer runtime tool gating): Switch between Craft (full execution), Plan (strictly read-only planning until you confirm via the ask_user card), and Ask (zero-tool Q&A), enforced by dual-layer runtime tool gating and aligned with MCP X-MCP-Mode scoping.
  • Seamless BYOK model picker: Pick or switch to any enabled text model with an API key (OpenRouter, DeepSeek, Claude, GPT, Gemini, local Ollama, …) idle or mid-session; your choice persists automatically.
  • Live sandbox toggle & interactive approval cards: Toggle between 🛡️ Restricted Mode (workspace-write) ↔ 🔓 Full Access (danger-full-access) right from the chat toolbar (idle or mid-turn), paired with interactive permission approval cards offering Allow Once / Always Allow / Reject (“Always Allow” persists per project, while unanswered non-interactive paths fail closed).
Ready out of the box: The Pi Agent runtime executes directly inside the main process (with Node.js also bundled for local bridges and scripts) — no external subprocess or developer toolchain required. The Zero-Key Instant Demo requires no keys; cloud chat turns require at least one enabled text model.

5.6 Skills

The chat agent carries a rich catalog of creation skills (covering film storyboarding, Game UI splitting, Machinations economy design, and 3D directing), and you can install community skill bundles or drop in custom skills via the Skills tab of the Skill Marketplace.

  • Built-in skills: 21-genre storyboard breakdown, 11-point continuity & Vision QC audit, Game UI layer decomposition & atlas composition, Machinations v2 balancing, 4-axis video forensics, plus prompt engineering, lighting, multi-angle camera, portrait retouching, and inpainting (managed automatically — do not edit manually).
  • Custom skills: Open Skill Marketplace → Skills → Open folder (located at <userData>/dsh-harness/skills/) and drop in a kebab-case .md file in SKILL.md format (frontmatter name / description + Markdown instructions, e.g. my-skill.md), or click “Create sample template”.
  • Skills + MCP tools: Skills are injected via <available_skills> to teach domain SOPs (how to structure work), while live MCP tools (graph_edit, workflow_use_installed, task_run) execute the actual mutations and renders.
  • Bundled workflow skills: Workflows installed from the Skill Marketplace may bundle companion skills (badged skill bundle) whose lifecycle follows the parent workflow.

5.7 Skill Marketplace

Clicking “Skill Marketplace” immediately to the left of “Settings” in the top bar opens a dedicated singleton window for discovering and installing official and community workflow bundles, domain skills, and MCP servers (accessible even before opening a workspace).

Tabs include All / MCP / Skills / Workflows. Opening the window force-refreshes the catalog from the official GitHub primary source with automatic fallback to the Gitee mirror (and graceful cached fallback when offline). To publish your own bundles, see the Skill Marketplace developer docs.

Install, update and uninstall

  • Workflow cards provide one-click Install / Update / Reinstall / Uninstall and Details (agents can also install via skill_install).
  • Uninstalling prompts for confirmation and cleanly removes local files along with any bundled companion skills.

Script disclosure & explicit per-install consent

  • Entries carrying companion skills or executable scripts display clear “Includes skill” or “Includes skill + scripts” badges upfront.
  • Whenever a bundle includes scripts, an explicit consent dialog lists every script path before writing anything to disk: confirming writes the scripts; cancelling installs only the Markdown instructions and references while keeping the node workflow fully usable. Consent is requested every time — never silently remembered.

Mounting installed workflows & managing MCP servers

  • Click “Skills” in the ◈ AI Chat composer toolbar or type /skills to insert a workflow pill; on send, the agent calls workflow_use_installed by ID to reproduce the exact topology rather than guessing from scratch.
  • Under Skill Marketplace → MCP, inspect the built-in aiartengine (93 tools) and blender (9 tools) endpoints or register/test third-party remote HTTP and local stdio MCP servers.

5.8 Scheduled automations (24-hour unattended runs)

v9.0.0 ships a built-in 24-hour (00:00–23:59) Scheduled Automations runner that wakes ◈ AI Chat and installed workflows on your clock for unattended daily content pipelines:

  • Full-day 00:00–23:59 scheduling: Configure daily or recurring triggers at any minute across the 24-hour clock (for example: overnight trend scraping → short-drama storyboard drafts, scheduled competitor video forensic breakdowns via rea-video, or off-peak batch localization renders).
  • Per-project & skill binding: Bind each schedule to a target workspace/project (project.json), model, and prompt (including /skills workflow pills).
  • Toggle, test-run & audit trail: Create, pause/resume, trigger an immediate test run, or delete schedules right from the ◈ AI Chat sidebar; every automated session, generated asset, and MCP audit log entry persists locally for review.

5.9 Multi-Fairy Wish Maiden & procedural weather

To bring atmosphere and companionship to parallel sessions and long production runs, the node canvas features an interactive Multi-Fairy Wish Maiden (祈愿巫女) alongside four real-time procedural weather ambiences:

  • Multi-Fairy Wish Maiden accompaniment: An optional interactive companion on the canvas that scales into multi-fairy accompaniment when parallel AI Chat sessions are running — click to draw fortune slips for smooth renders and zero face drift, or toggle visibility anytime from canvas appearance controls.
  • Four procedural weather modes: Switch effortlessly between Sunny, Sakura Snow, Aurora, and Meteor Shower — lightweight procedural particle and sky shaders engineered to never obstruct node ports or wire hit-testing.

6. Asset library

Browse and filter

  • Refresh next to the “Assets” title; search and type filters are supported.
  • The slider at the bottom switches between list view and icon view.
  • A breadcrumb shows the path, e.g. Assets > …
  • Marquee multi-select is supported; you can drag images / videos / audio / models / .aipackage in from your system.
  • Multi-select files / folders dragged to another directory: left-side directory rows and right-side asset cards are both draggable; drag a batch of files or multiple folders onto a target directory at once (everything goes through the folder_move IPC + the same on-disk rules: physical move + descendant asset.relativePath rewrite + cycle detection + duplicate-name auto-append " 2" / " 3"). Dragging within the same parent only rewrites .folder.json and doesn't move any data on disk. The asset library root cannot be dragged out of.

Right-click empty space or a folder

  • Create assets of any type, create a folder.
  • Import asset package / Export asset package.
  • Folders additionally offer: reimport, rename, delete folder (contents move up), delete folder with contents.

Right-click an asset

  • Open editor · reveal in file manager · copy original file.
  • Reimport · export asset package · rename · find references · delete.

Shortcuts with the asset library focused

  • Delete / Backspace: delete the selection.
  • Ctrl+A: select all.
  • Ctrl+C: copy-original-file related action.
