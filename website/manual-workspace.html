工作区、AI 对话与资产库

工作区的顶栏、可停靠面板布局与画布祈愿巫女天气系统，右侧 ◈ AI 对话 面板的可展开多工程侧边栏、内置工作区文件编辑器、零 Key 极速体验与 24 小时定时任务，技能系统与技能市场（Skill Marketplace），以及资产库管理。

5. 工作区

打开工作区（workspace.json / project.json）后进入主创作界面，采用可自由拖拽停靠的多面板布局。

5.1 顶栏

  • 未保存时标题旁显示 *；用 Ctrl+S 保存。
  • ↶ / ↷：撤销 / 重做（亦可用快捷键）。
  • 一键工作流：用内置预设（如 爆款视频拆解复刻）或 AI 自然语言规划生成可复用宿主资产（见 §7）。
  • 影视工作台：在节点图中双击 film.workbench 节点进入全屏 Dive 界面，一站式完成 21 题材五阶段闭环（分镜拆解 → 11 项导演审核 → 角色换装/场景/音色设定 → 批量拍摄质检 → 宣发包与成片导出，见 §9）。
  • 任务列表、执行日志：后台队列与模型 / MCP 工具调用日志。
  • 技能市场与设置：顶栏右侧「设置」齿轮左侧即为「技能市场」独立窗口入口（见 §5.7）。
  • 布局：切换默认布局、保存当前布局、导出/导入布局 .json、删除自定义布局。

提示：拖动标签可停靠到不同区域；标签右键可浮动、分离到新窗口或关闭相关标签。节点执行中不可关闭关键面板。

5.2 核心面板

面板 作用
工具 左侧窄栏，快捷新建各类资产草稿。
工作区画布 中心编辑器；空态显示推荐流程与最近资产，打开资产后为多标签页，并支持拖入 aiae:graph 配方 PNG 原地展开工作流。
◈ AI 对话 工作区右侧常驻 / 可展开的 Agent 协作中枢；自带可展开左侧边栏（多工程切换、会话历史、定时任务与工作区文件树）及内置文件编辑器（见 §5.5）。
资产 工程资产库浏览、筛选、打包与跨目录拖拽管理。
参数 当前选中节点或 Dive 元素的 Inspector 参数面板。

5.3 左侧工具栏：新建资产

点击图标创建草稿资产，编辑后用 Ctrl+S 落盘。可新建：

  • 自由画布 · 宿主资产 · 剧本 · 世界元素 · 场 · 导演台 · 图片 · 视频 · 声音

空工作区推荐流程：一键工作流 / 技能市场 → 宿主资产 → 节点运行，或按影视创作流程新建剧本、影视工作台与 3D 导演台。

5.4 右侧竖栏：资产 / 参数 / AI 对话

工作区右侧为 Rider 式竖栏，可分别展开或收起资产、参数与◈ AI 对话面板（收起后不占中间画布宽度）。

  • 点击竖栏按钮切换对应侧栏显示。
  • 可将「资产」拖到「参数」上方或下方叠放；拖放预览仅在上下半区出现（半屏 left/right 预览已禁用，避免灰框残留）。
  • 布局菜单保存的是展开几何；侧栏收起偏好单独记忆，不会把收起态写成零宽灰洞。

5.5 ◈ AI 对话面板（多工程侧栏 · 内置文件编辑器 · 全工作区直控）

点击工作区右侧的 ◈ AI 对话 打开应用内原生 Agent 协作面板。它运行内置的 DeepSeek Harness（dsh）运行时，实时感知当前焦点编辑器（节点图、全部 Dive 专业工作台、Machinations v2 沙盘、3D 导演台、成片时间线、剧本），并直接调用本地 102 个 MCP 工具与实时联网搜索—— 所有手动可在画布、Dive 工作台或 Inspector 中完成的操作，都可以在对话中用一句话驱动。

  • ⚡ 零 Key 极速体验（新手免配置入口）：在尚未填写任何 API Key 时，直接点击 ◈ AI 对话 欢迎区的 「⚡ 零 Key 极速体验」，系统即刻在本地自动运行一套仙侠 RPG 装备界面拆解 + 3D 爆炸视图分层预览 → 导出原生可编辑 TySh 文本图层 .psd / Unity UGUI / Godot 4 的完整演示流水线。
  • 可展开多工程左侧边栏与内置工作区文件编辑器：点击 ◈ AI 对话 顶部的侧栏展开按钮，即可打开多工程管理侧边栏——支持在同一工作区（workspace.json）下新建或秒切不同子工程（project.json）、管理多条持久化对话会话、浏览工作区磁盘文件树，并直接在内置工作区文件编辑器中查阅与修改剧本、JSON 配置、Markdown 技能或脚本文件，无需切出应用。
  • 全工作区感知与 MCP 工具直控：无论是安装并挂载市场工作流（调用 skill_install、workflow_use_installed）、增删连线编辑节点图并触发执行（调用 graph_edit、task_run）、运行本地离线 OCR 识别 UI 文字（调用 vision_local_ocr），还是操控 Machinations v2 经济沙盘仿真与曲线反推（调用 machinations_studio）或调度 3D 导演台机位灯光，工具执行进度均以实时状态卡片回显。
  • @ 引用资产与原生联网搜索：输入 @ 弹出工程资产选择器（支持图片 / 视频 / 声音 / 3D 模型缩略图内联引用）；同时内置 web_search 与 web_fetch 工具，可结合 设置 → 联网搜索 实时检索参考资料与竞品页面。
  • Ask / Plan / Craft 三档模式：自由切换只读问答（Ask）、沙箱规划（Plan）与全权执行（Craft），并与 MCP 的 X-MCP-Mode 权限模型严格对齐。
  • 任意 BYOK 文本模型选择：面板底部可选用任一已配置密钥的文本模型（OpenRouter、DeepSeek、Claude、GPT、Gemini、本地 Ollama 等），偏好自动记忆。
  • 越界需单次授权（Fail-Closed）：当 Agent 需要执行越过沙箱边界的操作时，对话内会弹出「需要你授权这一步」卡片，列明工具与原因，仅提供「允许一次」与「拒绝」（刻意不设「总是允许」）；无人应答的路径一律按失败即拒绝处理。
开箱即用：应用已内置 Node.js 与 dsh 运行时，无需安装外部开发环境。「⚡ 零 Key 极速体验」免密钥即可运行；常规 AI 对话需至少启用一个文本模型。

5.6 技能（Skills）

AI 对话的 Agent 携带一套创作技能（来自应用内置的分镜 / 游戏 UI / 数值 / 导演台专业规范，对话时自动注入）； 你也可以在技能市场的「技能」页签里安装社区技能包或放入自定义技能。

  • 内置技能：涵盖 21 题材影视分镜拆解、11 项导演连贯性审核、游戏 UI 拆层与图集组装、Machinations 经济建模、爆款视频四轴取证，以及图生提示词、多角度机位、打光、美颜精修、扩图重绘等系统创作规范（程序自动维护，请勿手动改动）。
  • 自定义技能：在技能市场 → 技能页签点击「打开目录」，放入符合 SKILL.md 规范（frontmatter name / description + Markdown 正文，文件名小写连字符如 my-skill.md）的文档，下次对话自动生效；可点「生成示例模板」快速起步。
  • 技能与 MCP 工具协同：技能清单通过 <available_skills> 按需注入上下文——技能定义领域 SOP（怎么做），而 graph_edit、workflow_use_installed、task_run 等 MCP 工具负责实际落盘与执行。
  • 随工作流附带的技能包：从技能市场安装工作流时若附带技能包，会在「技能」页签标注来源为「技能包」，生命周期跟随所属工作流（卸载工作流时一并清理）。

5.7 技能市场（Skill Marketplace）

顶栏右上角「设置」左侧的「技能市场」打开一个独立单例窗口：官方与社区发布的工作流包、领域技能包与第三方 MCP 服务都在此一站式浏览与安装（无需先打开工程即可访问）。

窗口包含 全部 / MCP / 技能 / 工作流 四个页签。每次打开都会自动刷新目录（GitHub 官方主源 + Gitee 国内镜像自动降级切换，离线或刷新失败时保留本地缓存目录并给出轻提示）。想自己打包发布工作流与技能包？请参阅 技能市场开发者文档。

安装、更新与卸载

  • 卡片直接提供 安装 / 更新 / 重新安装 / 卸载 与 详情（也可在对话中让 Agent 调用 skill_install 安装）；有新版本时自动标记「有更新」。
  • 卸载经应用确认框二次确认后删除本地文件；若工作流附带技能包则同步移除。

脚本透明披露与显式同意

  • 附带技能或可执行脚本的工作流会在卡片上醒目标注「含技能」或「含技能 · 含脚本」。
  • 凡含本地脚本的包，安装前必弹出确认框逐条列出脚本路径与用途：点「确定」才写入脚本；点「取消」仅安装 Markdown 规范与参考资料（脚本不落盘，节点工作流本体照常可用）。每次安装/更新均重新询问，绝不静默放行。

在 AI 对话与一键工作流中使用

  • 在 ◈ AI 对话 输入框上方点击「技能」按钮或输入 /skills，选中已安装条目即可插入胶囊引用块；发送后 Agent 调用 workflow_use_installed 按 ID 1:1 精确复现整张工作流，而非重新猜测拓扑。
  • 在技能市场 → MCP 页签中，还可直接查看内置 aiartengine（93 工具）与 blender（9 工具）状态，或添加/测试第三方 HTTP 与本地 stdio MCP 服务。

5.8 定时任务（24 小时无人值守自动化）

v8.9.1 内置全天候 24 小时（00:00–23:59）定时任务（Scheduled Automations）调度器，支持在指定时间点或周期自动唤醒 ◈ AI 对话 Agent 与已安装工作流，实现无人值守的日常内容生产与巡检：

  • 全时段精确调度：支持在 00:00–23:59 任意分钟级时间窗设置每日定时或周期触发规则（例如凌晨自动抓取热点文案 → 调用 short-drama 跑出分镜初稿、定时批量拉取竞品视频执行 rea-video 四轴取证拆解、或夜间批量渲染多语言电商变体）。
  • 绑定工作区、模型与技能：每条定时任务独立绑定目标工作区 / 子工程（project.json）、执行模型与自然语言指令（可携带 /skills 工作流引用）。
  • 启停控制与运行审计：在 ◈ AI 对话 侧边栏的定时任务视图中可随时新建、暂停/启用、立即试跑一次或删除任务；每次自动触发的会话记录、节点产出与工具审计日志均完整落盘，次日打开工作区即可直接审阅成片。

5.9 画布祈愿巫女与程序化天气系统

为了让高强度的节点编排与等待渲染过程更具沉浸感与陪伴感，工作区节点画布内置了可交互的祈愿巫女（Wish Maiden）与实时程序化天气渲染层：

  • 祈愿巫女（祈愿巫女）：驻留在画布角落的看板伙伴（支持点击互动抽签祈愿，祈求「抽卡不崩脸、一次过审、渲染秒出」，亦可在画布外观开关中随时隐藏或开启）。
  • 四种程序化天气氛围：支持在画布工具栏一键切换 晴空（Sunny）、樱吹雪（Sakura Snow）、极光（Aurora） 与 流星雨（Meteor Shower） 四套轻量级 GPU/Canvas 程序化粒子与光影天气，渲染开销极低且绝不遮挡节点连线与端口交互。

6. 资产库

浏览与筛选

  • 标题「资产」旁可刷新；支持搜索与类型筛选。
  • 底部滑条在列表视图与图标视图间切换。
  • 面包屑显示路径，如 Assets > …
  • 支持框选多选；可从系统拖入图片 / 视频 / 声音 / 模型 / .aipackage。
  • 多选文件 / 多选目录拖拽到其它目录：左侧目录树行与右侧资产卡片均加 draggable，可一次拖多枚文件或多个目录到目标目录（统一走 folder_move IPC + 同名落盘：磁盘搬移 + descendant asset.relativePath 写回 + 成环检测 + 同名追加 " 2" / " 3"）。同源目录内部拖拽仅写 .folder.json、不挪磁盘。资产库根目录不可拖出。

空白或目录右键

  • 新建各类资产、新建目录。
  • 导入资产包 / 导出资产包。
  • 目录另有：重新导入、重命名、删除目录（内容上移）、删除目录及内容。

资产右键

  • 打开编辑器 · 在文件管理器中显示 · 复制原始文件。
  • 重新导入 · 导出资产包 · 重命名 · 查找引用 · 删除。

资产库焦点下快捷键

  • Delete / Backspace：删除选中。
  • Ctrl+A：全选。
  • Ctrl+C：与复制原始文件相关操作。
