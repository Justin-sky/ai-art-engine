工作区与资产库

工作区的顶栏、四栏面板与新建资产入口，AI 对话面板、技能系统与插件市场，以及资产库的浏览、筛选、右键操作与快捷键。

5. 工作区

打开工程后进入工作区（应用内导航名称为「工作区」）。界面为可拖拽停靠的多面板布局。

5.1 顶栏

  • 未保存时标题旁显示 *；用 Ctrl+S 保存。
  • ↶ / ↷：撤销 / 重做（亦可用快捷键）。
  • 一键工作流：用预设或 AI 规划生成可复用宿主资产（见 §7）。
  • 剧集流水线：打开短剧分镜 Agent 流程窗口，集中完成 9宫格、4宫格、导演审核与视频生成（见 §7.5）。
  • 任务列表、执行日志：后台队列与模型调用日志。
  • 布局：切换默认布局、保存当前布局、导出/导入布局 .json、删除自定义布局。

提示：拖动标签可停靠到不同区域；标签右键可浮动、分离到新窗口或关闭相关标签。节点执行中不可关闭关键面板。

5.2 四栏面板

面板 作用
工具 左侧窄栏，快捷新建各类资产草稿。
AI 对话 左侧窄栏底部「◈」按钮打开；应用内 AI 助手，可在对话中调用 MCP 工具（见 §5.5）。
工作区 中心编辑器；空态显示推荐流程与最近资产，打开资产后为标签页。
资产 工程资产库浏览与管理。
参数 当前选中项的 Inspector 参数面板。

5.3 左侧工具栏：新建资产

点击图标创建草稿资产，编辑后用 Ctrl+S 落盘。可新建：

  • 自由画布 · 宿主资产 · 剧本 · 世界元素 · 场 · 导演台 · 图片 · 视频 · 声音

空工作区推荐流程：剧本 → 场 → 节点生成；也可快捷新建剧本、场、导演台，或双击最近资产打开。

5.4 右侧竖栏：资产 / 参数

工作区最右侧为 Rider 式竖栏，可分别展开或收起资产与参数面板（收起后不占中间布局宽度）。

  • 点击竖栏按钮切换对应侧栏显示。
  • 可将「资产」拖到「参数」上方或下方叠放；拖放预览仅在上下半区出现（半屏 left/right 预览已禁用，避免灰框残留）。
  • 布局菜单保存的是展开几何；侧栏收起偏好单独记忆，不会把收起态写成零宽灰洞。

5.5 AI 对话面板

左侧窄栏底部的 ◈ AI 对话 打开应用内 AI 助手。它运行 DeepSeek Harness（dsh） agent 运行时，能像外部 Agent 一样调用应用自带的 MCP 工具服务—— 相当于在聊天窗口里直接驱动生成与工程操作。

  • @ 引用资产：输入 @ 弹出资产选择器，可把工程内图片 / 视频 / 声音 / 3D 模型 内联引用进指令（输入区会显示缩略图预览）。dsh 直接解析文本里的 @路径。
  • 调用生成工具：让助手「把 @bg.png 生成一张标题图存进工程」——它会调用 generate_image 等 MCP 工具，工具执行过程以卡片形式实时显示（生成中 / 完成 / 失败）。
  • 模型选择：面板底部可选用任一已配置密钥的文本模型（不限于 DeepSeek 官方）；选择会记住，下次打开沿用。
  • 多会话：输入框上方工具栏可新建 / 切换 / 删除会话，历史消息本地持久化。
  • 取消与状态：执行中可停止；dsh 的状态行与工具活动实时回显在面板中。
  • 越界需授权：Agent 需要越过沙箱边界时，对话里会出现「需要你授权这一步」授权卡， 写明工具名与申请原因，只提供「允许一次」与「拒绝」两个选项。 授权只对这一次调用有效——应用刻意不提供「总是允许」，避免一次点击悄悄放宽 Agent 之后能跑的东西。 没有人能应答这条请求时（例如兜底的一次性执行路径），请求按失败即拒绝处理：它会被拒掉，绝不会默认放行。
前提：AI 对话已内置 Node.js 运行时与 dsh 运行体，开箱即用、无需安装任何环境 （极少数特殊环境才会回退联网拉包）；另需至少一个已启用并填好密钥的文本模型； 未打开工程时仅可做纯对话。

5.6 技能（Skills）

AI 对话的 Agent 携带一套创作技能（来自应用内置的分镜 / 导演台能力，对话时自动注入）； 你也可以在插件市场的「技能」页签里放入自己的技能，让助手具备专属的工作方法。

  • 内置技能：分镜 / 动画（9 宫格分镜表、节拍拆解表、动态提示词表、4 宫格动态分镜表等）、 导演审核（分镜 / 节拍 / 动态提示词）、系统创作（剧本、图生提示词、图片 / 视频生成、声音、情绪、灯光、 多角度、扩图、重绘、抠图、高清放大、界面图、界面拆分、世界提取、节拍拆分、节拍单元生成、策划案、 肖像贴图、提示词优化、擦除）。程序自动管理，请勿手动修改。
  • 自定义技能：在插件市场 → 技能页签里「打开目录」，把符合 dsh SKILL.md 格式（frontmatter name / description + Markdown 正文）的 .md 文件放进技能目录（文件名用小写字母 + 连字符，如 my-skill.md）， 下次对话自动生效；同一页签的「生成示例模板」可给出一份可用的写法参考。
  • 技能如何生效：技能清单以 <available_skills> 注入对话上下文， Agent 判断任务匹配时按需加载技能文件作为指令——技能告诉它流程与规范（怎么做）， MCP 工具负责真正动手（生成图片、跑工作流），两者配合才能「说到做到」。
  • 节点图节点使用同一套技能定义节点行为；API 调用日志中会标注节点所用的技能。
  • 技能包：从插件市场安装工作流时可能随包附带技能包。它会在市场的 技能页签里列出，来源标记为「技能包」；它跟着所属工作流走， 卸载那条工作流时会一并删除，因此不是可以单独管理的产物。
技能 vs 工具：技能是「职业手册」，工具是「手脚」。例如说 「用分镜技能把这段剧本拆成 9 宫格分镜表」——技能提供专业流程（节拍 → 机位 → 动态 → 提示词）， 生成动作由工具执行。

5.7 插件市场（Plugin Marketplace）

顶栏「设置」左边的「插件市场」打开一个独立窗口：MCP 服务、技能与工作流都在这里安装。 它是应用级入口——不需要先打开工程；窗口是单例，再点一次只会把已经开着的窗口聚焦到前台。

页签为 全部 / MCP / 技能 / 工作流。每次打开窗口都会强制刷新工作流目录， 所以刚发布的工作流重开窗口就能看到，不必等缓存过期；刷新失败时会保留上一次读到的列表并给一句软提示， 不会把市场显示成空的。目录有两个来源：官方主源（GitHub raw）与 Gitee 镜像，按顺序尝试、失败自动降级， 窗口顶部会说明当前读到多少条（切到镜像时提示「主源不可达，已切换到镜像」），离线时提示显示的是上次缓存的目录。

想自己发布工作流 / 技能包？见插件市场开发者文档。

安装、更新与卸载

  • 工作流卡片上直接带 安装 / 更新 / 重新安装 / 卸载 与 详情； 已安装的条目会标出状态，有新版本时显示「有更新」。
  • 卸载走应用自己的确认框；确认后本地已装的文件会被删除。如果这条工作流还带了技能包， 卸载时会一并移除它装下的技能。
  • 市场只负责「装到本机」：装好的工作流在 AI 对话里使用（见下）。

含技能的条目与脚本同意

  • 一条工作流可以随包附带技能包：卡片上标「含技能」，包里还有脚本时标 「含技能 · 含脚本」——装之前就能看到。
  • 技能包里的脚本是AI agent 可以在这台机器上跑起来的代码，因此只有在你明确同意时才会写入： 安装前会弹确认框，逐条列出每一个脚本路径，并说明这些脚本的性质。点「确定」写入脚本； 点「取消」则只安装说明书与 references，脚本不落盘——工作流照常可用。
  • 这份同意每次都问：应用不会记住「以后都允许」。
  • 装好的技能包同时出现在市场的技能页签里（来源标记为「技能包」）， AI 对话的 Agent 可以直接加载使用。它跟着所属工作流走：卸载那条工作流会一并删除它， 不是可以单独管理的产物。

MCP 页签

  • 内置 MCP 工具服务（aiartengine）与 Blender 工具集的查看入口， 详见 §4.5 与 MCP 接入教程。
  • 也可以添加第三方 MCP 服务：HTTP（远程）填服务地址与请求头，stdio（本地命令）填命令、参数与环境变量； 保存前可「测试连接」，直接看到能发现多少个工具。stdio 会在本机执行第三方程序，只添加你信任来源的服务。

在 AI 对话里使用已安装的工作流

  • 入口有两个：AI 对话输入框上方工具栏的「工作流」按钮，或直接输入 /workflow。
  • 选中一条工作流后，输入框里插入的是一个引用块（图标 + 标题的胶囊），而不是把标题 / id / 简介 摊成一段文字；悬停可以看到含 id 的完整引用。
  • 发送时 Agent 按 id 调用这条已安装的工作流（workflow_use_installed）， 精确复现它，而不是重新规划一个相似的东西。
两道闸：安装时的脚本同意解决的是「代码会不会落盘」；Agent 运行时真正要越过沙箱边界时还有第二道闸—— 对话里的「需要你授权这一步」授权卡，只有「允许一次 / 拒绝」，没有「总是允许」， 无人应答的路径按失败即拒绝处理（见 §5.5）。

6. 资产库

浏览与筛选

  • 标题「资产」旁可刷新；支持搜索与类型筛选。
  • 底部滑条在列表视图与图标视图间切换。
  • 面包屑显示路径，如 Assets > …
  • 支持框选多选；可从系统拖入图片 / 视频 / 声音 / 模型 / .aipackage。
  • 多选文件 / 多选目录拖拽到其它目录：左侧目录树行与右侧资产卡片均加 draggable，可一次拖多枚文件或多个目录到目标目录（统一走 folder_move IPC + 同名落盘：磁盘搬移 + descendant asset.relativePath 写回 + 成环检测 + 同名追加 " 2" / " 3"）。同源目录内部拖拽仅写 .folder.json、不挪磁盘。资产库根目录不可拖出。

空白或目录右键

  • 新建各类资产、新建目录。
  • 导入资产包 / 导出资产包。
  • 目录另有：重新导入、重命名、删除目录（内容上移）、删除目录及内容。

资产右键

  • 打开编辑器 · 在文件管理器中显示 · 复制原始文件。
  • 重新导入 · 导出资产包 · 重命名 · 查找引用 · 删除。

资产库焦点下快捷键

  • Delete / Backspace：删除选中。
  • Ctrl+A：全选。
  • Ctrl+C：与复制原始文件相关操作。
