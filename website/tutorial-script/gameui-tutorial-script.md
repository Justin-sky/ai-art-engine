# 游戏 UI 工作流 · 剪映教程脚本

> 适用于剪映「AI 创作 · 文生视频」：逐条复制画面提示词生成镜头，拖入轨道拼接；
> 界面类画面用真实录屏（剪映文生视频生成文字和界面容易乱码）。
> 对应功能：一键工作流「游戏UI界面」模板 + 全局风格参考（风格库「UI 风格」分类）。

## 使用说明

1. **生成画面**：打开剪映 → AI 创作 → 文生视频 → 把下方某条「画面提示词」整段复制粘贴 → 生成，重复此步骤得到全部镜头。
2. **拼接**：按镜头编号顺序把生成结果拖入轨道；涉及软件界面 / 文字的镜头（见「录屏镜头」）用实际录屏，不用 AI 生成。
3. **配音**：新建文本 → 把对应「配音文案」粘贴到文本朗读 → 生成旁白拖到音频轨。
4. **字幕**：用每条「字幕要点」做字幕条。
5. **结尾展示片**：把工作流生成的 UI 界面图导入剪映，按顺序拖入轨道做成 UI 展示片（每张约 3 秒，加轻量转场）。

## 一、AI 生成镜头

### 镜头 1（约 6 秒）

画面提示词（复制整段）：

> 现代科技感游戏工作室，一位年轻的游戏 UI 设计师趴在堆满策划文档和手绘界面草图的桌前，纸上密密麻麻写满界面布局和控件标注，他揉着太阳穴露出疲惫的表情，镜头缓慢推近，柔光，电影感，画面清晰。

配音文案：

> 做游戏 UI 最头疼的是什么？读策划、拆界面、一张一张画，还要保证整套画风统一。

字幕要点：

> 策划文档 → 拆界面 → 逐屏出图，还要统一风格

画面提示词（复制整段）：

## 二、录屏镜头（软件界面用实际录屏，不用 AI 生成）

剪映文生视频生成文字和界面容易乱码，以下镜头请用真实软件录屏：

| 镜头 | 录屏内容 | 对应脚本 |
| --- | --- | --- |
| A | 顶栏「一键工作流」→ 选「游戏UI界面」→ 预览模板 → 创建工作流 | 对应镜头 2 |
| B | 双击宿主资产查看自动生成的节点链路（策划案生成 → UI界面拆分 → UI界面生成） | 对应镜头 3 |
| C | 策划案生成节点填写需求并运行；双击「UI界面拆分」打开指令面板，运行后输出各界面提示词数组 | 对应镜头 3 |
| D | 双击「UI界面生成」进入内图，逐屏运行出图；回外层点 Cook 汇集全部界面图 | 对应镜头 4 |
| E | 风格库选择「UI 风格」分类中的一张风格图，设为全局风格参考后重新生成对比 | 对应镜头 5 |

## 三、拼接与配音顺序

1. 时间轴顺序：镜头 1 → 2 → 录屏 A → 3 → 录屏 B / C → 4 → 录屏 D → 5 → 录屏 E → 6。
2. 镜头之间加淡入淡出转场，避免 AI 生成画面跳动。
3. 配音用「文本朗读」按配音文案逐段生成，拖到音频轨后与画面对齐；字幕用每条字幕要点。
4. 结尾 UI 展示片：把工作流生成的界面图导入剪映，每张停留约 3 秒，加轻量转场与界面名称字幕，可配一段轻音乐收尾。

## 四、与其它内容的衔接

- 风格一致性依赖「风格库 → UI 风格」分类与全局风格参考，视频中可提示：先选风格图再重新生成，整套界面更统一。
- 与短剧 Agent 流水线教程可组成系列：一条讲短剧成片，一条讲游戏 UI 批量出图。
