# 生成帧动画序列图 + 特效预设 · 剪映文生视频推广脚本

> 剪映「AI 创作 · 文生视频」：逐条复制画面提示词生成镜头；配音用「文本朗读」；总时长约 90–110 秒。
> 推广功能：节点图「生成帧动画序列图」（`frame.animGen`）与指令面板「特效」预设；可衔接「2D帧动画」（`anim.2d`）切帧播放。

## 使用说明

1. 画面：剪映 → AI 创作 → 文生视频，逐条复制「画面提示词」生成。
2. 拼接：软件界面镜头用真实录屏（见「录屏镜头」），不用 AI 生成。
3. 配音：文本朗读粘贴「配音文案」；字幕用「字幕要点」。
4. 一致性：角色/特效镜头可上传同一张角色参考图或特效风格参考图，避免风格漂移。
5. 特效展示：录屏优先用「火焰 / 斩击 / 爆炸」等一眼能看懂的特效预设。

## 二、录屏镜头（软件界面用真实录屏）

| 镜头 | 录屏内容 | 对应 |
| --- | --- | --- |
| A | 节点图右键 → 动效分组 → 拖入「生成帧动画序列图」/「2D帧动画」并连线 | 镜头 3 |
| B | 接入角色或空白参考图，双击打开指令面板，切到「特效」页，点选火焰 / 斩击 | 镜头 4 |
| C | 设置行列（如 2×4），运行生成，展示序列图结果与多图叠放 / 展开方阵 | 镜头 5、6 |
| D | 运行 2D帧动画切帧，卡片双击播放序列帧 | 镜头 6 |
| E | （可选）并行再建一个特效节点，对比火焰与斩击两套输出 | 镜头 7 |

## 三、拼接与配音顺序

1. 顺序：1 → 2 → 3 → 录屏 A → 4 → 录屏 B → 5 → 录屏 C → 6 → 录屏 D → 7 → 录屏 E（可选）→ 8 → 9。
2. 镜头间加淡入淡出；特效类画面尽量用真实录屏，避免 AI 乱码界面。
3. 配音用「文本朗读」按文案逐段生成，与画面对齐；字幕用每条字幕要点。
4. 提示卡片（行列控制帧数；特效预设写入指令；切帧后可双击播放）做成静态图，放在镜头 9 前约 3 秒。
