# 片段重拍 · 剪映文生视频教程脚本

> 适用于剪映「AI 创作 · 文生视频」：逐条复制画面提示词生成镜头，拖入轨道拼接；
> 配音用剪映「文本朗读」粘贴配音文案生成。总时长约 90 秒。

## 使用说明

1. **生成画面**：打开剪映 → AI 创作 → 文生视频 → 把下方某条「画面提示词」整段复制粘贴 → 生成，重复此步骤得到全部镜头。
2. **拼接**：按镜头编号顺序把生成结果拖入轨道；涉及软件界面的镜头（见「录屏镜头」）用实际录屏片段，不用 AI 生成。
3. **配音**：新建文本 → 把对应「配音文案」粘贴到文本朗读 → 生成旁白拖到音频轨。
4. **字幕**：用每条「字幕要点」做字幕条。
5. **一致性**：所有镜头提示词都以「现代科技感后期工作室、深色界面、柔光、电影感」开头；生成人物镜头时，把同一张人物参考图作为首帧/参考图上传，保证角色统一。

## 二、录屏镜头（软件界面用实际录屏，不用 AI 生成）

剪映文生视频生成文字和界面容易乱码，以下镜头请用真实软件录屏：

| 镜头 | 录屏内容 | 对应脚本 |
| --- | --- | --- |
| A | 节点图右键菜单 → 视频分组 → 选中「片段重拍」拖入画布并连线 | 对应镜头 3、4 |
| B | 双击节点打开重拍台，左右键步进帧、空格播放、标记起点和终点 | 对应镜头 5 |
| C | 指令框输入、@ 引用、选预设、点预览提示词 | 对应镜头 6 |
| D | 模型下拉选 Seedance 2.5，点执行，对比前后成片 | 对应镜头 7 |

## 三、拼接与配音顺序

1. 时间轴顺序：镜头 1 → 2 → 3 → 录屏 A → 4（可省略）→ 5 → 录屏 B → 6 → 录屏 C → 7 → 录屏 D → 8。
2. 镜头之间加淡入淡出转场，避免 AI 生成的人物长相漂移；需要更稳时可每段都上传同一张人物参考图。
3. 配音用「文本朗读」按配音文案逐段生成，拖到音频轨后与画面对齐；字幕用每条字幕要点。
4. 提示卡片（源视频别超过 30 秒、480/720P、按 token 计费）做成一张静态图，放在镜头 8 之前约 3 秒。
