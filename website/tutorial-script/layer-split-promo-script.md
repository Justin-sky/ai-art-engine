# 游戏 AI 图层分离 · 剪映文生视频推广脚本

> 剪映「AI 创作 · 文生视频」：逐条复制画面提示词生成镜头；配音用「文本朗读」；总时长约 90–105 秒。
> 推广功能：节点图「图层分离」（`image.layerSplit`）——Seedream 5.0 Pro 一键把整张游戏 UI 拆成底图 + 透明 PNG 图层；双击进画布拖动、叠放、再拆选中层收进分组；导出全部时分组直接变成文件夹，可进引擎。
> 核心冲突：AI 出图只要 10 秒，PS 拆层要一下午。这期把「拆层」这件事干掉。

## 使用说明

1. 画面：剪映 → AI 创作 → 文生视频，逐条复制「画面提示词」生成。
2. 拼接：软件界面、图层列表、导出文件夹用真实录屏（见「录屏镜头」），不用 AI 生成。
3. 配音：文本朗读粘贴「配音文案」；字幕用「字幕要点」。
4. 一致性：游戏 UI 镜头统一同一套界面风格（暗金手游主界面 / 背包），避免控件乱飞。
5. 炸点优先：录屏一定要拍到「一层变一摞透明层」「选中层再拆成分组」「导出后文件夹就是分组」。

## 二、录屏镜头（软件界面用真实录屏）

| 镜头 | 录屏内容 | 对应 |
| --- | --- | --- |
| A | 上游接一张完整游戏 UI 图 → 添加「图层分离」节点 → 选 Seedream 5.0 Pro → 运行，图库出现底图 + 各透明层 + 合成图 | 镜头 3 |
| B | 双击节点进入画布：点选图层、拖动位置、隐藏底图、上移/下移叠放 | 镜头 4 |
| C | 选中某一层 → 点「拆分选中层」→ 侧栏出现分组，子层缩进在分组里 | 镜头 5 |
| D | 点「导出全部」→ 选文件夹 → 打开资源管理器，展示分组已变成子文件夹 | 镜头 6 |
| E | 可选：导出选中层 / 导出选中分组，对比单文件与文件夹结果 | 镜头 6 |

## 三、拼接与配音顺序

1. 顺序：1 → 2 → 3 → 录屏 A → 4 → 录屏 B → 5 → 录屏 C → 6 → 录屏 D（可接 E）→ 7 → 8。
2. 镜头间加 6–8 帧闪白或急速推近，前两镜要「炸」，后半段用真实录屏把功能钉死。
3. 配音用「文本朗读」按文案逐段生成，跟画面卡点；字幕用每条字幕要点，字号偏大，前三镜可加震动。
4. 软件菜单、按钮名、文件夹名一律用录屏或静态卡片，避免 AI 生成乱码。
5. 结尾 3 秒可叠一张静态卡：`整图接入 → 运行拆层 → 再拆选中层 → 导出分组文件夹`。
