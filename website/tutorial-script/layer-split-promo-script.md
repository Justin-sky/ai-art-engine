# 游戏 AI 图层拆分（16 类控件 + 离线 OCR 可编辑 PSD + 引擎代码）· 剪映文生视频推广脚本

> 剪映「AI 创作 · 文生视频」：逐条复制画面提示词生成镜头；配音用「文本朗读」；总时长约 90–105 秒。
> 推广功能：节点图「图层拆分」（`image.layerSplit`）——支持 **UI 控件拆分（`ui`）**、**2D 立绘拆件（`rig2d`）**、**场景分层（`scene`）** 与 **Seedream 5.0 Pro 自动拆层（`auto`）**；在 `ui` 模式下自动识别 **16 类标准 HTML5 / Unity UI Toolkit 控件**，通过**跨平台本地离线 OCR + 云端 VLM OCR** 提取按钮/面板文字、字色与描边，抹除字迹补全九宫格拉伸底板（`nineSlice`），一键导出**带原生 Photoshop `TySh` 可编辑文本图层与二级嵌套分组的 `.psd`**，以及 **Unity UI Toolkit (`.uxml/.uss`) · Unity UGUI (`.cs`) · Godot 4 (`.tscn`) · HTML5** 界面代码。
> 核心冲突：AI 出图只要 10 秒，PS 抠图层、重打文字、切九宫格、写引擎 UI 布局要一整天。这期直接交付可编辑 PSD 与引擎代码。

## 使用说明

1. 画面：剪映 → AI 创作 → 文生视频，逐条复制「画面提示词」生成。
2. 拼接：软件界面、图层列表、Photoshop 双击改字与 Unity/Godot 导出文件夹用真实录屏（见「录屏镜头」），不用 AI 生成。
3. 配音：文本朗读粘贴「配音文案」；字幕用「字幕要点」。
4. 一致性：游戏 UI 镜头统一同一套界面风格（暗金手游主界面 / 背包），避免控件乱飞。
5. 炸点优先：录屏一定要拍到「识别 16 类控件 + 抹字净底板」「导出 PSD 在 PS 里直接双击修改按钮文字」「一键导出 Unity / Godot / HTML5 界面代码」。

## 三、拼接与配音顺序

1. 顺序：1 → 2 → 3 → 录屏 A → 4 → 录屏 B → 5 → 录屏 C → 6 → 录屏 D → 7 → 8。
2. 镜头间加 6–8 帧闪白或急速推近，前两镜要「炸」，后半段用真实录屏把功能钉死。
3. 配音用「文本朗读」按文案逐段生成，跟画面卡点；字幕用每条字幕要点，字号偏大，前三镜可加震动。
4. 软件菜单、按钮名、Photoshop 改字与引擎代码一律用真实录屏，避免 AI 生成乱码。
5. 结尾 3 秒可叠一张静态卡：`整图输入 → 16 类控件拆解 & 离线 OCR → 可编辑 PSD + Unity/Godot 代码`。
