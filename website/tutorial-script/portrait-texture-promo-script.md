# 人像质感调节 · 剪映文生视频推广脚本

> 剪映「AI 创作 · 文生视频」：逐条复制画面提示词生成镜头；配音用「文本朗读」；总时长约 85–100 秒。
> 推广功能：节点图「人像质感调节」（`image.portraitTexture`）——专业人像质量参数引擎：肤质 / 光影 / 融合 / 色彩 / 细节五组连续参数，内置自然 / 杂志人像 / 商业修图 / 电影感 / 港风复古预设，本地实时预览与 PS 式原图对比。

## 使用说明

1. 画面：剪映 → AI 创作 → 文生视频，逐条复制「画面提示词」生成。
2. 拼接：软件界面镜头用真实录屏（见「录屏镜头」），不用 AI 生成。
3. 配音：文本朗读粘贴「配音文案」；字幕用「字幕要点」。
4. 一致性：人像镜头统一用同一张参考图（女性 / 男性人像均可），避免换脸漂移。
5. 质感展示：录屏优先用「磨皮 / 光影 / 色温 / 颗粒」等一眼能看出差别的参数。

## 三、拼接与配音顺序

1. 顺序：1 → 2 → 录屏 A → 3 → 录屏 B → 4 → 录屏 C → 5 → 6 → 录屏 D → 7 → 录屏 E → 8 → 录屏 F → 9。
2. 镜头间加淡入淡出；界面与参数面板镜头用真实录屏，避免 AI 乱码界面。
3. 配音用「文本朗读」按文案逐段生成，与画面对齐；字幕用每条字幕要点。
4. 提示卡片（五组参数、五个预设名）做成静态图，放在镜头 9 前约 3 秒。
