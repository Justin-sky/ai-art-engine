# 3D 导演台 · 剪映文生视频教程脚本

> 剪映「AI 创作 · 文生视频」：逐条复制画面提示词生成镜头；配音用「文本朗读」；总时长约 2 分钟。对应功能：导演台（3D 工作台）。

## 使用说明

1. 画面：剪映 → AI 创作 → 文生视频，逐条复制「画面提示词」生成。
2. 拼接：软件界面镜头用真实录屏（见「录屏镜头」），不用 AI 生成。
3. 配音：文本朗读粘贴「配音文案」；字幕用「字幕要点」。
4. 一致性：人物镜头统一上传同一张参考图，避免角色漂移。

## 三、拼接与配音顺序

1. 顺序：1→2→3→录屏 A→4→录屏 B→5→6→录屏 C→7→录屏 D→8→录屏 E→9→10→录屏 F→11。
2. 镜头间加淡入淡出；人物镜头统一参考图防漂移；提示卡片（GLB/GLTF/FBX、out-shots/out-actions、动画写入 Cache/Videos）做成静态图放结尾前。
