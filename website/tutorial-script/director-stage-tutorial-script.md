# AI-Art-Engine 3D 工作台 · 剪映文生视频教程脚本

> 适用于剪映「AI 创作 · 文生视频」：逐条复制画面提示词生成镜头，拖入轨道拼接；
> 配音用剪映「文本朗读」粘贴配音文案生成。总时长约 2 分 30 秒。
> 对应功能：导演台（3D 工作台）——3D 场景摆姿、机位、动画预览与录制，输出站位图（out-shots）与动作视频（out-actions）。

## 使用说明

1. **生成画面**：打开剪映 → AI 创作 → 文生视频 → 把下方某条「画面提示词」整段复制粘贴 → 生成，重复此步骤得到全部镜头。
2. **拼接**：按镜头编号顺序把生成结果拖入轨道；涉及软件界面的镜头（见「录屏镜头」）用实际录屏片段，不用 AI 生成。
3. **配音**：新建文本 → 把对应「配音文案」粘贴到文本朗读 → 生成旁白拖到音频轨。
4. **字幕**：用每条「字幕要点」做字幕条。
5. **一致性**：所有镜头提示词都以「现代科技感后期工作室、深色界面、柔光、电影感」开头；生成人物镜头时，把同一张人物参考图作为首帧/参考图上传，保证角色统一。

## 三、拼接与配音顺序

1. 时间轴顺序：镜头 1 → 2 → 3 → 录屏 A → 4 → 5 → 录屏 B → 6 → 7 → 8 → 录屏 C → 9 → 10 → 11 → 录屏 D → 12 → 录屏 E → 13 → 14 → 15 → 16 → 录屏 F → 17 → 18。
2. 镜头之间加淡入淡出转场，避免 AI 生成的人物长相漂移；需要更稳时可每段都上传同一张人物参考图。
3. 配音用「文本朗读」按配音文案逐段生成，拖到音频轨后与画面对齐；字幕用每条字幕要点。
4. 提示卡片（模型格式支持 GLB / GLTF / FBX；站位图与动作视频分别走 out-shots / out-actions；动画录制自动写入 Cache/Videos）做成一张静态图，放在镜头 18 之前约 3 秒。
