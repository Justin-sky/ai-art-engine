# Blender MCP + AI 操作 Blender · 剪映文生视频推广脚本

> 剪映「AI 创作 · 文生视频」：逐条复制画面提示词生成镜头；配音用剪映「文本朗读」粘贴配音文案生成。总时长约 100 秒。
> 对应功能：MCP Blender 工具集（`execute_blender_code` / `get_viewport_screenshot` / `export_scene` 等 9 个工具）+ 3D 模型生成（Meshy / Tripo / Hyper3D，支持 rig 骨骼绑定）。
> 主题：复现刷屏的「AI 看屏幕、自己操作 Blender」效果——文生 3D 绑骨、AI 写脚本调走路循环、截图自查，全程不碰鼠标。

## 使用说明

1. **生成画面**：打开剪映 → AI 创作 → 文生视频 → 把下方某条「画面提示词」整段复制粘贴 → 生成，重复此步骤得到全部镜头。
2. **拼接**：按镜头编号顺序把生成结果拖入轨道；涉及软件界面和 Blender 画面的镜头（见「录屏镜头」）用实际录屏片段，不用 AI 生成——AI 生成界面和代码文字会乱码。
3. **配音**：新建文本 → 把对应「配音文案」粘贴到文本朗读 → 生成旁白拖到音频轨。
4. **字幕**：用每条「字幕要点」做字幕条，重点词放大变色（如「没碰鼠标」「截图自查」）。
5. **一致性**：所有镜头提示词都以「现代科技感后期工作室、深色界面、柔光、电影感」开头；出现真人时上传同一张人物参考图，保证角色统一。
6. 镜头 1 的「AI 演示」画面用抽象表达，不出现任何真实产品名；核心证据全部放在录屏镜头（D / E / F）里。

## 二、录屏镜头（软件界面用实际录屏，不用 AI 生成）

## 三、拼接与配音顺序

1. 时间轴顺序：镜头 1 → 2 → 3 → 录屏 A → 4 → 录屏 B → 5 → 录屏 C → 6 → 录屏 D → 7 → 录屏 E → 8 → 录屏 F → 9 → 10。
2. 录屏 D、E 是全片证据核心，**保持原速不加速**，可在视口角落叠加小窗显示 AI 的思考摘要；镜头 1–4 可 1.5 倍速快放拉节奏。
3. 配音用「文本朗读」按配音文案逐段生成，拖到音频轨后与画面对齐；字幕用每条字幕要点，重点词（没碰鼠标 / 截图自查 / 绿灯）放大加色。
4. 提示卡片（两种插件方案：社区 blender-mcp / 官方 Blender Lab 扩展；safe mode 只许 bpy 相关 import；Plan 模式先出方案再放行）做成静态图，放在镜头 4 之后约 3 秒。
5. 前 4 秒用低鼓点，镜头 5–8 切科技感轻快 BGM，录屏 D、E 处 BGM 音量压低突出工具音效，结尾回归轻快。
