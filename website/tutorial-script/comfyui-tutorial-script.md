# ComfyUI 接入 · 剪映文生视频教程脚本

> 适用于剪映「AI 创作 · 文生视频」：逐条复制画面提示词生成镜头，拖入轨道拼接；
> 配音用剪映「文本朗读」粘贴配音文案生成。总时长约 100 秒。
> 核心卖点：AIArtEngine 连接本机 ComfyUI，免 Key、不计次、不上云，无限免费生成各类视频，并把 ComfyUI 复杂的节点连线封装成极简节点。

## 使用说明

1. **生成画面**：打开剪映 → AI 创作 → 文生视频 → 把下方某条「画面提示词」整段复制粘贴 → 生成，重复此步骤得到全部镜头。
2. **拼接**：按镜头编号顺序把生成结果拖入轨道；涉及软件界面与命令的镜头（见「录屏镜头」）用实际录屏片段，不用 AI 生成。
3. **配音**：新建文本 → 把对应「配音文案」粘贴到文本朗读 → 生成旁白拖到音频轨。
4. **字幕**：用每条「字幕要点」做字幕条。
5. **一致性**：所有镜头提示词都以「现代科技感 AI 创作工作室、深色界面、柔光、电影感」开头；出现人物时把同一张人物参考图作为首帧/参考图上传，保证角色统一。

## 二、录屏镜头（软件界面用实际录屏，不用 AI 生成）

剪映文生视频生成文字和界面容易乱码，以下镜头请用真实软件录屏：

| 镜头 | 录屏内容 | 对应脚本 |
| --- | --- | --- |
| A | 终端执行 pip install comfy-api-proxy、启动代理、访问 /api/v2/health 返回就绪 | 对应镜头 5 |
| B | ComfyUI 开 Dev mode → Save (API Format) → 保存到 user/default/workflows/ | 对应镜头 6 |
| C | 设置 → 模型 → 添加 ComfyUI → Base URL 填 8189 → 拉取模型勾选 | 对应镜头 7 |
| D | 图片节点选 txt2img → 写指令 → 执行出图 | 对应镜头 8 |
| E | 视频节点选 MiniMax H3 图生视频 → 连首帧 → 选 16:9 与时长 → 执行出片 | 对应镜头 8 |

## 三、拼接与配音顺序

1. 时间轴顺序：镜头 1 → 2 → 3 → 4 → 5 → 录屏 A → 6 → 录屏 B → 7 → 录屏 C → 8 → 录屏 D/E → 9。
2. 镜头之间加淡入淡出转场，避免 AI 生成的人物长相漂移；需要更稳时可每段都上传同一张人物参考图。
3. 配音用「文本朗读」按配音文案逐段生成，拖到音频轨后与画面对齐；字幕用每条字幕要点。
4. 端口号、命令、菜单名等文字信息优先用录屏或静态卡片展示，避免 AI 生成乱码。
