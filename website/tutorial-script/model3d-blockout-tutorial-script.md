# 3D 模型生成 + AI 白模 · 剪映文生视频教程脚本

> 剪映「AI 创作 · 文生视频」：逐条复制画面提示词生成镜头；配音用「文本朗读」；总时长约 100 秒。
> 对应功能：`3D 模型生成` 节点（Meshy / Tripo / Rodin（Hyper3D）/ Luma AI / Lux3D，文生 3D / 图生 3D / 多图生 3D）与导演台「生成 3D 白模」（AI 场景白模）。

## 使用说明

1. **生成画面**：打开剪映 → AI 创作 → 文生视频 → 把某条「画面提示词」整段复制粘贴 → 生成，重复得到全部镜头。
2. **拼接**：按镜头编号顺序拖入轨道；软件界面镜头用真实录屏（见「录屏镜头」），不用 AI 生成。
3. **配音**：文本朗读粘贴「配音文案」；字幕用「字幕要点」。
4. **一致性**：人物镜头统一上传同一张参考图，避免角色漂移。
5. 硬核知识点（五大平台、3 张参考图上限、out-shots）做成静态提示卡片，放结尾前。

## 二、录屏镜头（软件界面用真实录屏）

| 镜头 | 录屏内容 | 对应 |
| --- | --- | --- |
| A | 设置 → 模型 → 3D 模型页签，填 Meshy / Tripo / Rodin（Hyper3D）/ Luma AI / Lux3D 的 API Key | 镜头 2 |
| B | 「3D 模型生成」节点输入一句话，文生 3D 出 GLB 模型 | 镜头 3 |
| C | 同一节点换成图生 3D：传单图或多张参考图生成 | 镜头 4 |
| D | 模型连线到导演台的 3D 模型输入端口，双击 dive 进入舞台，模型自动实例化 | 镜头 5 |
| E | 点「生成3D白模」：加参考图、选透视 / 360 全景类型、选文本模型、改指令，点「创建场景」，看「AI 白模」分组逐个长出物体 | 镜头 6、7、8 |
| F | 白模场景摆机位、相机预览、截屏站位图，out-shots 接下游节点入队 | 镜头 9 |

## 三、拼接与配音顺序

1. 顺序：1→2→录屏 A→3→录屏 B→4→录屏 C→5→录屏 D→6→录屏 E→7→8→9→录屏 F→10。
2. 镜头间加淡入淡出；人物镜头统一参考图防漂移；提示卡片（五大平台名、3 张参考图上限、透视 / 360 全景、out-shots）做成静态图放结尾前。
