# 逐帧拉片 · 剪映文生视频教程脚本

> 适用于剪映「AI 创作 · 文生视频」：逐条复制画面提示词生成镜头，拖入轨道拼接；
> 配音用剪映「文本朗读」粘贴配音文案生成。总时长约 90 秒。
> 对应功能：`video.framePull` 逐帧拉片节点（关键帧胶片条、取帧批注、输出图片参考）。

## 使用说明

1. **生成画面**：打开剪映 → AI 创作 → 文生视频 → 把下方某条「画面提示词」整段复制粘贴 → 生成，重复此步骤得到全部镜头。
2. **拼接**：按镜头编号顺序把生成结果拖入轨道；涉及软件界面的镜头（见「录屏镜头」）用实际录屏片段，不用 AI 生成。
3. **配音**：新建文本 → 把对应「配音文案」粘贴到文本朗读 → 生成旁白拖到音频轨。
4. **字幕**：用每条「字幕要点」做字幕条。
5. **一致性**：所有镜头提示词都以「现代科技感后期工作室、深色界面、柔光、电影感」开头；生成人物镜头时，把同一张人物参考图作为首帧/参考图上传，保证角色统一。

> 现代科技感后期制作工作室，深色桌面，一位年轻内容创作者拖动鼠标翻看一段视频素材，画面暂停在一瞬间，他盯着屏幕露出遗憾的表情，因为这一段不能直接使用，镜头缓慢推近他的侧脸，柔光，电影感，画面清晰。

## 二、录屏镜头（软件界面用实际录屏，不用 AI 生成）

剪映文生视频生成文字和界面容易乱码，以下镜头请用真实软件录屏：

| 镜头 | 录屏内容 | 对应脚本 |
| --- | --- | --- |
| A | 节点图右键菜单 → 视频分组 → 选中「逐帧拉片」拖入画布并连线 | 对应镜头 3、4 |
| B | 双击节点打开拉片台，观察关键帧胶片条，左右键步进、空格播放 | 对应镜头 5 |
| C | 选中一格取当前帧，在批注框写要点，查看帧列表联动 | 对应镜头 6 |
| D | 把输出口连到下游图片 / 视频生成节点，运行查看参考图生效 | 对应镜头 7 |

## 三、拼接与配音顺序

1. 时间轴顺序：镜头 1 → 2 → 3 → 录屏 A → 4（可省略）→ 5 → 录屏 B → 6 → 录屏 C → 7 → 录屏 D → 8。
2. 镜头之间加淡入淡出转场，避免 AI 生成的人物长相漂移；需要更稳时可每段都上传同一张人物参考图。
3. 配音用「文本朗读」按配音文案逐段生成，拖到音频轨后与画面对齐；字幕用每条字幕要点。
4. 提示卡片（ffprobe 提取关键帧、无 ffprobe 时回退逐帧胶片条）做成一张静态图，放在镜头 8 之前约 3 秒。

## 四、与片段重拍教程的衔接

- 两期可组成系列：本期「逐帧拉片」讲从参考视频里抽帧，下期「片段重拍」讲只改指定区间。
- 结尾 CTA 可互相引导：「想看怎么只改其中几秒，点进片段重拍那期」。
