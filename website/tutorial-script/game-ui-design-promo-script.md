# 用 AI-Art-Engine 设计游戏 UI · 剪映文生视频推广脚本

> 剪映「AI 创作 · 文生视频」：逐条复制画面提示词生成镜头；配音用「文本朗读」；总时长约 2 分钟。
> 推广功能：节点图「策划案生成 → UI 界面拆分 → 图片生成」游戏 UI 设计工作流（对应 test5 演示画布）。

## 使用说明

1. 画面：剪映 → AI 创作 → 文生视频，逐条复制「画面提示词」生成。
2. 拼接：软件界面镜头用真实录屏（见「录屏镜头」），不用 AI 生成。
3. 配音：文本朗读粘贴「配音文案」；字幕用「字幕要点」。
4. 一致性：界面类镜头统一参考同一套 UI 风格图，避免风格漂移。

## 二、录屏镜头（软件界面用真实录屏）

| 镜头 | 录屏内容 | 对应 |
| --- | --- | --- |
| A | 画布中连好 文本→策划案生成→UI 界面拆分→图片生成 | 镜头 3 |
| B | 执行策划案生成，展示生成的策划案 | 镜头 4 |
| C | 执行 UI 界面拆分，展示界面列表 | 镜头 5 |
| D | 选择一条界面提示词，执行图片生成 | 镜头 6 |
| E | 两个图片生成节点并行出图 | 镜头 7 |
| F | 拖入风格参考图，对比不同配色输出 | 镜头 8 |

## 三、拼接与配音顺序

1. 顺序：1→2→3→录屏 A→4→录屏 B→5→录屏 C→6→录屏 D→7→录屏 E→8→录屏 F→9→10→11。
2. 镜头间加淡入淡出；界面镜头统一同一张风格参考图防风格漂移。
3. 提示卡片（风格参考图最多 4 张；UI 拆分每界面一条提示词；策划案生成需先接需求文本）做成静态图放结尾前。
