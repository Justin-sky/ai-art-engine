# 人像处理 · 剪映文生视频推广脚本（全功能讲解 + 对标像素蛋糕）

> 剪映「AI 创作 · 文生视频」：逐条复制画面提示词生成镜头；配音用「文本朗读」；软件界面一律用**真实录屏**（见第二节）。总时长约 **150–175 秒**，可按第四节压到 **60 秒**。
> 推广功能：节点图「人像处理」（`image.portrait`）——16 组工具、五档档位、12 套预设，参数合成提示词后调用**你自己配的图片模型**出图；默认开启「只处理对应部位」，人脸关键点在本机离线分析，发给模型的原话在编辑器里可见可改。
> 一句话定位：**不是比像素蛋糕修得更好看，而是把「按张付费的云端修图」换成「你自己的模型 + 一次调参批量出片」。**
> **口径与合规**：只讲可核对的事实（计费形态、照片去向、批量能力），不贬损同行、不编造对方参数；涉及对方产品形态的表述以写作时的公开信息为准，若对方改版请同步修改配音。

## 使用说明

1. **画面**：剪映 → AI 创作 → 文生视频，逐条复制「画面提示词」生成；同一张人像参考图贯穿全片，避免换脸漂移。
2. **界面**：所有提到面板 / 参数 / 按钮的镜头**必须用真实录屏**，AI 生成的界面一定会有乱码和假按钮。
3. **配音**：文本朗读粘贴「配音文案」，语速 1.0–1.1；每句控制在 6 秒内，长句已按镜头拆好。
4. **字幕**：用「字幕要点」，字号大、白字黑边，关键数字（16 组 / 五档 / 24 张 / 10 规格）单独做描红。
5. **录屏要点**：录制前把鼠标指针调大、点击加高亮；对比镜头固定用同一张原图、同一机位。
6. **节奏**：配音按 **5 字/秒** 估算（本脚本每条镜头的配音字数都已核过，不超过镜头时长）；念不完就删形容词，不要加快语速。
7. **素材合规**：演示用的照片请用自有素材或已授权模特，不要用客户/他人肖像。
8. **数字随版本走**：片尾「事实速查表」是配音里所有数字的出处，改版后先核对表再录。
