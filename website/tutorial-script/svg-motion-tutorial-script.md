# 一句话生成 SVG 矢量动画 · 剪映文生视频教程脚本

> 适用于剪映「AI 创作 · 文生视频」：逐条复制画面提示词生成镜头，拖入轨道拼接；
> 配音用剪映「文本朗读」粘贴配音文案生成。总时长约 110 秒。
> 核心卖点：在 AI 对话面板里说一句「生成一个鹈鹕骑自行车的 SVG 动画」，Agent 自动在节点图里建好
> 「SVG 生成」(`svg.gen`) → 「SVG 烘焙」(`svg.anim`) 两个节点并运行，产出 `.svg` 矢量资产 + GIF 动图：
> 矢量放大不糊、改色不用重画，动效既能出 GIF、也能出逐帧 PNG。

## 使用说明

1. **生成画面**：打开剪映 → AI 创作 → 文生视频 → 把下方某条「画面提示词」整段复制粘贴 → 生成，重复此步骤得到全部镜头。
2. **拼接**：按镜头编号顺序把生成结果拖入轨道；涉及软件界面与对话过程的镜头（见「录屏镜头」）用实际录屏片段，不用 AI 生成。
3. **配音**：新建文本 → 把对应「配音文案」粘贴到文本朗读 → 生成旁白拖到音频轨。
4. **字幕**：用每条「字幕要点」做字幕条，关键词（SVG / 矢量 / 一句话）放大加色。
5. **一致性**：所有镜头提示词都以「现代科技感 AI 创作工作室、深色界面、柔光、电影感」开头；出现人物时把同一张人物参考图作为首帧/参考图上传，保证角色统一。
6. **录屏前置（很重要）**：开录前先在应用里把整条链路真跑一遍（文本模型出 SVG 约十几秒，逐帧烘焙 + GIF 编码另需数秒），确认工程里已有 `.svg` 资产与 GIF 结果，再回头录「输入一句话 → 产物出现」的全过程，避免录屏时干等。
7. **避坑先看第五节**：动效必须写在 SVG 自身（SMIL）里才会被逐帧烘焙；静态 SVG 只出 1 帧、不产 GIF。

## 五、录屏前必看：避坑清单

1. **静态 SVG 只出 1 帧、不产 GIF**。要让「SVG 烘焙」出多帧和 GIF，动效必须写在 SVG 自身内部，并在下需求时说清「无缝循环」。只说「画一张鹈鹕骑车图」，结果就是一张静态矢量图。
2. **动效写 SMIL，别写 CSS `@keyframes`**。逐帧烘焙求值的是 `<animate>` / `<animateTransform>` / `<set>`；写在 `<style>` 里的 CSS 动画不参与求值，会被当成静态 SVG（只出 1 帧）。位移也别用 `<animateMotion>`（不参与求值，元素会停在原位）。真烘出来只有一帧、没有 GIF 时，多半就是这个原因——回对话里补一句「动效改成 SVG 内置的 `animateTransform`，要无缝循环」，重跑一次即可。
3. **要矢量就别让它改走文生图**。`generate_image` 出的是位图，放大一样糊；明确说 SVG / 矢量，让它用「SVG 生成」节点。
4. **端口是 `svg` 口**：`svg.gen` 的输出接 `svg.anim` 的输入；图库里的 SVG 资产（`image` 口）也兼容，能直接接进烘焙节点。
5. **帧数与耗时**：帧数 2–60（默认 12），帧越多越顺但烘焙越慢；取样时长 0 表示自动探测 SVG 自身的动画周期（上限 30 秒）。
6. **参考图也能生矢量**：给「SVG 生成」的图片口接一张参考图（最多 4 张），它会照着轮廓与配色重绘成纯矢量，不会内嵌位图。
7. **手动路线**（不想用对话时）：画布右键 →「图片」分组 → 新建「SVG 生成」，接指令与参考图运行；再把它的输出接进「SVG 烘焙」运行。

## 六、可复制的对话指令（录屏时照着说）

| 想要的结果 | 直接对对话面板说 | 走到的链路 |
