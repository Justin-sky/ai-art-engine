# MCP + AI 对话面板 · 剪映文生视频教程脚本

> 适用于剪映「AI 创作 · 文生视频」：逐条复制画面提示词生成镜头，拖入轨道拼接；
> 配音用剪映「文本朗读」粘贴配音文案生成。总时长约 105 秒。
> 对应功能：AI 对话面板（DeepSeek Harness 运行时，@ 引用工程资产 + MCP 工具调用）+ 内置 MCP Server（stdio 桥 / HTTP 直连，Claude Code / Codex 等外部 Agent 可操作工程）。

## 使用说明

1. **生成画面**：打开剪映 → AI 创作 → 文生视频 → 把下方某条「画面提示词」整段复制粘贴 → 生成，重复此步骤得到全部镜头。
2. **拼接**：按镜头编号顺序把生成结果拖入轨道；涉及软件界面的镜头（见「录屏镜头」）用实际录屏片段，不用 AI 生成。
3. **配音**：新建文本 → 把对应「配音文案」粘贴到文本朗读 → 生成旁白拖到音频轨。
4. **字幕**：用每条「字幕要点」做字幕条，重点词放大变色（如「MCP」「调工具」）。
5. **一致性**：所有镜头提示词都以「现代科技感后期工作室、深色界面、柔光、电影感」开头；生成人物镜头时，把同一张人物参考图作为首帧/参考图上传，保证角色统一。
6. 竞品对比镜头（11）不点具体产品名，用「图片工具」「视频工具」「3D 工具」抽象图标表达「单点工具」，避免引战。

## 二、录屏镜头（软件界面用实际录屏，不用 AI 生成）

剪映文生视频生成文字和界面容易乱码，以下镜头请用真实软件录屏：

| 镜头 | 录屏内容 | 对应脚本 |
| --- | --- | --- |
| A | 打开 AI 对话面板，`@` 引用素材库资产，输入「给产品出一张赛博朋克主视觉」，观察界面自动调用 MCP 工具、进度条推进、图片生成 | 对应镜头 3、4 |
| B | 生成图上的 AI 质检五维评分面板，触发一次 FAIL 后自动注入原因重试，最终通过 | 对应镜头 5 |
| C | 对话里输入「把这张图转成 3D 白模，扔进导演台」，节点图自动连线，双击 dive 进入 3D 舞台查看白模场景 | 对应镜头 6 |
| D | 对话里输入「用可灵把主视觉变成 15 秒产品广告」，视频生成后素材落到成片时间线并整轨预览 | 对应镜头 7 |
| E | 设置 → MCP Server：开启 stdio 桥与 HTTP 端点、查看/编辑 token（跨重启复用）；打开 Claude Code 终端，命令连接本应用后规划并落盘一个工作流、`task_run` 执行并 `task_status` 查状态 | 对应镜头 8、9 |
| F | MCP 工具清单界面（models_list / generate_image / generate_model3d / generate_video / generate_speech / graph_read / graph_edit / task_run / task_status / folder_list）与操作审计日志 | 对应镜头 10 |

## 三、拼接与配音顺序

1. 时间轴顺序：镜头 1 → 2 → 3 → 录屏 A → 4 → 录屏 B → 5 → 6 → 录屏 C → 7 → 录屏 D → 8 → 9 → 录屏 E → 10 → 录屏 F → 11 → 12。
2. 镜头之间加淡入淡出转场，避免 AI 生成的人物长相漂移；需要更稳时可每段都上传同一张人物参考图。
3. 配音用「文本朗读」按配音文案逐段生成，拖到音频轨后与画面对齐；字幕用每条字幕要点，重点词（MCP / 调工具 / 一句话）放大加色。
4. 提示卡片（MCP 是 Model Context Protocol、Claude Code 如何一行命令连进来、可用的工具命令清单）做成静态图，放在镜头 10 之后约 3 秒。
5. 前 5 秒用低鼓点，镜头 3–7 切科技感轻快 BGM，镜头 8–10 切「黑客帝国风」电子音，结尾回归轻快。
