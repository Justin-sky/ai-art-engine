Manual · Setup

工程与设置

新建与打开工程，并在设置中完成通用偏好、模型提供商、对象存储、扩展、MCP 工具服务与联网搜索的配置。第一次使用时，建议先把这一部分走一遍。

3. 首页与工程

新建工程

  1. 点击「新建工程」。
  2. 填写「工程名称」。
  3. 点击「浏览」选择「存储目录」。
  4. 点击「创建」后进入工作区。

打开工程

  • 点击「打开工程」，选择工程目录中的 project.json。
  • 或在「最近工程」列表中点击对应路径。

最近工程

  • 列表展示近期打开过的工程路径。
  • 右侧 × 表示「从最近列表移除」——不会删除磁盘上的工程文件。
当前版本没有应用内「删除工程」功能。若要彻底删除，请在文件管理器中手动删除工程目录。

4. 设置

在首页或工作区顶栏进入「设置」。修改会自动保存。

4.1 通用

  • 主题：暗色 / 亮色。
  • 语言：中文 / English。
  • 自动保存：可启用，并设置间隔（秒）。
  • 关于与更新：查看版本、检查更新（见下文）。

4.2 模型

  1. 点击「添加模型提供商」，可选：
    • OpenRouter：文本 / 图片 / 视频 / 决策（聚合目录，单 API Key）。
    • OpenAI：文本（GPT 系列）/ 图片（gpt-image-1 / gpt-image-2）；需可访问 api.openai.com 的网络与境外账号，文生图走 /images/generations，参考图编辑走 /images/edits（最多 1 张）。

    • 智谱：GLM 文本（/chat/completions）+ CogView 文生图 （glm-image / cogview-4 / cogview-3-flash，/images/generations）。
    • Kimi（月之暗面）：文本（kimi-k2 系列 / moonshot-v1 系列，OpenAI 兼容，默认 Base URL https://api.moonshot.cn/v1）。

    • Ollama：本地 OpenAI 兼容端点（默认 http://localhost:11434/v1），无需 API Key。
    • LM Studio：本地 OpenAI 兼容端点（默认 http://localhost:1234/v1），无需 API Key。

    • MiniMax：文本 / 图片 / 视频 / 音色设计（同一 API Key；默认 Base URL https://api.minimaxi.com）。
    • 通义千问：文本（兼容模式）/ 万相图 / 万相视频（含 HappyHorse、Wan 3.0-Video 等，百炼 API Key）。Wan 3.0-Video 支持单次 30s、10 图 + 5 视频 + 5 音频参考，公测 / 邀测中， Model ID 以百炼控制台为准。
    • 魔塔：文本 / 文生图（ModelScope 访问令牌，如 ms-…）。
    • ComfyUI：图片 / 视频 / 声音，走 API 2（POST /api/v2/jobs）。 模型 id = userdata 里的 API 格式 workflow 名（不是 checkpoint），模型列表由服务动态拉取。 视频 workflow 支持多模态参考（r2v）、视频 / 音频参考注入与首尾帧（first_frame / last_frame）注入，视频时长上限 15s。 本机默认 Base URL http://127.0.0.1:8189（需先装 comfy-api-proxy，不要直连 8188）； 云端填 https://cloud.comfy.org 并填 Key。本机可空 Key。 完整步骤见 ComfyUI 接入教程。
    • MagicRouter：多供应商聚合网关（OpenAI 兼容），文本 / 图片 / 视频； 需 mr- 开头 API Key，默认 Base URL https://api.magicrouter.ai/v1，模型目录由 /models/live 拉取，视频为异步提交 / 轮询。
    • Meshy：文生 3D / 图生 3D（含多图生 3D，API Key，默认 Base URL https://api.meshy.ai）。
    • Tripo：文生 3D / 图生 3D（API Key，默认 Base URL https://api.tripo3d.ai）。
    • Rodin（Hyper3D）：文生 3D / 图生 3D（API Key，默认 Base URL https://api.hyper3d.com/api/v2）。
    • Luma AI：文生 3D / 图生 3D（API Key，默认 Base URL https://api.lumalabs.ai/dream-machine/v1）。
    • Lux3D：文生 3D / 图生 3D / 多图生 3D（API Key，G1 / G1-Turbo， 默认 Base URL https://api.aholo3d.cn）。
    • World Labs（Marble）：空间世界生成 —— 文生世界 / 图生世界 / 多图生世界 / 视频生世界（API Key，默认 Base URL https://api.worldlabs.ai，鉴权头为 WLT-Api-Key；模型 marble-1.1 标准、marble-1.1-plus 更大世界、marble-1.0 与 marble-1.0-draft 上一代。参考媒体走官方托管上传，无需对象存储）。
    • 自定义：自选端点类型（OpenAI 兼容 / Anthropic / Gemini）并填写 Base URL 与 API Key，用于 NewAPI、one-api 等中转网关或自建服务；支持文本与图片，模型常在目录里拉不到， 需手动填 id —— 完整步骤见 NewAPI 接入教程。

    • LM Studio 官网（本地服务无需密钥）： https://lmstudio.ai
    • 火山方舟 API Key（文本 / 图片 / 视频）： https://console.volcengine.com/ark/region:ark-cn-beijing/apiKey
    • 豆包语音控制台（声音设计 API Key / speaker_id）： https://console.volcengine.com/speech/app
    • 可灵开放平台（API Key）： https://app.klingai.com/cn/dev
    • MiniMax 接口密钥： https://platform.minimaxi.com/user-center/basic-information/interface-key
    • 通义千问 / 百炼 API Key： https://bailian.console.aliyun.com/?tab=model#/api-key
    • 魔塔访问令牌： https://modelscope.cn/my/myaccesstoken
    • ComfyUI：本机可空 Key；云端 API Key 见 Comfy 开发者文档 ；本机安装 proxy 与 workflow 见 ComfyUI 接入教程。

  3. 填写显示名称、Base URL、密钥（可显示/隐藏）。
  4. 启用该提供商后，点击「拉取可用模型」（可灵 / MiniMax 部分模态 / 百炼图视频 / OpenAI 与智谱图片等为本地静态目录；vLLM / Ollama / LM Studio / ComfyUI 等本地服务无需密钥，直接拉取）。
  5. 用筛选、全选/清空勾选需要的模型；也可手动添加模型 ID。
  6. 按模态配置：文本 / 图片 / 视频 / 声音 / 3D 模型 / 空间世界 / 决策（OpenRouter 支持文本 / 图片 / 视频 / 声音 / 决策，决策页签走 output_modalities=decisions 拉取；TypeSafe 直连仅「决策」页签，目录走 GET /v1/models、判定走 POST /v1/systemone，与 OpenRouter 的决策协议一致但不经其中转；方舟声音页签会提示语音控制台链接，并手填 speaker_id；可灵仅图片与视频页签；MiniMax 支持文本 / 图片 / 视频 / 音色设计； OpenAI 支持文本 / 图片 / 声音；ElevenLabs 支持「声音」与「音乐」两个页签（语音合成 / 多说话人对话 / 音效生成走「声音」，音乐生成走「音乐」）； DeepSeek 仅文本；Kimi（月之暗面）仅文本；xAI（Grok）支持文本 / 图片 / 视频（视频为异步轮询）；Google（Gemini）支持文本 / Nano Banana 图片 / Veo 3.1 视频（异步轮询）；智谱支持 GLM 文本与 CogView 图片；vLLM 支持文本与视频（Wan T2V / I2V）；Ollama / LM Studio 仅文本（多模态理解可在文本节点传图）； 魔塔仅文本与图片，文生图为异步任务；ComfyUI 支持图片 / 视频 / 声音，无文本页签；MagicRouter 支持文本 / 图片 / 视频；Meshy / Tripo / Rodin（Hyper3D） / Luma AI / Lux3D 仅 3D 模型页签；World Labs（Marble）仅空间世界页签；自定义提供商的页签由端点类型决定 —— OpenAI 兼容 / Gemini 为文本 + 图片，Anthropic 仅文本，且图片模型必须手动填 id，见 NewAPI 接入教程）。
  7. 声音（TTS）：OpenAI / OpenRouter 的声音页签走 POST /audio/speech， 请求体是 model + input + voice（可选 response_format / speed）—— 这是 OpenAI 的 TTS 协议形状，各类聚合器（new-api / one-api / 自建网关）都按它对接，把 Base URL 换成网关地址即可直接使用。 模型目录：OpenRouter 走 /models?output_modalities=speech（能拿到 supported_voices）， OpenAI 用本地静态表（GET /models 只给 id、不给音色列表）；聚合器上的模型也可手填 id。 ElevenLabs 走自己的协议：POST /v1/text-to-speech/{voice_id} （鉴权头 xi-api-key），模型目录 GET /v1/models、音色目录 GET /v1/voices。 它的 voice_id 是不透明字符串，所以面板里显示的是音色名 （如 Sarah - Mature, Reassuring）；音色目录公开可读，没填 Key 也能先看模型与音色。 同一把 Key 还接了两条既有管线：语音转文字（Scribe，时间线的「配音转字幕」）与 音乐生成（BGM / 音效）。这三个端点混在同一份模型目录里，声音节点的下拉只列 TTS 模型。 音色在声音生成节点的指令面板里填（不在这里）：音色是按节点生效的参数， 同一张图里不同配音节点本就该用不同音色；候选来自接口返回的 supported_voices （OpenRouter 文档页不列，但 /models?output_modalities=speech 会返回，实测 23 个语音模型里 18 个有， 最长的微软 MAI Voice 有 97 个），可按应用语言优先排序。 留空则用模型自己的默认音色（我们不会替你猜一个音色名发给上游 —— 各家的音色命名并不通用）。 少数模型（如 bytedance-seed/seed-audio-1-0）没有音色列表： 它的音色由提示词描述决定，留空即可。
  8. 另外两个声音类节点（ElevenLabs 专属端点，产物同样是声音资产）：
    • 多说话人对话：一次合成整段对白。指令框里按行写 说话人: 台词（中英文冒号都认），例如 A: 你终于来了。 / B: 路上堵车。； 没有冒号的行沿用上一段的说话人（旁白 / 连续独白）。 每个说话人在节点指令面板里绑定一个音色（未绑定的回退到节点默认音色）， 缺音色会明确报出是第几段、哪个说话人。
    • 音效生成：走 POST /v1/sound-generation， 描述的是声音本身（如「雨落在铁皮屋顶上」），而不是台词。 指令面板里可选「可无缝循环」（环境音长播时必开：接缝不再咔嗒）、 「期望时长」（规范范围 0.5–30 秒）与「提示词影响力」 （0–1，默认 0.3）；落盘到 Cache/Sfx。 那个端点的模型是唯一取值（eleven_text_to_sound_v2）， 所以卡片上的下拉实际是在选用哪个提供商实例（多账号 / 多 Key 时才有意义）， 标题已写明「模型固定为 …」。没有可用提供商时会明确报错，不会退回语音合成。
    这两个节点与「配音转字幕」一样，都复用同一把 ElevenLabs Key。
  9. 音乐（BGM）走另一个页签：ElevenLabs 的 POST /v1/music 归在「音乐」页签下（与「声音」分开）—— 音乐是编曲（prompt + 歌词 / 纯音乐）， 语音合成是 TTS（text + voice），两边的端点与模型体系都不同。 同一页签下还能勾 OpenRouter（Google Lyria 3）、MiniMax（music-3.0）与 通义千问 · 百炼（fun-music-v1）的音乐模型；音乐节点下拉只列音乐模型， 不会出现 TTS 模型。升级前把音乐模型勾在「声音」页签的旧设置会自动迁移过来。
  10. 设置默认生成模型（如需要）。提供商卡片可折叠以节省空间。
API Key 保存在本机设置文件中（Windows 示例： %APPDATA%\AIArtEngine\aiartengine-settings.json），不会上传到应用官方服务器。

4.3 对象存储

用于将本地参考视频等上传为可公网访问的 URL（私有桶时使用签名链接）。

  • 「添加对象存储」→ 选择其一：
    • 火山引擎 TOS：AccessKey / SecretKey、Region、Endpoint、Bucket。
    • 阿里云 OSS：AccessKey / SecretKey、Region、Endpoint、Bucket。
    • 腾讯云 COS：SecretId / SecretKey、Region、Bucket（通常为 BucketName-APPID）。
  • 密钥申请页（设置中亦有外链）：
    • 火山引擎： https://console.volcengine.com/iam/keymanage
    • 阿里云 RAM： https://ram.console.aliyun.com/manage/ak
    • 腾讯云 API 密钥： https://console.cloud.tencent.com/cam/capi
  • 公网访问域名（CDN / 自定义域名）可选；未填时使用签名 URL（约 24 小时有效）。
  • 同时只能启用一个对象存储；勾选启用会自动关闭其它项。卡片支持折叠。

4.4 扩展

应用内部扩展走 Cordis（ctx.editor.*），可贡献节点、卡片、检查器、Skill 与执行器覆盖等；开发说明见仓库 GRAPH_PLUGINS.md。 设置页只读列出用户数据目录 plugins 下的声明式扩展。当前不会执行外部任意脚本，仅展示已声明的扩展信息。 正式安装包默认不加载「图插件示例」演示。

4.5 MCP 工具服务

应用内置 MCP 工具服务，供 Claude Code / Codex 等外部 AI Agent（以及内置 AI 对话面板）调用——规划并落盘工作流、运行生成、读写资产与节点图。 详细接入步骤见 MCP 接入教程。

  • 启动 / 重启：设置页显示运行状态与端口；端口默认 43110，被占用时依次尝试 43110–43119。修改端口或点击「重启」后应用工具服务会以新端口拉起。
  • Token：可显示 / 复制 / 编辑；跨重启保持不变，配置一次即可长期使用。 怀疑泄露时点「重置 Token」——重置后旧 token 立即失效，客户端需用新 token 重新注册。
  • 接入命令：一键复制 claude mcp add --transport http … 命令， 在终端执行即可把应用注册为 Claude Code 的 MCP server（HTTP 直连，无需 Node.js）。
工具服务只监听 127.0.0.1 本机回环，全部请求需带 Bearer token；文件读写限制在工程根目录内 （唯一例外是 asset_import：按你给出的绝对路径读取工程外文件并复制进工程）； 所有工具调用写入审计日志 <userData>/logs/mcp-audit.jsonl（5MB 滚动）。

设置面板另提供 「stdio 桥」可视化配置：可改 stdio 桥命令（默认仍是 node + 仓库内 scripts/mcp-bridge.mjs 或安装包内置 <安装目录>/resources/mcp-bridge.mjs）、桥 HTTP 监听端口、Blender addon 的 BLENDER_HOST / BLENDER_PORT 透传。 修改即时落盘，外部 Agent 重连即生效，不需要重启应用。

同一设置面板还支持 「反向桥」：注册任意外部 stdio MCP server（如 Blender addon / 其它本地 MCP 服务），让应用内 ◈ AI 对话面板（DeepSeek Harness / dsh）也能直接消费 它们的工具 —— 不再需要它们额外暴露 socket 端口。详见 MCP 接入教程里的反向桥段。

另外，第三方 MCP 服务（HTTP 远程 / stdio 本地命令）也可以在 插件市场的 MCP 页签里添加与管理。

4.6 联网搜索

设置页 → 联网搜索 Tab 配置 多 provider 并行可用 的搜索能力。 与模型 provider 体系刻意分离 —— 搜索适配器数量少、不需要按工程维度注入上下文，模块级注册中心 已够用；后续若出现大量第三方搜索服务可平滑迁移到 Cordis plugin。

  • 内置 5 个适配器：DeepSeek Search（默认）/ Tavily / Brave / SerpAPI / Mock （Mock 仅用于本地连通性测试，不会发真请求）。每个适配器可独立启停、配 Base URL、API Key、搜索 深度与时间窗。
  • 面板操作：工具栏「新增 provider」下拉 → 选 kind → 加；每张 provider 卡 折叠 / 展开、勾启用 / 禁用 / 移除；自带「连通性测试」按钮，命中响应 / 失败原因直接显示。
  • 当前使用范围：设置面板里仅配置（暂未接入应用内 AI 对话面板或 一键工作流的联网检索调用）；如需触发联网检索，请在面板里手动测连通。后续会按 agent tool 形态接入对话流，届时与本面板共用同一组 provider 实例。
Mock provider 始终返回固定样本 —— 离线开发、CI 跑通「搜索可用」状态位用；不要在生产环境勾选 （其它 provider 关闭时可能回落 Mock，但不会替换真实数据）。
