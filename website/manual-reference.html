13. 工作区文件结构与资产包 .aipackage

13.1 本地工作区目录结构

AI Art Engine 采用 100% 本地优先存储。每个工作区（Workspace）对应磁盘上的一个独立文件夹，可直接用 Git 或网盘备份，并在右侧 ◈ AI 对话 面板的可展开左侧栏随时多项目秒切与内嵌编辑文本文件：

  • workspace.json + project.json：工作区元数据、画布/视图会话状态、全局风格参考图、全局随机种子与资产注册索引（旧版工程打开时自动无感升级补齐 workspace.json）。
  • Assets/：已归档入库的正式资产（画布、宿主工作流、剧本、小说、GDD 策划案、图片、视频、配音、3D 模型等）。
  • Cache/：节点图与各 Dive 工作台的生成缓存（Cache/Images、Cache/Videos、Cache/Voices、Cache/Music、Cache/Sfx、Cache/Models 等），未手动入库前不会污染正式资产树。
  • MCP 桥接描述文件：应用级 %APPDATA%/aiartengine/mcp.json（macOS 为 ~/Library/Application Support/aiartengine/mcp.json）由应用自动维护本地端口与 Bearer Token，供 Claude Code / Cursor / Codex 接入 102 个 MCP 工具（请勿手改）。

13.2 资产包 .aipackage 导出与导入

格式标识为 com.aiartengine.asset-package，用于在不同工作区之间打包迁移整套素材及其上游依赖；若只需分享单张节点图拓扑，也可直接分享导出的 aiae:graph PNG 配方卡（拖入任意画布即还原）。

  1. 导出：在资产库选中资产或文件夹 → 右键选择「导出资产包」→ 勾选条目并可开启「包含依赖」→ 点击「导出」。
  2. 导入：在资产库空白处或根目录右键「导入资产包」（或直接将 .aipackage 拖入资产库）→ 勾选要导入的条目 → 支持同名资产复用与依赖重映射。

15. 故障排查

按现象对号入座，下面按出现频率排序——绝大多数问题都能在前三条里解决。 仍未解决可到 QQ 群 647306826、邮箱 284139554@qq.com 或 GitHub Issues 反馈（附上执行日志会更快定位）。

提示「余额不足」，或一执行就失败

生成调用的是你自己配置的模型提供商，费用由提供商侧结算。本软件不代收任何费用（若想零密钥先体验完整拆层管线，可在右侧 ◈ AI 对话 面板点击「⚡ 零 Key 极速体验」）。

排查顺序：

  1. 登录对应提供商控制台，确认余额或剩余额度充足（免费额度用尽也会直接失败）。
  2. 设置 → 模型：确认密钥填写正确、未过期、未被吊销。
  3. 确认所需模型已勾选启用，并分别设好了默认的文本 / 图片 / 视频模型。
  4. 换一个模型试跑同一节点，用于区分是「账户问题」还是「单个模型问题」。
提示密钥无效、401 / 403，或模型列表拉不到
  1. 检查密钥前后是否混入空格或换行；重新复制粘贴一次通常能解决。
  2. 确认该密钥在提供商侧已开通对应模型的权限，部分模型需要单独申请。
  3. 若使用代理或 NewAPI 等中转服务，确认中转地址填写完整（含 /v1 等路径）。
  4. 网络受限时可在设置中配置代理后重试；公司网络常见的 HTTPS 拦截也会导致拉取失败。
连线连不上，提示端口类型不匹配

端口严格区分单数与复数及领域专用类型： image 进不了 images，spatialWorld 也不能直接进 model（必须经过 spatialWorld.export 转换）。

常见处理方式：

  1. 需要列表输入时（如「选取图片 / 视频 / 声音 / 文本」），请从上游的 方形口（out-all，导演台为 out-shots / out-actions）连线，默认圆形 out 连不上。
  2. 结构化端口（如 storyboard、filmCast、spatialWorld）请接对应的专用下游节点（如 film.shot、spatialWorld.export），不能与普通 text 混连。

详见 §8 节点图。

节点执行完没有输出，或任务一直排队
  1. 打开节点的执行日志，查看具体报错（多数是模型返回错误或参数不合法）。
  2. 确认上游节点已成功执行：上游没跑完，下游不会有输入。
  3. 检查任务队列是否被其他长任务占满；可暂停或取消排队中的任务。
  4. 图库生成节点有 out（当前选中）与 out-all（全部历史）两个出口， 若接的是 out，请在右侧 Inspector 中确认已选中期望的那条。
角色「变脸」、换装串色，或分镜之间声画不一致

靠五阶段影视工作台（film.workbench）的设定锚点而非反复手写描述来锁死一致性：

  1. 启用 Stage 3 设定锚点与 #variant 语法：在影视工作台「③ 设定」中生成角色定妆图、多套服装变体（如 CHAR01#battle、CHAR01#casual）、场景/道具卡与全局画风卡 STYLE01，并绑定跨集持久化 TTS 音色。
  2. 依赖 Stage 4 自动 @1–@4 锁图与 Vision QC：批量拍摄时会自动把本镜出场变体与场景注入为 @1–@4 视觉锚点，并由视觉质检自动重拍崩坏关键帧。
  3. 启用 Stage 2 导演 11 项连续性审计：在拍摄前自动修正轴线跳切、服装接戏错误与对白覆盖率不足（≥67% 门禁）问题。

详见 §9.2 五阶段影视工作台 与 短剧制作教程。

图片模糊、分辨率不够，或游戏 UI 按钮文字发糊
  1. 普通图像可在末端接入 10 合 1 图像处理（image.process）节点并切换为「高清放大（upscale 2K/4K）」。
  2. 游戏 UI 界面切勿只靠整图生图硬出小字：请使用 ui.componentLib + ui.atlasCompose 真实图集拼装，或经 image.layerSplit 通过本地离线/云端 OCR 提取字色描边、补全九宫格干净底板并导出原生 Photoshop TySh 可编辑矢量文本层 .psd。
视频不动、运镜不听话，或参考视频没生效
  1. 确认动态提示词写清了主体动作与镜头运动；需要精确走位与推拉摇移时，可先在 3D 导演台（director.stage）录制离屏 .webm 轨迹白盒视频作为 @2 参考输入。
  2. 云端模型读取本地参考视频需要可访问外链时，请在设置中启用一个对象存储（火山 TOS / 阿里云 OSS / 腾讯云 COS / 兼容 Amazon S3；私有桶未填公网域名时自动签发约 24 小时有效签名 URL）。详见 S3 配置示例。
对象存储配置失败，或视频外链打不开
  1. 同一时间只能启用一个对象存储（火山 TOS / 阿里云 OSS / 腾讯云 COS / 兼容 Amazon S3）， 启用新的前请先关闭旧的。
  2. 私有桶可以保持私有。未填公网域名时，应用会给出约 24 小时有效的签名链接，模型可以拉取；过期后重新上传即可。
  3. 核对 AccessKey 读写权限与 Region（如 Yandex Object Storage 为 ru-central1，见 配置示例）。
ComfyUI 连不上 / 报 workflow 格式错误
  1. 确认本机 comfy-api-proxy 已启动，且端口与软件中填写的一致。
  2. 确认 ComfyUI 本体已启动并可正常访问。
  3. 必须使用 API 格式的 workflow（在 ComfyUI 中开启 Dev Mode 后「Save (API Format)」导出），界面格式（含 nodes / links 数组）不可用。详见 ComfyUI 教程。
启动异常、白屏，或更新失败
  1. 确认安装包与系统架构匹配（macOS 需区分 Intel / Apple Silicon）。
  2. 首次启动若被系统安全策略拦截，需在系统设置中允许该应用运行。
  3. 更新失败时可在设置 → 通用 → 关于与更新 中重新检查，或从 Releases 手动下载覆盖安装。
  4. 仍异常时，先备份工作区目录（workspace.json + project.json 及 Assets/），再重置配置重试并附上日志反馈。
如何让 Claude Code / Cursor / Codex 通过 MCP 驱动应用？（102 个 MCP 工具）

应用内置双端点 MCP 服务（主服务 /mcp 93 个工具 + Blender 实时桥 /mcp/blender 9 个工具，合计 102 个工具），外部 AI Agent 可直接安装技能市场包（skill_install + workflow_use_installed）、编辑节点图（graph_edit）、运行任务（task_run）、操控 Machinations v2（machinations_studio）、执行本地 OCR（vision_local_ocr）与联网提取（web_extract_article / web_fetch_video）。保持应用运行，任选其一接入：

  1. stdio 桥（推荐，需 Node.js 18+）：执行 claude mcp add aiartengine -- node <安装目录>/resources/mcp-bridge.mjs。
  2. HTTP 直连（无需 Node.js）：打开 设置 → MCP，一键复制「Claude Code 接入命令」执行；或手动运行 claude mcp add --transport http aiartengine <接入地址> --header "Authorization: Bearer <token>"。

注册后重启 Agent 会话即可看到全部工具；应用侧 mcp.json 由应用自动维护，不要手改。完整工具分类见 MCP 接入教程。

AI 对话面板报错 / 联网搜索未返回 / 定时任务未触发
  1. 模型不可用（HTTP_404 等）：确认右上角「模型」下拉选中的文本模型已在对应提供商后台开通，并在 设置 → 模型 填妥密钥。
  2. 联网搜索与网页抓取：内置 ◈ AI 对话（原生 web_search / web_fetch）与 MCP（web_extract_article / web_fetch_video）均已接入设置页「联网搜索」配置——若搜索报错，请在 设置 → 联网搜索（§4.6） 检查搜索引擎 API Key 或本地网络代理。
  3. 24 小时定时任务（00:00–23:59）未触发：自动任务依赖桌面应用进程存活（最小化到托盘即可），请确认应用未完全退出且对应计划开关处于启用状态（见 §5.8 定时任务）。
  4. 切换工作区后找不到会话：展开 ◈ AI 对话 左侧项目栏，确认已切回目标工作区。
排查时先换一个模型跑同一节点，是区分「软件问题」和「模型 / 账户问题」最快的办法。

16. 关于与更新

路径：设置 → 通用 → 关于与更新。

  • 当前版本：显示为 v{version}（如当前正式版 v8.9.1；预发布版会标为 prerelease）。
  • 检查更新：查询 GitHub Releases；开发模式下会提示跳过自动更新检查。
  • 状态包括：正在检查、发现新版本并下载、已是最新、下载进度、失败提示。
  • 下载完成后可点击重启并安装，所有本地工作区（workspace.json + project.json）与密钥配置无损保留。
  • 更新日志：完整版本演进历史见 CHANGELOG。
