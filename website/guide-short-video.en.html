AI Comic Drama & Short Drama Guide (5-Stage Film Workbench)

Install domain workflows on demand from the Skill Marketplace, drag in an aiae:graph PNG-as-Workflow recipe, or place the unified 5-in-1 Film Workbench (film.workbench) directly on a Free Canvas. Powered by 21 genre blueprints (P01–P21), complete “① Dual-Rhythm A+B Beat Breakdown → ② 11-Point Director & ≥67% Spoken Dialogue Audit → ③ Character #variant Sheets, STYLE01 Bible & Cross-Episode TTS Voice Binding → ④ @1–@4 Anchor-Locked Batch Shoot with VLM Vision QC → ⑤ Cover Poster Release Pack, Stitched .mp4 & JianyingPro / CapCut Draft Export” in one workspace.

1. Preparation

  1. Models: Settings → Models → add and enable a provider (Volcengine Ark, Kling, MiniMax, Tongyi Qianwen, ModelScope, OpenRouter, DeepSeek, …). Select and set defaults for the text / VLM model (A+B beat breakdown / 11-point director audit / Vision QC), the image model (STYLE01 master style bible, character base & #variant sheets, scene plates, props, shot keyframes and cover posters), the TTS voice model (persistent character dialogue dubbing) and the video model (image-to-video shot clips).
  2. Object storage (optional): Settings → Object Storage → enable one of Volcengine TOS / Alibaba Cloud OSS / Tencent Cloud COS / Amazon S3–compatible. Recommended when a cloud video model requires public reference URLs; skip it when using direct local uploads or local preview.
  3. Create or open a project from the home page and enter the workspace.
Make sure the provider account has enough credits — generation fails immediately and stops the task when the balance runs out.

2. Step 1: Three ways to launch a comic / short-drama workflow

In v8.9.1, domain workflow presets live in the standalone ai-art-engine-skills catalog so they stay modular and up to date. Choose any of the three entry paths below:

  • Option A — Install on demand from the Skill Marketplace: open Skill Marketplace in the top bar to search and install official short-drama workflows from ai-art-engine-skills (or drive them from an MCP agent via skill_search → skill_install → workflow_use_installed):
    • “Film pipeline” (short-drama): a clean Script (text.plain) → Film Workbench (film.workbench) loop (defaults to vertical 9:16, switchable to 16:9 and more inside the workbench), built for full AI comic-drama (AI 漫剧) and short-drama episodes.
    • “Film · single-shot polish” (short-drama9): Script → Film Workbench (film.workbench) → Shot (film.shot) → Keyframe (asset.image) → Shot clip (asset.video), ideal when you want to pull out hero shots by index and route them through the 10-in-1 Image Processing (image.process) workbench.
  • Option B — Drag & drop a PNG-as-Workflow recipe (aiae:graph): drag any recipe PNG containing an embedded aiae:graph metadata chunk (such as assets/recipe/recipe1.png) onto the workspace or canvas to reconstruct the full node graph and parameters instantly.
  • Option C — Drop film.workbench straight onto a Free Canvas: create a Free Canvas, right-click Film → Film Workbench (film.workbench), and wire a text script node directly without any preset wrapper.

3. Step 2: Understand the generated nodes & typed ports

Dive into the graph to inspect the type-safe topology centered around Film Workbench (film.workbench) (replacing legacy 9-grid / 4-grid slicing chains and dozens of loose nodes):

  • Script (text.plain): paste your episode script, web-novel chapter or synopsis here (or feed it from an upstream novel-to-script node).
  • Film Workbench (film.workbench):
    • Input ports: in (script text), in-cast (optional upstream filmCast library to reuse character sheets, #variant outfits, STYLE01 and persistent TTS voice bindings across multi-episode series), and in-image (optional reference art bound to matching cast/scene entries first).
    • Output ports: out (storyboard structured document aiart.film-storyboard@1), out-cast (filmCast character, wardrobe variant, scene, prop & TTS voice library aiart.film-cast@1, ready to wire into the next episode's in-cast), out-sheets (images STYLE01 style bible plus character/variant/scene/prop sheets), out-images (images per-shot keyframes & cover poster), out-videos (videos per-shot video clip sequence), out-voices (voices per-shot TTS dialogue lines rendered with bound character voices), out-text (text readable shot list, director audit report & viral release copy).
  • Shot (film.shot, optional single-shot branch): connects to the workbench's out and out-cast ports, selects a shot via filmShotRef (e.g. "1" or "S01-02"), and outputs its keyframe prompt (out, with @1–@4 anchor mapping), bound cast variant / scene / prop sheets (out-refs) and motion prompt (out-motion).

4. Step 3: Run the 5-stage Film Workbench pipeline

After pasting your script into the “Script” node, double-click the “Film Workbench” node (or click “Open Film Workbench” in the Inspector) to open the full-screen Dive workspace. Switch across the five stage tabs at the top, click “⚡ Run Full Pipeline” to execute all five stages end-to-end, or step through stage by stage:

  1. Stage 1 — Beat Breakdown (Dual-Rhythm A+B & P01–P21 21 Genre Blueprints):
    • Pick from 21 vertical comic-drama & short-drama genre blueprints (P01–P21) in the left sidebar (covering urban comeback, historical intrigue, xianxia cultivation, rule-horror, mystery thriller, sci-fi apocalypse, romance, action shonen and more), alongside aspect ratio (9:16 / 16:9), target shot count (0 = story-adaptive) and auto per-shot duration (computed dynamically from line length and action beats, or pinned to 4s / 8s / 10s / 15s tiers).
    • Runs a dual-rhythm A+B beat breakdown (Track A narrative progression + Track B emotional hooks, cliffhangers and payoff beats) to generate scenes, structured shot cards (framing, camera angle/move, auto duration, acting, dialogue, imagePrompt, time-sliced videoPrompt) and the extracted character (with state variants) / scene / key prop table.
    • Edit any field inline, toggle Per-Shot Lock, or launch “3D Director Previs” to rehearse character blocking and Cinemachine camera moves on a 3D stage.
  2. Stage 2 — AI Director Audit (11-Point Continuity & ≥67% Spoken Dialogue Gate):
    • Audits the entire storyboard against a 11-point AI Director continuity checklist (180-degree axis rule, shot-size progression, eyeline match, lighting/time continuity, 3-second opening hook, shootability, anchor slot budget and more).
    • Enforces a strict ≥67% spoken dialogue ratio audit so episodes stay driven by punchy character interaction rather than wall-of-text narration; any flagged issue or low-dialogue scene supports one-click targeted rewrite (or automatic multi-round revision up to filmReviewMaxRounds) while skipping locked shots.
  3. Stage 3 — Cast, #variant Wardrobe Sheets, STYLE01 Bible & Cross-Episode TTS Voice Binding:
    • STYLE01 Master Style Bible: renders the global visual style, linework/rendering finish and color-lighting anchor shared across the episode.
    • Character base + #variant wardrobe/state sheets: generates base turnarounds plus automatic per-scene Character#variant sheets (e.g. LinMo#battle-damaged, SuWan#gala-dress, Villain#awakened) so costume or state changes never break facial identity.
    • Scene plates & key props: generates clean, character-free environment plates and hero prop sheets.
    • Persistent cross-episode TTS voice binding: audition and bind a project Voice Profile (timbre, emotion, speed) to every character right on their cast card; bindings persist across episodes via out-cast → in-cast and synthesize per-shot dialogue audio automatically.
  4. Stage 4 — Batch Video Shoot (@1–@4 Anchor Lock + VLM Vision QC + Fingerprint Cache):
    • @1–@4 anchor-locked generation: automatically injects each shot's active character #variant sheets, scene plate, key prop and STYLE01 / same-scene continuity frame into exact @1–@4 reference slots for keyframe and video generation.
    • VLM Vision QC auto-reshoots: a multimodal vision model inspects generated keyframes for facial drift, wrong wardrobe variants, hand/anatomy defects or prompt mismatch, triggering automatic reshoots up to your retry cap.
    • Fingerprint incremental cache & per-shot lock: content hashes across prompts, anchors and model settings ensure unchanged shots hit cache in milliseconds — combine with per-shot lock and Keyframes only / Keyframes + Video modes for zero-waste retakes.
  5. Stage 5 — Release Pack, Full Stitched .mp4 & JianyingPro / CapCut Draft Handoff:
    • Cover poster & viral title/tag release pack: generates vertical/horizontal cover posters alongside platform-ready viral titles, episode hooks and hashtag packs for TikTok, Douyin, ReelShort, Bilibili and YouTube Shorts.
    • Full stitched .mp4 & output.timeline handoff: export a complete stitched .mp4 episode with dubbed dialogue in one click, or hand off all video clips, per-line TTS dialogue tracks and subtitles directly to output.timeline for NLE finishing and one-click JianyingPro / CapCut multi-track draft export.
Credit-saving workflow (lock keyframes before shooting video & release pack): run Stage 4 in “Keyframes only” mode first to verify compositions and #variant likeness across the episode; tweak and lock individual cards, then switch to “Keyframes + Video” and proceed to Stage 5 — cached keyframes skip redrawing 100%.

5. Step 4: Incremental retakes, single-shot polish & CapCut drafts

  • Edit one shot, reshoot only one shot: tweak a single shot's prompt, line or active #variant tag and click “↻ Rerun” — every untouched shot hits the fingerprint cache immediately.
  • Multi-episode cast & voice continuity: wire Episode 1's out-cast port into Episode 2's in-cast port to carry over base turnarounds, #variant outfits, STYLE01 and bound TTS voices across an entire season.
  • Pixel-level single-shot polish with film.shot + image.process: wire a “Shot” (film.shot) node from out + out-cast (or install short-drama9) and insert the 10-in-1 Image Processing (image.process) workbench for local inpainting, cutout or 4K upscaling.
  • Finish in output.timeline & export JianyingPro / CapCut drafts: hand off from Stage 5 to output.timeline to add transitions, LUTs and effects across 6 creative tabs, then export a finalized .mp4 or a native JianyingPro / CapCut multi-track project draft.

6. FAQ

  • Where do I install presets like short-drama in v8.9.1? Domain workflow presets are published in the Skill Marketplace (ai-art-engine-skills) for one-click on-demand installation. You can also drag in assets/recipe/recipe1.png (aiae:graph PNG-as-Workflow) or drop film.workbench straight onto any Free Canvas.
  • How do characters change outfits or battle states mid-episode without losing facial consistency? Stage 3 generates Character#variant wardrobe/state sheets anchored to each character's base turnaround, and Stage 4 injects the active variant alongside the scene plate, key prop and STYLE01 into @1–@4 reference slots automatically.
  • What happens when Stage 2 flags spoken dialogue below 67%? Click One-Click Targeted Rewrite in Stage 2: the AI Director converts exposition-heavy narration into natural, conflict-driven character dialogue while leaving any locked shots untouched.
  • How do I keep the exact same character voices across Episode 1, 2, 3…? Bind each character to a persistent project Voice Profile in Stage 3 and pass out-cast into the next episode's in-cast port — every episode synthesizes lines with the identical voice and hands them off cleanly to Stage 5 and JianyingPro / CapCut drafts.
