Guide · v8.9.1 · Video Generation, Forensic Remake & Timeline NLE

AI Video Generation, 2-Node Forensic Remake & Multi-Track Timeline

Start from a blank Free Canvas to wire text-to-video, image-to-video and 3D Director Stage offscreen .webm trajectory white-box clips (@2), run the built-in flagship builtin.video-breakdown-remake (semantic.analyze → semantic.rebuild) pipeline for 4-axis audio-visual forensic breakdown & 1:1 video remake, and finish in the CapCut-grade 6-tab output.timeline with native JianyingPro / CapCut draft export.

1. Preparation

  1. Models: Settings → Models → add and enable a provider (Volcengine Ark, Kling, MiniMax, OpenRouter, …) → tick the models you want on the Video tab and set the default video model. For 2-node forensic video remakes, also configure default multimodal VLM / text, image and optional TTS models.
  2. Object storage (required for reference video): Settings → Object Storage → add and enable one of Volcengine TOS / Alibaba Cloud OSS / Tencent Cloud COS / Amazon S3–compatible. Local reference videos (including 3D Director Stage .webm trajectory clips) are automatically uploaded to signed URLs so cloud video APIs can fetch them.
  3. Make sure the provider account has credit — submission fails immediately when the balance is low (e.g. MiniMax 1008).
You can skip object storage while doing pure text-to-video with no local reference video. The moment you connect a project or imported video to the video port, an enabled object storage is required.

2. Create a free canvas

  1. With the project open, create a new Free Canvas from the workbench toolbar or the asset library.
  2. If a “Free Canvas” already exists, new ones are named “Free Canvas 2”, “Free Canvas 3”… The name only distinguishes them in the asset library; you can rename the asset there.
  3. Double-click the Free Canvas asset to enter the blank node graph (host inner graph).
Renaming a node on the canvas only changes its display name in the current graph — it does not rename the asset in the library. Rename the asset itself in the asset browser.

3. Build a minimal video chain

Right-click on empty space in the Free Canvas graph (or press Space for the menu) and add / connect nodes in this order:

  1. Add a Video Generation node. Pick the video model on the node or in the Inspector, then write the generation prompt.
  2. (Optional) Add a Text / Note node, or an upstream Prompt Optimizer, and connect its text output to the Video Generation Text input.
  3. (Optional) Add Select Video, or drag a video asset from the asset library as a host / reference node, and connect its video output to the Video Generation Video input (reference video).
  4. (Optional) Connect an image node or asset to the Image / First frame / Last frame port (depends on the model and frame mode — see the next section).
  5. Add a Video Output or Final Timeline (output.timeline) node and wire the generation output into it for preview and export.

Sketch (text-to-video + reference video):

[Text / Prompt] ──────────────► [Video Generation] ──► [Video Output / output.timeline]
                                        ▲
[Select Video / 3D Stage .webm] ────────┘   (Video port = reference video)

4. Reference video & 3D Director Stage .webm white-box control (@2)

The Video Generation node's Video input accepts a reference video so the model can follow motion, camera trajectories, acting beats or scene pacing.

  • Source: videos imported into the asset library, a Select Video node, upstream generated videos, or offscreen trajectory white-box clips exported from the 3D Director Stage (.dstage / director.stage3d).
  • 3D Director Stage offscreen .webm trajectory white-box video (@2): block out characters, props and Cinemachine camera keyframes inside the 3D Director Stage — the stage renders an offscreen keyframe anchor (@1) alongside a clean camera-trajectory white-box video .webm (@2). Wire both into a multimodal reference-capable video node and prompt “keep @1 character/scene appearance while following @2 camera trajectory” for deterministic 3D camera control.
  • Upload & cleanup: at run time, local paths / data URLs are uploaded via your enabled object storage into signed URLs, and temporary objects are cleaned up automatically when the run finishes.
  • Multiple references: where the Video port accepts several links, you can attach multiple reference clips (subject to actual model support).
Use the full endpoint shown in your console for object storage (an https:// prefix is fine). The app handles the protocol correctly; if you ever hit an ENOTFOUND …https error, upgrade to a build containing the TOS presign fix and retry.

5. First/last frames and prompts

  • Pick the frame mode in the Video Generation node params:
    • None: no forced first/last frame (pure text-to-video, or reference video / image only).
    • First frame: exposes a first-frame image port — good for image-to-video and frozen openings.
    • First + last frame: constrains both the opening and closing shot (requires model support, e.g. Hailuo / Kling / Seedance capabilities).
  • Use @ (e.g. @1, @2) in the prompt to reference connected upstream images and reference videos cleanly.
  • Duration, resolution and audio options depend on the current model capability catalog; unsupported options are ignored or disabled.
  • Frame Pulling: connect an upstream video to the Frame Pulling node and double-click to open the pull station — browse frame by frame on the filmstrip, grab key frames and annotate them; the grabbed frames can be wired into downstream generation nodes as references.
  • Segment Reshoot: connect the source video to the Segment Reshoot node and double-click to open the reshoot station — mark the start / end time to change and describe the edit (e.g. “make the umbrella transparent”); running it reshoots only that timestamp window while leaving the rest untouched.

6. Flagship: 2-Node Forensic Video Breakdown & 1:1 Remake (semantic.analyze → semantic.rebuild)

Need to reverse-engineer a viral talking-head clip, e-commerce ad, trailer or short drama and remake it 1:1 with your own cast, product photos or art style while preserving its exact cut rhythm, camera moves and beat drops? AI Art Engine v8.9.1 ships the built-in core preset builtin.video-breakdown-remake (rea-video) powered by two directly connected first-class nodes: 

[Source Video (in-video)] ──► [🧭 Video breakdown: semantic.analyze] ──(SemanticTimeline aiart.semantic-timeline@1)──► [🎬 Video remake: semantic.rebuild] ──► [out-video + compare.mp4]
                                        ▲                                                                                          ▲
[Replacement Subject / Product Images (in-images, @Image1..k)] ────────────────────────────────────────────────────────────────────┘
  1. 4-Axis Audio-Visual Forensics (semantic.analyze):
    • Word-level ASR track (WhisperX): extracts millisecond-accurate word timestamps and speaker utterances for lip-sync alignment and kinetic captions.
    • Cut detection (PySceneDetect) + 3-frame VLM camera forensics: locates every shot boundary and samples the first / middle / last frames of each shot so a VLM can decode shot size, angle, camera movement, lighting and blocking.
    • Musical beat grid (Librosa) & audio stem separation (Demucs): computes BPM and beat accents via Librosa while Demucs isolates clean instrumental/BGM stems from spoken vocals.
    • Outputs a unified, type-safe SemanticTimeline (aiart.semantic-timeline@1) document you can inspect and edit by double-clicking the node.
  2. Clean-Plate Background Anchor Extraction (Subtitle Removal): automatically detects and inpaints away burned-in subtitles, stickers and lower-thirds from source shots to extract clean background anchors without garbled text artifacts.
  3. Dynamic-Programming Shot Batching, Lip-Sync & Kinetic .ass Subtitles (semantic.rebuild):
    • DP shot batching: groups rapid-fire micro-cuts optimally via dynamic programming to match your video model's duration tiers, cutting API cost while keeping cut-on-beat precision.
    • Subject swap, lip-sync & kinetic .ass captions: swaps in new characters or products wired to in-images (@Image1..k), applies lip-sync to newly synthesized speech, mixes back clean Demucs stems, and burns beat-synced kinetic .ass subtitles into the remade master (out-video).
  4. Side-by-Side Verification Video (compare.mp4): alongside the clean remake MP4, automatically renders a frame-locked side-by-side compare.mp4 (original on left, remake on right) so you can verify pacing, framing and beat alignment at a glance.

7. 6-Tab Final Timeline (output.timeline) & JianyingPro / CapCut Draft Export

  1. Select the Video Generation, semantic.rebuild or output node → click Execute in the toolbar (or hold C); shared upstream nodes cook only once.
  2. CapCut-grade 6-tab Final Timeline (output.timeline): wire or drag generated clips, dubbing and BGM into output.timeline and double-click to open the multi-track NLE studio:
    • Features 6 creative asset tabs — Media, Effects, Transitions, Filters, Adjust and Templates — with 120+ effects, seamless transitions, LUTs and DOTween dual-layer keyframe curves.
    • Dual export paths: render a finished .mp4 directly inside the app, or export a native JianyingPro / CapCut multi-track project draft preserving separate video, dialogue, BGM and subtitle tracks for downstream editors.

8. FAQ

Symptom Fix
Object storage not configured Enable one of TOS / OSS / COS / Amazon S3–compatible under Settings → Object Storage and fill in the keys and bucket. For the S3 fields, see the Yandex Object Storage example.
insufficient balance (1008) The provider account is out of credit — top it up in the matching console (not an API Key mistake).
How do I launch the 2-node forensic remake workflow? Pick the built-in preset builtin.video-breakdown-remake in One-Click Workflow, or right-click on any Free Canvas to wire Video breakdown (semantic.analyze) → Video remake (semantic.rebuild).
Renaming a node also renamed the asset Newer builds no longer rename the asset — update the client. Use the asset browser to rename library entries.
Reference video has no effect Confirm it's connected to the Video port, that the model supports video reference, and check the upload summary in the run log.

For the full interface reference see the Manual; model and object storage details are in chapter 4 of the manual.
