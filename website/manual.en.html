1. Overview & preparation

AI Art Engine (AIArtEngine) is a local-first, agent-native multimodal AI desktop studio and production asset engine for game development, AI comic dramas / short dramas, viral video remakes, advertising and e-commerce. In v9.0.0, beyond flat images and clips, it compiles AI outputs directly into engine-ready production assets:

  • Game UI Layer Split & Sprite-Atlas Compose (image.layerSplit + ui.atlasCompose + ui.componentLib): 16 UI control classes, offline/online OCR fill+stroke extraction, 9-slice clean-plate inpainting, 3D exploded preview, real sprite-atlas UI composition, and one-click export to editable .psd with native TySh text layers plus Unity UGUI/UXML, Godot 4 .tscn, and HTML5 code.
  • Machinations v2 Game Economy Studio (game.economy): 100% Machinations semantic alignment across 59 verified building blocks, lossless Simple Macro ↔ Pro Blueprint toggle, 120fps Bezier slope diamond (◆) & direct curve-drag inverse Goal-Seek formula solver (k * pow(STEP, p)), Monte Carlo P10/P50/P90 bands, 2D sensitivity heatmaps, and zero-code playable HUD card prototypes.
  • 21-Genre, 5-Stage AI Comic Drama / Short Drama Workbench (film.workbench): ships P01–P21 genre archetypes across a 5-stage closed loop (① A+B dual-rhythm beat breakdown → ② 11-point continuity & ≥67% dialogue audit → ③ #variant wardrobe / scene / prop / STYLE01 anchors & cross-episode TTS voice binding → ④ @1–@4 locked batch shoot & Vision QC → ⑤ Cover/Title release pack & full episode .mp4).
  • 2-Node Forensic Viral Video Remake (rea-video: semantic.analyze → semantic.rebuild): combines WhisperX word-level ASR, PySceneDetect cuts, Librosa BPM/beats, Demucs vocal/BGM stems, and 3-frame VLM camera forensics to strip burned-in subtitles and render a 1:1 split-screen comparison remake (compare.mp4).
  • In-Process Pi Agent, 102-Tool Bi-Directional MCP Server & 24h Scheduled Automations: exposes /mcp (93 core tools) and /mcp/blender (9 live Blender modeling tools), paired with built-in ◈ AI Chat running an in-process Pi Agent runtime with load_toolset on-demand lazy MCP loading (<= 96 active tools — never hits the 128-tool API limit), Craft / Plan / Ask dual-layer gating, live 🛡️ Restricted Mode ↔ 🔓 Full Access toolbar toggle, up to 6 parallel cross-project sessions (with multi-fairy Wish Maiden accompaniment), and 00:00–23:59 scheduled runs.
  • CapCut-Grade 6-Tab NLE, Spine 2D Rigging & Wavelet Portrait Lab: 120+ GPU/FFmpeg effects/transitions/LUTs, editable JianyingPro / CapCut draft export, AI-aligned Spine 2D skeleton export, 4-band wavelet skin retouching, and 56-bone 3D Director Stage blocking.

Workspaces and media stay in a local directory you choose (workspace.json + project.json); text / image / video / audio generation runs through your own BYOK model providers (OpenRouter, OpenAI, DeepSeek, Zhipu, Kimi, xAI, Google, vLLM, Ollama, LM Studio, Volcengine Ark, Kling, MiniMax, Tongyi Qianwen, ModelScope, ComfyUI, MagicRouter, …); 3D model generation supports Meshy, Tripo, Rodin (Hyper3D), Luma AI, Lux3D and live Blender MCP modeling, while spatial world generation supports World Labs (Marble 3DGS → .glb). Launch pipelines via One-Click Workflow, the Skill Marketplace, or by dragging any exported aiae:graph recipe PNG directly onto the canvas.

First-time setup

  1. Install the package for your platform from the download page or GitHub Releases.
  2. Create a workspace and click “⚡ Zero-Key Instant Demo” inside right-hand ◈ AI Chat to test Xianxia RPG UI layer splitting with zero API keys; for cloud generation, open Settings, add a model provider key, and fetch & tick your models.
  3. (Optional) Under Object storage configure Volcengine TOS / Alibaba Cloud OSS / Tencent Cloud COS / Amazon S3–compatible (only one can be enabled at a time) so large files such as reference videos can be exposed as URLs.
  4. Inside your workspace, start from One-Click Workflow (e.g. built-in builtin.video-breakdown-remake), install domain bundles from the Skill Marketplace, or drag an aiae:graph recipe PNG onto the canvas.
There is no traditional menu bar. The top-left logo returns to the home page; “Settings” opens the settings panel, and the “Skill Marketplace” sits immediately to its left, opening a dedicated window for installing workflows and skills (see §5.7 Skill Marketplace). Close Settings by clicking the empty overlay or “Back”.

2. Core concepts

Spend two minutes on the terms below and every screen afterwards will make sense. In v9.0.0, data is organized as Workspace → Multi-Project → Host Asset / Node Graph → Asset: the workspace and projects are local folder containers, the node graph is the production floor, and assets are the deliverables.

Workspace & Project

Stored in a local directory you choose, tracked by workspace.json and per-project project.json files. Switch projects or edit files anytime from the ◈ AI Chat left sidebar; copy the folder to migrate across machines.

See §3 Home & workspaces

Asset

The umbrella term for every output and piece of media in a project: scripts, storyboards, cast sheets, keyframes, video, audio, 3D models, UI atlases, and host assets — browsed and dragged from the asset library.

See §6 Asset library

Host asset & PNG recipe

A reusable black-box component built via One-Click Workflow or the Skill Marketplace. Double-click to Dive into its inner node graph, or export/drag an aiae:graph recipe PNG to unpack the full pipeline anywhere.

See §7 One-Click Workflow

Node graph

The typed DAG canvas describing “input → generate / simulate / decompose → output”, serving as the shared foundation for all Dive workbenches and all 102 MCP tools.

See §8 Node graph

Port

A node's inlet or outlet. Ports strictly distinguish singular from plural: image / images, video / videos, text / texts. Different types never connect, and singular can't go into plural. Round ports are single out; square ports are lists (out-all).

See §8.1 Add and connect

5-Stage Film Workbench

Film Workbench (film.workbench) pairs 21 genre archetypes (P01–P21) with a 5-stage Dive loop: ① A+B Beat Breakdown → ② 11-Point Audit → ③ Cast/Scene/TTS Voice → ④ @1–@4 Batch Shoot & Vision QC → ⑤ Release Pack & Full MP4.

See §9 Film Workbench

Anchor sheets & #variant

Character #variant wardrobes, scenes, props, and STYLE01 reference sheets generated in Stage 3 and locked via @1–@4 plus cross-episode TTS voices in Stage 4 — eliminating face drift across shots.

See the Short-Drama Guide

Game UI & Economy Studio

image.layerSplit + ui.atlasCompose deliver native TySh .psd and Unity/Godot UI code; game.economy brings Machinations v2 simulation with 120fps curve-drag inverse Goal-Seek.

See §8 Game UI & Economy

3D / 2D Director Stages

director.stage features 56-bone humanoid rigs, 24 procedural motions, 38 pose presets, offscreen .webm trajectory white-box video (@2), and World Labs 3DGS → .glb; stage.2d exports AI-aligned Spine 2D rigs.

See §11–12 Canvas & Director

6-Tab Final Timeline

CapCut-grade multi-track NLE (Media, Effects, Transitions, Filters, Adjust, Templates) with 120+ GPU/FFmpeg effects, DOTween keyframes, TD-PSOLA singing synthesis, and editable JianyingPro / CapCut draft export.

See §10 Final timeline

Asset package .aipackage

An archive format that packages assets together with their dependency graph for cross-machine migration or team handoff, restoring everything intact on import.

See §13 Asset packages

2.1 How a 5-stage AI comic / short drama runs

With the concepts above in place, the closed-loop data flow of the v9.0.0 short-drama pipeline reads:

  1. Script input (text.plain) → wired into Film Workbench (film.workbench) with one of the 21 genre archetypes (P01–P21).
  2. ① A+B Dual-Rhythm Beat Breakdown: splits the script into structured A (narrative) + B (emotional reaction) beats with shot sizes, camera moves, durations, dialogue, and cast/scene/prop tables.
  3. ② 11-Point Continuity & ≥67% Dialogue Audit: audits every shot across 11 directorial continuity rules and dialogue pacing, auto-rewriting unapproved shots while respecting locked shots.
  4. ③ Cast #variant, STYLE01 & TTS Voice Binding: batch-generates character wardrobe variants, locations, props, and style anchors (with fingerprint caching) and binds persistent cross-episode TTS voices.
  5. ④ @1–@4 Locked Batch Shoot & Vision QC: binds @1–@4 anchors to render keyframes (with Vision QC auto-reshoots) and batch-shoots multi-cut motion clips with lip-synced dialogue.
  6. ⑤ Release Pack & Master Export: generates cover art and viral title copy in Stage 5 and exports the full episode .mp4 — or sends clips into the 6-tab Final Timeline for CapCut draft export.
Install the short-drama bundle from the Skill Marketplace or generate it via One-Click Workflow with zero manual wiring. See the Short-Drama Guide and Quickstart for the full walkthrough.
